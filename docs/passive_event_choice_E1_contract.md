# E1 · 事件触发下的必选分岔开发试跑

- 固定开发种子 `43621`、`43641`，各飞 `N` 和 `LLM` 一次，共四臂。不筛场、不加跑，前述旧预算与封存种子不动。复用现有随机场生成器与 P7 两栋 2.5D 建筑；每对同场、同测量噪声种子（场景种子加一）。
- 唯一输入是已知 2.5D 建筑、飞行状态、当前位置历次带噪总功率原始点、冻结 GP 的可公开预测与已发生残差。隐藏场、源、未来点、其他臂和事后数据不进入数值决策或独立请求。每秒先用新点检验旧预测，再更新 GP；不补测、不延续最近读数，不训练 MLP。
- 起飞以公共数值算法规划，不咨询。每个普通点后查承诺路线未来 1/2/3/4 秒的有支持 GP 均值。任一达 `-80 dBm` 进入预警；每次进入后最多复核一次，跌回阈值下后再进入可再次复核。没有备选时先沿合法余程继续，到预警消失或出现备选为止。阈值取现有暴露归一化参考，无断链含义，不用本批场景调参。
- 公共混合菜单：全域枚举保留所有合法余程，按首中间点分组；另外对承诺余程尝试删除首个尚未经过的中间点并直接重连。每次重新核建筑、完整余程到目标、全程 `1.25D0`、能量和时限；不合法、重复的重连不得进入菜单。软门控只作为相对原路的证据信息，不否决合法选择。算子借鉴 Røpke–Pisinger（2006）的破坏—修复思路，并非复现 ALNS。
- 各候选从同一时刻起，用 6 秒窗口、0.5 秒中点积分，遇候选在窗内结束则拆小区间。仅在所有仍飞行候选均有支持的时间片积分逐点线性功率上尾 5% 均值；未知段不填 1，不当作安全。单路线有支持风险仅作提示。数值 N 枚举完整菜单：依窗口 T+共同支持 Q（保留 8 位小数）、全余程航时、路线 ID 排序。无共同支持时不声称 Q=0 的物理判断，仅按时间排序。全程真实 T、Q、T+Q、是否合法到达仅用于事后评价。
- 有至少两条合法余程时，LLM 新独立会话必须从路线 ID 选择一条，也可明确选原路；没有弃权字段，不传数值答案、不自动覆盖合法回复。每次只给冻结的公开 allowlist、最近至多 12 条已发生点测和残差、各路线图与风险分解，不读工作区、历史或联网；原始请求和原始回执留证。每臂最多三次事件复核；起飞另计一次。超过预算继续已承诺的合法余程。缺失、迟到或非法回复停止该 LLM 臂并保留合法进展，不以数值回退冒充 LLM。一次回复上限 180 秒、800 字节，请求不超过 24 KB；本批总等待上限 720 秒。不重试、不续跑。
- 公共上限：每臂 61 个普通点和 GP 拟合、4 次候选评分、70M 逻辑查询、90 秒仿真时间、最多 126 条候选每次。仿真咨询同步暂停，墙钟另计，不能证明实时可用。每场发布完整左右双图和各次预警、实际选择、是否合法到达；没有触发也完整发布。这是开发试跑，不用于跨场景显著性或 LLM 收益结论。
