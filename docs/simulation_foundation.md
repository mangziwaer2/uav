# 传播、范围感知与信息边界

更新：2026-10-31。本文件说明阶段①的仿真基础，不增加新研究方向；后续优先级只在`current_roadmap.md`维护。

## 1. 本轮修正什么

旧环境只有局部高斯场和单点总功率。无人机可以收到逐渐增强的信号，但没有方向观测；单次innovation小于阈值时，持续上升还可能错过提前复核。因此不能只调整提示词，或要求LLM从没有收到的证据中判断前方源位置。

当前默认环境改为：

- 固定载频下的大尺度传播衰减，考虑源高、机高和简化建筑穿透。
- 无人机同时接收本位置的总功率和360°波束功率快照，能在强干扰参考等值线外发现远源方向。
- 多源先合成接收功率再检测，不把真实源个数、距离或位置作为传感器输出。
- 新发现可检测方向、接收功率持续增强及首次越过软参考，可以提前请求决策；仍遵守最小复核间隔。
- 点测支持、测向证据、模型预测和隐藏真值分别保存。没有实现周围每个空间位置的直接测量。

这里的“范围感知”是被动接收远处辐射的能力，不是雷达式测距，更不是读取半径R内的真值网格。探测范围是发射功率、传播、遮挡、接收灵敏度和噪声共同产生的结果，不设一个普适圆半径。

## 2. 真值传播

默认`fields`每项包含`center_m`、`eirp_dbm`、`height_m`、`start_seconds`、`end_seconds`、`velocity_mps`。EIRP是当前观测频带内的等效全向辐射功率，不是全频总辐射功率。所有源在同一频带，暂不模拟跨频扫描或协议解调。

“活动源”指真值脚本中当前正在辐射的隐藏源，不是被无人机发现、定位或激活的源。仿真器必须知道这些参数才能生成传感器读数；无人机／LLM／规划器只接收有噪观测，不能枚举真实源。左图源S是研究者评价信息，不是在线源列表。

对每个活动源，中心随时间平移；三维传播距离由水平距离及机高与源高差计算：

```text
d = max(sqrt(horizontal_distance² + (uav_altitude - source_height)²), d0)
PL0 = 20 log10(4π d0 f / c)
Pr_dBm = EIRP_dBm - PL0 - 10 n log10(d/d0) - blocked_prisms × obstacle_loss_dB
I_dBm = 10 log10(10^(background_dBm/10) + Σ 10^(Pr_dBm/10))
```

`c=299792458m/s`。`PL0`使用自由空间参考损耗；`n`是经验距离损耗指数，不宣称ITU给出了本场景的2.2标定值。参考距离夹紧避免近场数值奇点，不是近场电磁求解。源贡献与背景在毫瓦域相加，绝不直接相加dBm；假设非相干或经过时间平均，不模拟相位干涉。

默认机高30m、源高1.5m、载频2.4GHz、参考距离1m、损耗指数2.2。两个源的EIRP分别为−2／−5dBm，保留原来的活动与运动脚本。它们是研究场景参数，不代表实际干扰器、接收机或无人机平台标定值。

### 遮挡近似

已知矩形按统一`obstacle_height_m`外推成竖直棱柱。接收点到源的三维线段穿过某棱柱时扣除一次`obstacle_loss_db`；多个棱柱累计。使用原始矩形，不把飞行净空膨胀当作建筑厚度。默认统一高度20m、每个棱柱损耗6dB，不是每米损耗，也不区分墙体材料。

飞行规划仍保守禁止进入二维障碍投影，即使机高高于部分棱柱；传播几何和飞行净空约束是不同用途，不因此开放越障飞行。遮挡只衰减，不把障碍背后设成绝对不可检测。

### 高斯合成基线

此前的`center_m/sigma_m/peak_dbm/start_seconds/end_seconds/velocity_mps`六字段格式仍可显式构造合成对照或回放本项目的干扰日志；它不是默认传播模型，也不是旧通信质量兼容接口。两种源参数不能混写。高斯基线不施加传播棱柱损耗。

## 3. 机载感知

默认`sensor.mode=power_bearing`假设机上有能覆盖360°且已消除前后模糊的阵列接收系统，位置已知、世界方位带标定误差。实现使用**同步波束快照**，不是让机械天线瞬间转一圈。暂未计阵列处理的额外功耗、相干采样误差、旁瓣真实结构或设备处理延迟；不是具体商品设备数字孪生。设为`power_only`则只有本地点功率，`directional_scan=null`；不能从一个全向功率标量凭空得到来向。切换模式不改变点测随机数或真值。

一次`observe(position,t)`返回：

1. 本位置总干扰接收功率dBm，叠加独立的点测dB高斯噪声。
2. `directional_scan`：24个15°间隔的波束方位与接收功率、超过检测条件的角峰下标、当前有效检测阈值、波束宽度及方位标定误差标准差。

“来波”是干扰源辐射后传播到接收机的电磁信号；“来波方向”按从无人机指向该信号来源的方位定义。“接收波束”是接收设备对不同方向信号的选择性响应，不是无人机向外发射的雷达扫描束，也不是源发出的扇形危险区。真实阵列可以通过阵元信号加权形成方向响应；当前用下面的参数化功率响应代替阵元IQ信号和具体测向算法。

方向以东为0°、向北为90°，逆时针增加，世界坐标系。测向接收器使用独立种子流，不改变点测噪声序列；真值和回放查询不消耗传感器随机数。

采用归一化主瓣功率响应：

```text
angular_error = wrap_to_[-180,180)(beam_azimuth + calibration_error - source_bearing)
attenuation_dB = min(front_back_dB, 12 × (angular_error / full_half_power_beamwidth)²)
beam_power_mW = background_mW + Σ source_received_mW × 10^(-attenuation_dB/10)
beam_measurement_dBm = 10 log10(beam_power_mW) + beam_noise_dB
threshold = max(receiver_sensitivity, background_dBm + minimum_excess_dB,
                median_scan_power_dBm + minimum_contrast_dB)
```

每束先叠加所有源，再加测量噪声、检测局部角峰；按峰功率从强到弱，在环形方位上抑制小于一个波束宽度的邻近峰，避免同一主瓣内的噪声起伏被当成多个可分辨方向。这是分辨能力的工程近似，不是MUSIC分辨率公式或源数估计。原始波束功率不因去重而改变，间隔足够的弱峰仍可能保留。

该响应是工程近似，峰值增益归一化为0dB、各束背景功率统一；不是从真实阵元电压计算的MUSIC或完整阵列流形模型。默认半功率全宽45°、方向抑制上限25dB、波束功率噪声1dB、扫描共同标定误差稳态标准差3°，最低检测功率−94dBm，背景增量与角峰突出量均3dB。角峰突出量用于抑制平坦旁瓣或全向背景产生的伪方向。

### 方位误差不是每秒独立重抽

默认方位误差采用稳态一阶Gauss–Markov过程，使用真实观测时间差而不是循环次数：

```text
rho = exp(-delta_t / tau)
bias(t) = rho * bias(previous) + sigma * sqrt(1-rho²) * Normal(0,1)
bias(initial) ~ Normal(0,sigma²)
```

`sigma=bearing_error_deg`，`tau=calibration_correlation_seconds`，默认5s。相同时间的相关偏差不变；较长间隔才逐渐去相关，稳态标准差不随时间无限增长。`tau=0`显式退回独立快照误差。方位误差与每束功率噪声使用独立随机流；实际抽取的偏差只留在传感器内部，不作为观测或上下文输出。模型只能知道公开误差参数，不能据此减掉本次真实偏差。

采用相关误差是为避免把相邻重复扫描误当独立证据，并非新增高精度测向算法。Smith等研究在功率增益变化中使用同类过程，不为此处的方位误差参数提供标定；3°与5s均是工程假设，不因采用随机过程就成为真实设备规格。

**当前仍是直达路径主导的理想化测向。** 真源方位仅在传感器内部生成方向响应；建筑只减功率，不生成反射路径或改变来向。故只要检出，扇区仍常覆盖真源。这不能证明真实城市遮挡、多径下也如此准确，45°扇区也不是概率置信区间。本轮没有人为增加噪声来制造LLM优势，也没有实现多径或阵元IQ仿真。

波束中心不能当作精确AoA，15°离散、宽主瓣、标定噪声和多源混叠都造成方向不确定性。源正好位于机下时没有可定义的水平方位，采用无方向的平坦功率响应，不返回任意真实方位。

### 允许出现的不完美观测

- 同方向多个源可以合为一个角峰；峰数不等于源数。
- 不同方向且可分辨的源可以产生多个峰；强源旁瓣或噪声也可能产生伪峰。
- 阈值附近可以漏检／虚警，不强制源必定被发现。
- 遮挡或低EIRP使同距离源不可检测，强源也可能在更远处被发现。
- 信号变强可以是接近、源运动、源出现、功率叠加或遮挡变化；传感器不替模型选择解释。
- 一次测向没有距离；单次功率也不能在未知EIRP条件下唯一确定距离。

因此`−94dBm`灵敏度与`−80dBm`干扰软参考不能合并：检测条件可以在仍低于干扰参考时满足，之后仍需要推断与规划。二者均是仿真配置，不是硬件或安全标准。

## 4. 观测如何进入闭环

`ElectromagneticBelief`保存点测和有时间戳的波束观测；最多缓存128次，向模型提供有效年龄窗内最多6个分布取样的测向快照。每条包含接收位置、时刻、角峰及功率、角分辨率相关参数；当前完整波束数据仍在`latest_observation`与观测事件中。

**测向不直接涂满地图。** 点测只支持最大40m局部外推，35s后失效，已有启发式距离／年龄误差仍保留。远源检测并不增加远处格子的直接观测支持，空峰也不能降低远处不确定性。多位置角线索为LLM比较源假设和选择补测提供依据，但没有内置把真实位置复制成源假设的定位捷径。

2026-10-31默认LLM源协议已改为0至3个候选传播源的`center_m/eirp_dbm/height_m/velocity_mps`，显式高斯协议保留但不可混写。公开前向模型只含机高、载频、距离损耗参数与已知建筑，不含源真值；LLM必须从观测提出源假设，数值层不自动拟合源位置。

已有功率拟合之外，现加入候选源合成波束角峰与观测角峰的环形残差及相关时间块汇总；没有观测角峰不反推远处安全，峰数不是源数。新方向观测还会在更新窗口前检验旧源预测，显著失配可提前复核。字段、归一化、目标权重、拒绝／停用条件及启发式局限统一见`first_version.md`第2节。允许拟合不唯一和LLM说明证据不足；观测、假设、已测支持与隐藏真值始终分开。

### 提前复核

`ObservationMonitor`只读观测，以下情况可提前请求咨询：

1. 相比上次复核，首次出现可检测角峰。
2. 当前最强角峰比上次复核增强至少6dB。
3. 最近5s至少3次点测的累计上升达到6dB，当前功率已达到检测灵敏度，且比上次复核增强至少6dB。
4. 点测从上次复核的低于软参考变为达到／超过软参考。

单次innovation达7dB的原触发继续保留，周期10s、最小复核间隔3s不变；触发之后仍由原有决策／传统算子执行，不强制绕行，也不证明已安全。趋势事件与大单次偏差分开记录，所有点测照常更新地图。此处是基础观测事件处理，不是学习门控或新增模型行动。

## 5. 日志、回放与验收

日志版本仍为干扰语义2，新增字段是可选扩展。每次观测保存完整扫描和预警依据；上下文提供`directional_sensing`和`sensing_warning`，明确测向硬件是否可用、相关时间及未模拟反射／阵元IQ。扫描摘要记录相关时间和最小峰间隔，可读日志提醒重复方向不是独立证据。新增`directional_scans`、`directional_detected_scans`、`sensing_warning_reviews`计数，均不是正确定位次数或LLM收益。旧日志只回放原记录，不补造新的传感器读数。

可读日志用中文列出接收到的方向、功率、预警原因，明确没有测距。左右回放叠加同一份橙色测向扇区和虚线：扇区来自当帧最新有效观测，左图便于与真源对照，不重新使用真源方位绘制；长度只为显示，**不是探测半径或已测区域**。左侧真源S仍只供研究者观察，未知灰色遮罩不因测向消失。

基础测试覆盖解析式损耗、频率／高度变化、三维遮挡、多源线性叠加、角峰混叠、提前发现、源生灭／运动、随机复现、测向不增加远处地图支持、时效、趋势预警、非法观测以及完整仿真日志与最小复核间隔。默认演示仍离线检查可绕行通道，测试折线不进入在线决策。

截至2026-10-31此次协议适配仍未启动真实LLM长时间试跑、训练或收益评价；模拟响应与数值回放只能验证接口，不能证明模型会利用新证据绕行。源预测与真值共享公开传播公式是当前匹配模型基线，后续真实收益不应回避模型失配或传统定位方法对照。

## 6. 未实现与适用边界

当前是可解释的大尺度传播＋理想化阵列功率观测近似，不是完整电磁仿真平台。尚无建筑材质与高度逐项标定、地形、天线极化／俯仰响应、相关阴影、多径／反射／绕射、相干叠加、真实阵列模糊、饱和与动态范围、脉冲／扫频干扰、传感器带宽及接收机热噪声分解、导航定位退化、转弯动力学或真实平台故障模型。噪声标准差、阈值与损耗未由实测数据校准，误差不是概率保证。

实际模型墙钟耗时仍单独记账，仿真仅计固定决策悬停，不随本地模型运行几分钟而让场移动几分钟。规划仍采用当前地图快照，不是到达时刻的时空安全优化。不得把“发现提前了”写成“肯定能绕开”或“安全最优”。
