# 离线有限过程生成：接口与任务评价合同

2026-11-11。承接证据/额度研究；本阶段先实现共同执行器并验证接口，下一阶段才做有限LLM生成。本文件实验前版本随运行冻结，结果另节补充。第一轮产物是**用现有算子组成的新过程**，不是生成底层Python函数或新RRT*实现。

## 共同执行版本

新增`src/uav_em/offline_process.py`，旧v1/v2、GP、传播、RRT*与仿真源码不变。所有方法先运行相同的原v2候选生成器：几何连接/侧绕和700样本旧J-RRT*，统一建立初始可行池与全程参考D0。采用既有R10规则：候选接下来10s的已支持期望超参考积分E，加10dB×未知秒数；在全池最低R10+1dB·s内选最短剩余路线，稳定平局保留原顺序。每次加入新候选后对全部已保留可行候选重选，不做逐次容差累积。

这个选择器是共同固定的开发代理，不是已验证稳定最优目标。旧J继续用于RRT*内部搜索和诊断，不再要求J下降才能接受候选，也不要求E必须下降；未知代价主导排序的已知局限仍存在。当前生成过程优化的是在这一共同接受器下的构造/搜索过程，不能随意输出新的评分权重或把未来真值作为运行状态。

初始池、初始验证、过程摘要、局部搜索/双腿、候选评分和最终独立几何验证共用2100样本/10000边上限；不重发预算。原池使用过的终检边不退还，新执行器重新建代价缓存时的未缓存查询仍收费。保留全候选池终检所需额度，资源不足则保留已验证的共同池路线。样本/边相同上限不等于实际CPU或总成本相同，字段计算节点与耗时另记。新解释器当前不对重复快捷连接做事前跳过，但候选生成后标注重复并可分支，工作不退还。

真正硬约束为碰撞与端点、剩余能量允许的距离、固定全程`已飞距离+剩余长度≤1.25D0`及共享搜索预算。D0只在任务开始确定一次，不能每次重新充满；它是初始有限池最短参考，不是真实全局最短。主动补测、等待、爬升、树持久复用和GP修改均未接入。

## 状态、动作与反馈

公开状态复用`RepairState`白名单：已知地图、当前位置/goal、能量、真实已收到的点测、GP公开样本/支持/年龄、当前剩余路线连接点与逐段摘要、已发生求解反馈；追加固定航程上限、已飞距离和当前前段风险分解。未知均值为null，不提供隐藏源、测向、未来脚本或未执行路线真值；支持范围80m不表示扫描。反馈中J分解仅为诊断，`improved`指共同R10窗口/长度规则选中了不同路线，不代表真实暴露改善。

过程为JSON，顶层仅`version/nodes`，版本`offline_finite_process_v1`，最多6节点。每节点仅有`action/next`：

- `action`字段为`operator/metric/padding/side/scale/allocation`；操作为shortcut/local_rrt/via/global_rrt/keep；区段度量为whole/supported_interference/unknown_front/stale/detour/evidence，沿用已实现的数值构造。
- padding为0–3个连接点，side为both/left/right/tube（via必须left或right），scale为near/local/wide，allocation为fixed/feedback。固定每步最多350样本；反馈分配按实际边/样本比与剩余步骤分摊、每步最多700，全程总账优先。
- `next`有default，可按improved/no_gain/geometry_failure/search_failure/resource_stop/duplicate/stopped/policy_error分支；只允许跳到更后节点或stop。没有任意表达式、自由数值坐标、导入、循环、文件接口或Python执行。

`generation_contract()`提供机器可读签名与人工参考。先比较共同池直接选择、固定过程、数值自适应过程；submitted_process与它们共用执行器。submitted仅表示外部提交的合法JSON，本身不代表模型生成。真实模型请求/响应由后续桥接器另留证，不能通过给方法命名伪造模型调用。

## 小预算离线生成协议（已由下一研究执行）

只用已检查的开发城市611/613/617/619。验证701/709与测试1601/1607/1609/1613/1619/1621继续不生成/读取；当前不报告泛化。未来验证另需冻结同分布生成器与方案，不仅保留种子。

先生成2份初始过程，最多再给2次修订，总共最多4份提交，非法提交也计数；每份至多评价一次、在4开发场景各运行一次，最多16次生成过程飞行。三个共同参考各4场景，共12次参考飞行；不得从旧版本复制指标当新共同版本结果。后续若要扩大预算必须另立协议。

每份原始请求、响应、解析、错误、程序哈希先保存，再评价。离线设计者可收到各场景的任务级标量反馈与合法性/预算错误，不给源参数、真值图或事后参考路线；任何反馈都属于开发期训练式选择，不能称未见效果。运行时过程只能读当前公共状态。全部生成及搜索开销均报告，不能仅报告胜者。无GPU训练或大规模代码进化。

固定任务评价同时看到达、真实飞行超参考积分、航程与计算成本，另报决策悬停积分；dB·s是仿真惩罚指标，不是物理剂量。相对同版本pool_only的开发门槛：全部到达且硬约束/预算核验通过、总飞行积分下降至少10%、平均航程不超过125%、每场景积分增加不超过max(1dB·s,基线10%)、基线零积分场景航程不超过105%。门槛不是统计显著性或安全保证；同时与固定/自适应参考完整比较，不能只凭赢pool_only声称LLM优越。若多份通过，先总积分、再总航程、再总边数选定，均不通过则保留失败、不得宣称优化。
