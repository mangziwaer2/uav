# 联合推断—规划核心评价设计

2026-11-19交接整理。完整主实验尚未运行或冻结预算；本文保留核心研究评价，不要求先完成异步工程或整个矩阵才做简单闭环。实施顺序只见[current_roadmap](current_roadmap.md)。旧事件合同和历史结果不作为新运行授权。

## 核心问题

GP辅助的多等效场中，LLM能否依据预测失败和路径相关分歧，在相同工具/信息/预算下更有效地组织解释检验与新路径搜索，从而降低实际飞行代价、提前避让高风险区域？

一次事件：公开点测/GP/解释证据/剩余任务/预算 → LLM选机制、修订对象和工具作业 → 数值求解/反馈 → LLM提新中间点或搜索计划 → 同一冻结预测下数值复核 → 执行短段 → 新点测检验与更新。

LLM不报可信真源坐标、不改解释权重、不读取真图或未来脚本。预测新版本不继承重复历史成绩；GP派生点不是新增独立证据。简单前方预警、GP/源能力和接受器在各核心方法间一致。

## 同状态机制检查

推断检查固定开发点测前缀、公开几何及工具总预算，比较数值反馈和LLM工具组织；先冻预测，再评价后续点测/另冻的任务区域误差及路线排序。开发尾段被用于修订后不再当独立验证；训练误差不能代替外推。

规划检查固定预测/证据、当前状态及共享账本，比较强数值搜索和LLM提出池外中间点/分配搜索。已精确评分的固定候选池以argmin为参考，不能把LLM同池选最小值说成优化。

## 闭环对照

| 方法 | 推断组织 | 路径组织 |
|---|---|---|
| N | 强数值反馈 | 强数值搜索 |
| I | LLM＋同一拟合工具 | 强数值搜索 |
| P | 强数值反馈 | LLM＋同一路径工具 |
| J | LLM＋同一拟合工具 | LLM＋同一路径工具 |
| GP参考 | 独立局部GP | 强数值搜索 |
| 延续参考 | 最近功率延续 | 强数值搜索 |

N/I/P/J具有相同GP＋源能力、传感信息、规则触发、硬约束和总预算；报告实际使用量，不为配平让数值方法无意义等待。J对N检验整体，J对P和J对I检查两环节增量；两个环节都用了LLM不自动证明协同。

主指标：到达、航程、实际暴露/T+Q、约束违例、预警提前量/漏报/误报、LLM及工具资源、接受/拒绝/回退。全到达、热图相像或预测代理降低都不是任务优化结论。闭环航迹不同造成点测不同，不能假称全程同前缀；归因另用同状态检查。

## 新运行前冻结

场景/种子/动态类型、方法/重复数、GP/源过渡、软拟合/预警参数、工具和路径候选预算、真实LLM提示及调用轮数、总资源、评价区域/指标和GIF范围。必须预测先冻后真值，不追加旧额度或读封存城市。

现有同步回调冻结物理时间，墙钟单列，不能声称已计真实延迟收益；物理时间推进若以后研究须另冻合同，不作为当前核心前置。断联执行/通信恢复不在本研究线。必要消融在核心闭环有观察后另定，不默认全量跑完。
