# 小预算离线LLM过程生成：第一轮开发试验

2026-11-11。承接[已冻结接口](offline_process_contract.md)，本文件实验前版本随新研究冻结。目标是检验LLM离线生成的**现有算子组合过程**，能否在共同信息/接受器/资源下改善完整飞行的暴露—航程权衡；不是在线LLM决策、新底层Python算子、训练或未见泛化。

## 冻结设计

只用既有dev611/613/617/619，不抽新城市或筛seed；场景原样复制。验证/测试不生成、不读取。控制器使用已验证`OfflineProcessOptimizer`，不改GP、传播、RRT*、触发或接受器。共同池/旧J搜索、全池R10+1窗口选最短路线、全程1.25D0与能量约束、2100样本/10000边总账全部相同。原始共同池工作先收费，过程与终检共享余量，不做预算外恢复或主动补测。

三个数值参考pool_only/fixed_process/adaptive_process各跑4城，共12次新飞行，不复制历史指标。初始生成2份过程，再各允许1份修订，共最多4份提交；非法响应也占名额。每份合法产物每城只跑一次，最多16次生成过程飞行；不因失败重试、不挑最好飞行。修订01只修订初稿01，02只修订初稿02，两份初始结果全冻结后才能准备修订请求。每次设计独立新会话，最长6节点JSON，不执行任意Python；只输出有限过程及简短说明。

独立设计者只读取自己public子目录的实际请求、合同、人工参考和6个历史因果状态示例；不读源码/研究文档/隐藏配置、其他方法/历史真值评价。初稿分别要求关注局部计算效率和互补几何构造，完整提示实际留档，不向模型提供人工编写的生成答案。修订可接收自身父产物、数值参考及父产物每场景任务标量/合法性错误，不给隐藏源、未来脚本、真值图或事后参考路线。共享文件系统是流程allowlist而非OS隔离，不能声称硬件隔离。所有公开请求输入先哈希，原始响应、身份/解析、接受产物、实际执行、错误和约束检查分别留证。没有API词元数据则记null，不估造。记录会话起止、生成墙钟和实际会话标识，运行时模型调用另列为0。

## 评价与选择

先冻结本阶段全部飞行，再生成相应反馈或最终评价。统一报告到达、飞行真实超参考dB·s、航程、超参考秒数、能量、决策/搜索/字段计算和墙钟；事后复算决策悬停积分，不回传运行时控制器。固定0.5s仿真决策延迟不等于实际LLM计算时延，4进程并行墙钟不能当部署时延。飞行失败保留，低积分不得奖励失败。

沿用接口预声明门槛：相对pool_only，全部到达且约束/预算/执行审计通过，总积分下降≥10%、平均航程≤125%、每场景增加≤max(1dB·s,基线10%)、基线零积分场景航程≤105%。同时完整比较固定/自适应参考，不仅选弱参考。仅通过门槛的生成产物有资格选定，依次最小化合计积分、总航程、总边数；全未通过则没有胜者，不继续扫参数或追加第5份。少量开发场景/单种子无统计优势或泛化结论，真实积分不是物理剂量，−80dBm为软参考。

入口`tools/run_offline_generation.py`，新目录`outputs/interference_offline_generation_20261111/`拒绝覆盖，回放GIF统一`replay/`。运行阶段依次prepare、references、两次submit、initial、initial_summary、两个revision request/submit、revisions、evaluate、report；模型会话由外部真实子agent提供，脚本不自动生成响应或伪造调用。运行前冻结源码、场景、合同和提示输入。实际结果在实验完成后另补，不能把未来设计写成已完成。
