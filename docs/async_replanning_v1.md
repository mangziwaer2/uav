# 及时重规划最小调度合同 v1

日期：2026-11-19。先写本合同，再实现和测试。对应主线[方法](method.md)的快慢调度，不另启旧研究分支。本轮仅接口、数值工具集成与合成时序检查，0真实LLM、0新研究飞行、0新源拟合/训练，不读旧飞行真值或封存城。

## 本轮边界

实现一个不持有仿真真场的调度器。宿主每次交给它最新公开状态、已经收到的点测前缀和冻结预测；宿主负责继续推进飞行/时间/源运动与点测。调度器在每个观测点先检查数值快路径，再轮询咨询，不等待LLM。合成宿主用折线执行和已声明读数验证时间推进；不是新的城市场景实验或实机实时证明。

数值工具在本轮是同步CPU函数，独立记录墙钟；本轮不把它的墙钟自动加到仿真物理时间。实际飞行驱动下一轮必须明确数值计算期间的推进及提交重验，不能把本接口测试称完整实时闭环。LLM回复可以在后台线程到达，或用合成传输模拟指定延迟；后者实际模型调用始终为0。

## 状态与顺序

宿主每次提供严格递增的当前时刻、最新位置、目标、剩余路线、已飞距离、总长度上限、能量、速度/功率参数，以及只用已收前缀建立的ScenarioForecast。预测的history最后一条须与当前位置/时刻/本条读数一致，禁止用未来点测或未来真值。执行state只含既有planning合同字段，delay_seconds=0，不能再假设每次咨询固定悬停0.5秒。

一次tick顺序固定：验证快照并更新廉价特征 → 必要时数值复核/修复 → 轮询旧回复/处理超时并用当前快照重验 → 按咨询门控和额度派发新请求 → 返回仅当前剩余路线。路线提交、数值复核和咨询分别记时间/版本。返回回复只在本tick可见时处理，不回填到先前时刻。

不把无LLM或等待状态等同悬停；合法当前路线可继续飞。若当前路线无效，数值层立即尝试直接到goal或有预算RRT*，不等待门控/LLM。无可行路线、复核额度耗尽且无法确认可执行路线、或全程长度/能量不允许时返回明确stop，宿主结束任务；v1没有悬停探测/免费安全等待。不会在该状态恢复旧路线或继续飞未验证边。

## 廉价判断与小模型接口

先检验完整剩余路线的几何/能量/长度，这是执行检查，不依赖调用门控。当前几何是静态公开先验；检查的边数也计任务账本。每点廉价特征为当前时刻、距上次数值复核时间、距上次咨询时间、当前功率对前3读数中位数的变化、最近3个出生前预测创新量均值、当前路线是否合法、是否到达goal、剩余能量/航程/工具和调用额度、是否有请求在途。没有从未知区域获取新真值。

规则数值复核条件：首次、当前路线不可行、功率变化≥6dB、连续3个已发预测标准化平方残差均值≥2.25，或距上次数值复核≥8s。非紧迫复核至少间隔2s；路线不可行立即处理。阈值是工程原型设置，不是设备耐受线，不调本轮阈值寻优。

咨询gate是只接上述特征的callable，输出严格bool。默认规则gate复用复核理由；可注入始终不咨询的对照或未来小模型。学习模型本轮未训练。gate异常/非法返回视为本tick不咨询并留证，不影响数值复核。达到goal不调用工具或LLM。

## 请求、派发与取消

最多1个在途请求；默认每任务4请求、最小间隔2s、TTL=12s（含等待/传输，不含免费派发宽限）。请求绑定原观测前缀、原forecast/状态、几何与当时可用采样额度，附独立consultation_id、issued_at、deadline、原路线版本及本任务已发生反馈。只给public字段，禁止传整个config/world。

派发、worker开始、回复可见、解析合法、重验、实际改航迹分别记录，不能把提交后台任务算一次真实模型调用。通用线程回调没有真实模型原件证明时actual_model_call=null；合成传输显式false。worker时钟仅为墙钟诊断，物理截止始终由宿主传入now判断，不读文件mtime。

到deadline仍允许该tick已可见的完整回复；超过deadline先拒绝回复，取消不保证中止已运行线程。不释放新请求槽来绕过旧worker：取消后传输若仍忙，阻止新派发；任务结束也取消在途请求。迟到/重复/未知ID回复仅留记录，不改变航迹或重算科研成绩。

## 最新状态重验

回复先严格用**原请求**验证request_id/action/waypoint/quotas/sampling/reason，不能直接换ID跳过原绑定。keep只确认，不恢复旧航迹。direct/via保留的是意图，不保留原起点、整条旧路径或旧评分。

via还须在当前goal方向的前半平面（点积>0）且不等于goal；当前位置已经越过的目标拒绝。它是v1保守适用范围，会拒绝部分可能有价值的回退/侧向探测，不声称完备最优。

以最新位置、当前路线、当前预测与剩余共享账本构造**新请求**；原样额度超过当前剩余则拒绝，不悄悄缩放。只搬运原合法动作/目标/额度/模式，并另记origin_id和rebased_id；交给原execute，保留其严格版本检查，不放松旧接口。

旧路线也以相同最新快照重算，候选必须全程长度/能量/几何可行且共同C=T+Q更优才提交。相同或更差保持当前路线。新路线从当前位置开始到goal，只含未飞剩余段。

## 工具预算与预测

每任务默认最多12次数值/回复工具事务，共2800采样、40000边检查。每事务最多700采样/10000边；每点执行几何复核、候选复核、捷径、RRT和失败消耗都计入任务总边账本。只按实际消耗扣账，不把一次新请求当免费新任务。预算耗尽可继续已重新确认可执行的路线；无法支付下一次必需边检查则stop。零额度合法，不能偷偷恢复默认额度。

同一tick的数值/LLM事务都读同一最新预测、不同的任务剩余额度。GP和候选预测接收点次数、时间、候选/原路线评分均记录。LLM回复后重验成本属于本任务，不能藏在池外。等效场仅维护宿主给定的既有假设，本轮不添加拟合作业或宣称联合推断收益。

## 必须通过的检查

- 无咨询时仍能数值复核/执行；有在途请求也能更新读数、推进位置和数值修复。
- 模拟等待期间源功率/观测变化，旧请求不带回旧评分；新中间点从新位置求解和比较。
- 迟到、恰好截止、非法JSON/错ID、重复/未知回复、传输异常、worker不能取消、gate异常有清楚记录。
- goal/已飞中间点/长度和能量不足/搜索及执行复核额度耗尽，均不恢复旧路线或放宽约束。
- 数值和回复事务共享任务预算，错误也计费；相同/变差路线不提交。
- 因果观测/冻结状态不可被gate或传输修改；传输不接触world、真源脚本或后验评价。

本轮完成只支持“异步接口及合成执行语义成立”，不支持规划收益、低漏触发率、真实LLM及时性或学习gate有效性。下一步另冻真实闭环合同后再运行研究飞行，不续用C1/B预算。
