## 先明确问题

overview单独展示一个候选环境，其中可能包含多个同时作用的等效基元；full_mixture展示全部替代环境按原质量混合的当前时刻功率期望。候选环境之间不是把源全部叠加。权重是当前近似模型下的相对预测证据，不是经过校准的真实概率。

不能因为overview有红色干扰团，就认定这个解释可靠，也不能为了让full_mixture出现红团而提高其权重。

现存旧C1动态日志中，`event1_refine_job0`有以下**事先发出、随后取得点测**的记录：

| 时刻/s | 源解释原预测/dBm | 后来实际点测/dBm |
|---|---:|---:|
| 21.5 | −71.209 | −72.658 |
| 22.5 | −69.469 | −73.975 |
| 23.5 | −68.267 | −76.073 |
| 24.5 | −67.679 | −72.817 |

这个解释预测干扰越来越强，而实际读数并没有持续按它预测的方式变强；23.5秒相差约7.8dB。它随后退权有实际预测误差依据。25.5秒延续质量约99.8%，不能单凭其占优就断定评分器故障。

以上只是读取现存`episode.json`中的已存值，没有重新拟合、预测、评分或查询真值。来源与哈希见[本轮阅读及缓存清单](../references/hypothesis_refinement_20261119/sources.json)。最新event_demo和timing_diagnostic目录当前缺失，不据历史数字重建它们。

## 当前实现中值得改的地方

[event_inference.py](../../src/uav_em/event_inference.py)的`operator_dictionary/fit_job`从当前位置周围80m间隔的网格、40/80/160m尺度中选基元；平移速度是四个轴向的3m/s，强度变化率是±0.5dB/s。小求解主要优化强度，并没有连续优化中心、尺度和速度。旧模型可平移后热启动，仍不等于这些参数可以自由细化。

新事件作业会产生新解释；两次事件之间，已有源解释按固定参数传播，而延续模型每次直接使用最近读数预测下一点。两者是合法的不同模型，但一步预测成绩不自动代表远处/多秒后预测能力。短步延续强，以及当前源解释确实偏差大，可能同时存在。

沿直线的总功率点测还可能无法区分航迹上方和下方的镜像解释。LLM不能从没有方向信息的输入中创造测向证据；它可以保留替代解释并安排计算检验。

## 第一轮只增加一个能力：有界局部细化

先保持现有触发规则、质量更新、规划目标和接受器，给源解释增加**围绕粗解连续细化中心/尺度、同时重估强度**的数值工具。速度及机制仍使用当前有限候选，不一次性把所有结构都改掉。边界、正尺度、总作业/残差/时间额度在运行合同中预先确定。

LLM输入是当前位置/时间、历史点测、旧解释、过去发出的预测及实际残差、已知几何、未飞路线和工具账本。GP摘要可作为同一批观测的派生信息，不能当第二个独立传感器。不给真源、未来脚本、评价图或未到达位置的真值。

LLM决定修订哪一个解释、在哪个已许可区域细化、把有限工具额度分给哪个作业，并可根据返回的失败信息改一次计划。连续坐标、尺度和强度由工具求解。LLM不直接填写可信权重，不用“这张图更容易绕行”证明它更真实。

工具返回参数、拟合/开发残差、边界或求解失败、计算开销，以及该解释对不同短程路线的预测差异。路线差异用于判断值得在哪种解释上花计算，不用于给解释增加观测证据。无法区分的上下解释分别保留，不合成一张上下都有源的地图。

这一步相对当前有限库的实际变化是：**旧解释有了被有针对性修正的能力，LLM选择修正过程，数值工具提供可检查结果。** 不是单纯再多生成几个叉。

## 怎样判断修订有效

1. 使用旧前缀内较早数据拟合，尾段作开发反馈；一旦LLM看过尾段并据此修订，该尾段就不再是独立验证集。
2. 修订结果及方案先冻结，再用后到达的真实点测计分。改过参数的模型是新版本，不继承旧版本“已经预测正确”的成绩；拟合/反馈历史不能反复记成出生后证据。
3. 保留现有逐点预测检验；另按预先规定时距保存不再更新的预测，在实际到达时评价。近一步强不等于前方几秒都可靠。同一次读数的多时距误差只作分组指标，不能重复相乘成多份独立证据。
4. 前缀检验通过后，接回原简单路径闭环，显示overview和full_mixture、解释权重、触发及实际提交。仍评价实际航时＋功率积分和可行到达，不只看地图是否像真值。

三类对照为：当前方法、数值规则调度同一细化工具、LLM调度同一工具。后两者必须共享信息、工具能力和总资源上限，保留GP/延续参考。只有LLM相对同工具数值调度的增量才可归于LLM；工具本身变强的收益另报。短程预测和实际飞行预算另行冻结，不能沿用已结束的旧调用/拟合额度。

## 后续研究主张与顺序

候选主张是：**在动态电磁环境下，LLM根据预测失败证据和路径相关分歧，组织有限预算的等效场假设修订，再支持短程重规划。** 要证明的是相同资源下更好的未来预测/路线决策及实际任务代价，尚不能声称已具创新性或性能优势。

如果新解释未来预测已变好，却仍被陈旧证据压制，再独立研究DMA式遗忘/机制重置；如果只有一步准而多秒差，再研究预测时距适配。保持每轮改动可归因，不先删除延续模型或强行增加源质量。

当前下一步是实现上述一个局部细化工具及公开失败反馈接口，随后冻结有限验证合同。没有新训练、RL、主动补测、LLM决策或飞行；本轮也未新增仿真真值查询。
