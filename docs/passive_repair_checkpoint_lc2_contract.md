# LC2：静止检查点工具闭环验收

2026-11-25。唯一检查点固定为合成夹具的第 2 秒，即 LC1 第 1 秒之后的下一个整秒。从已关闭的动作表夹具中提取保持直行的既有前缀，避免采用另一段模拟 LLM 改道带来的点测。几何沿用已冻结的 LC1 公开布局。不是 LC1 重试；不看旧改道提议、当前帧或未来的历史候选、选择、真场或评分。无新点测、无飞行推进。

- **首包**：当前 `(670,100) m`，终点 `(820,100) m`；点测 `t=0,1,2 s`，两条已发生的残差；建筑净空及已有资源。已飞 `30 m`，全程上限 `225 m = 1.25 × 180 m`，剩余 `195 m`，能量约 `99.806 Wh`。首包只登记 `R0`，不是预先枚举候选。用此前缀逐次验证两个到达预测，再建立 `t=2 s` 的冻结 `nominal` 后验并重算原路预警。
- **资源**：冻结和交付前校验分别重建同一份状态，各 3 次 GP 拟合、6 个预测点（两次到达残差和四点预警）；重复验算不进入在线评分，不提供额外数据。在线阶段不再拟合，可用 8 次几何尝试（含失败）、192 个 GP 预测点（锁窗和查询都扣除，缓存不重复扣）、360 秒模型交互总墙钟。不设模型咨询次数配额。连续建筑净空、全程航程与 90 秒到达上限、保留能量不变。比较用冻结的 6 秒参照窗和最少 0.5 秒分岔后共同支持，未知 Q 保持未知。
- **独立接收**：采用无项目数据预检过的最小模型配置，另禁用 shell、图像读取、浏览器、应用和网页搜索。每轮本地重算原始请求 SHA-256；新临时配置目录和空工作目录，不恢复会话。只有供给的公开状态和已经发生的 LC2 工具反馈。非模型消息活动、异常、无会话 ID 或回执错绑均不执行。认证留在权限受限的临时配置，不写入证据。保留逐轮精确请求、原始事件、回复、会话 ID、回执哈希和反馈。
- **强 N**：不运行配对臂。原路和共同核是本次的参照；E3 强 N 仅是背景，任何 LC2 候选或 Q 差不归因于相对强 N 的收益。正式对照另冻同工具、同信息、同约束和资源的强 N，不强制搜出相同候选。
- **停止**：首次合法 `commit`、超出几何或 GP 资源、总墙钟、接收故障或无效回执即停；合法送达后的工具参数不合法则如实反馈，不刻意制造失败。回执缺失不代选、不重开挑结果。`R0` 的明确提交仍合法。单次独占启动，验证结束不飞。
- **验收**：分别记录主动生成合法新余程、真实请求同一参照窗比较及其支持状态、自然拒绝后是否自主修正、首次显式提交的路线 ID。必须按实际顺序完成生成、比较和合法提交才报告闭环成功；保留 `R0` 与改路分开标注。没有遇拒则修正未触发；无全程 `T+Q` 收益结论。
