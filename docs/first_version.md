更新：2026-11-04。本版明确聚焦部分可观测时变电磁干扰环境中的航路优化，不再以通信服务站和通信质量为环境定义。日志版本为2；旧通信质量结果不是本版实验。传播及传感器基础详见`simulation_foundation.md`；定高2.5D和外部仿真数据协议见`environment_25d.md`；独立离线地图学习见`map_encoding.md`，尚未改变在线输入。

## 1. 执行流程

**当前主流程（2026-11-03最新确认）：** 普通建筑＋本地隐藏时变源，`configs/demo.json`和`demo_25d.json`显式选择`single_reflection`。三维自由空间衰减＋每栋楼一次等效穿透损耗＋有效单次墙／地面Fresnel反射，路径及多源在线性功率域相加；点测和含误差测向使用同一批来波路径，反射方向不一定指向源。没有调用Sionna，也不依赖外部电磁栅格、真实设备或GPU。完整公式、参数与简化边界见`simulation_foundation.md`。省略模式的旧配置保持`log_distance`，不把历史回放换成新公式重算。

可选独立电磁真值后端：`tools/generate_interference_rt.py`在隔离环境调用Sionna RT，读取`configs/optional/`中的模板／源设置，先核查自由空间接收功率，再导出静态定高多源总干扰栅格；读取导出的`simulation.json`后复用下述simulate，不加载射线引擎。此模式仅有含噪当前位置功率，不提供测向或圆盘空间扫描；源清单留在离线清单，详见`sionna_rt_environment.md`。

```text
run_experiment.py读取configs/demo.json
  → ElectromagneticWorld生成几何和隐藏时变干扰真值
  → observe在无人机位置同步接收：时间、总干扰功率及360°含噪波束功率／检测方向
  → 先检验旧源假设对本次点测的预测，再更新局部估计、支持范围、年龄及启发式误差
  → 首次／周期到期／观测偏差／首次测向发现／持续增强／越过软参考／补测结束等事件
  → build_context：局部干扰摘要、未知区域、航路、飞行器、能量与候选位置
  → 加入上轮阶段计划、区间点测／实际执行／补测／传统求解反馈及剩余预算
  → Advisor.decide提出策略及可选等效源假设 → 严格JSON解析
  → 数值层检验假设；同一观测集可反馈迭代，每轮计调用预算；刷新预测图
  → continue／replan／probe → 数值求解与几何、能量复核
  → 根据真实接受行动创建／确认／修订／暂停阶段计划，保留提议与执行的区别
  → 执行短段 → 下一轮测量
```

首个决策发生在初次测量之后，模型可直接选择补测，不保证先生成完整终点航路。默认主规划器是渐近最优快速探索随机树（Rapidly-exploring Random Tree Star，RRT*）；A星搜索（A* Search）仅作可选网格对照。补测尾段验证和数值回退使用所选或配置规划器，不偷偷调用另一算法。两者都是重新搜索，没有增量树修复或显式时间搜索状态。

### 完整流程调试入口

用户要求的`temp/debug_full_pipeline.py`直接调用正式`simulate`，没有复制算法。`simulate(..., debug_hook=None)`可选接收`debug_hook(stage, data)`观察回调，共12种阶段，覆盖初始化、接收、地图更新、复核、上下文、咨询开始／返回、源检验、求解、接受决策、飞行和终止。回调数据深拷贝、返回值忽略，不参与决策；异常原样抛出，不计为模型错误。源检验在解析之后执行，`advisor_returned`通知时可能已完成源检验，随后`source_evaluated`给出其数值结果。

默认不加载模型；`mock`只检查接线，`local`才是真实模型。调试入口额外流式保存阶段、调用前上下文／提示词、返回后的原文／实际模板输入及运行元数据；正式`decision_log.txt`仍在仿真结束后生成。输出必须为新目录，已有结果不覆盖。最终指标与回放配置是评价信息，不回灌模型。IDE／pdb断点及文件说明见`../temp/debug_full_pipeline.md`。

断点不推进仿真时间，但调试回调／人工暂停可能计入外层`advisor_seconds`等墙钟统计；调试记录不作推理或规划速度基准。实际后端生成词元和耗时另见每轮`model_runtime`，仍应避免把断点运行当成性能实验。未使用回调时没有这些调试日志开销。

## 2. 真值、观测与估计

环境可选定高2.5D：多边形楼体／庭院有逐栋基底和高度，按飞行高度及净空判断能否飞越。矩形障碍保持旧平面禁入语义；传播使用未膨胀楼体，不与飞行净空混用。新字段在旧日志中缺省时保持原行为，没有把旧通信质量日志恢复为新环境。

外部静态总接收干扰功率栅格可替代隐藏源合成真值，接收高度与频率必须一致，在线仅查询当前位置且加噪，完整栅格仅留评价配置。纯功率数据强制power_only、空fields，不生成方向或真实源列表；不能与下述合成传播后端的动态源／测向能力混称。回放数据自包含，无需原文件路径。当前外部适配是统一格式接口，不是已有第三方数据实测验证。

主JSON环境用三维自由空间距离衰减、原始棱柱等效穿透损耗及有效一次墙／地面Fresnel反射；背景、路径和多源接收贡献先以毫瓦叠加再转为dBm。旧省略模式配置保留经验对数距离基线；显式高斯源仅保留为合成对照和本项目干扰日志回放。数值越大干扰越强，例如−60 dBm强于−90 dBm。没有服务站或期望通信信号。移动、生灭由隐藏脚本驱动，不受无人机观测影响；模型不接收脚本。

每次接收当前位置总功率及24个方向波束功率，能在强干扰参考边界外发现远源角线索；含噪、带时间戳，不返回源坐标／距离，角峰数不等于源数。测向历史最多提供6个有效快照，不能把远处地图直接标成已测。没有有效源假设时地图作点测局部常值外推；有假设时用下文的源预测加残差。默认局部支持半径40m、有效年龄35s，距离／年龄增加启发式误差。此半径不是探测范围，彩色支持区不是逐格实测；无支持处始终标未知，摘要估计仍为null，误差不是校准概率。

上述默认`sensor.mode=power_bearing`假设具备测向载荷；`power_only`模式只返回本地点功率，无方向快照，不从单点功率伪造来向。方位误差默认采用稳态标准差3°、相关时间5s的一阶Gauss–Markov近似；相邻扫描不是独立定位证据。主瓣内角峰按一个波束宽度去重。主配置已用直达及一次反射路径形成波束，反射方向可能指向墙而非源；仍未模拟阵元IQ，参数未经实测标定，不能把GIF当作真实设备能力证明。论文阅读与能力分层见`uav_sensing_reading.md`。

`ObservationMonitor`补充首次可检测方向、波束增强、5s窗累计上升6dB及软参考跨越事件，仍受3s最小复核间隔约束，不控制是否更新地图。详细条件、阵列假设和缺失物理项见`simulation_foundation.md`。没有固定全向探测半径，也没有周围空间网格扫描。

环境全配置仅供传感器、事后评价和回放。模型上下文没有真实源中心、峰值、运动脚本或未观测全图真值；其中源参数只能是模型自己提出的假设。最近一次点测量、观测创新量和触发原因进入上下文，便于理解为何询问。

### 源假设、数值验证与地图更新

当前实现位于`src/uav_em/source_model.py`。LLM提出参数，固定数值工具评价观测一致性；没有自动源定位器、参数梯度优化器或生成代码执行。完整场补全是有条件的研究预测，不是对真实电磁传播的精确求解。

源协议适配公开传播模型并把测向残差加入数值检验；2026-11-03同一模式选择也用于候选源的有限路径功率和来波预测，避免拿反射观测只对真源方位评分。传感器提供本地功率与可选含误差方向，LLM提出源位置、功率、数量与运动假设；没有“真坐标加噪声后当作粗定位”的捷径。前向模型只保存公开传播参数、机高和已知建筑几何，不保存`electromagnetic.fields`或任何源真值。共享真值生成器的传播公式是明确的匹配模型假设，不是已证明的真实设备标定；后续须检验模型失配。

`source_hypothesis`是决策中的可选字段，例如下面仅为格式示意的单源假设：

```json
{"reference_seconds":30.0,"sources":[{"center_m":[400.0,300.0],"eirp_dbm":0.0,"height_m":1.5,"velocity_mps":[0.0,-0.4]}]}
```

| 字段 | 含义、单位与限制 |
|---|---|
| `reference_seconds` | 源中心坐标的参考仿真时刻s，须与本次上下文时刻一致（容差0.002s），不是出生时刻 |
| `sources` | 0至3个候选源；数组长度即假设源数，空数组表示仅背景，不代表证明不存在源 |
| `center_m` | 参考时刻的二维中心m，须在地图内；后续恒速外推可以出界 |
| `eirp_dbm` | 观测频带内等效全向辐射功率假设，−150至80dBm；不是无人机接收功率 |
| `height_m` | 相对统一地面的源高假设，0至100m；是研究搜索边界，不是已知真实源高 |
| `velocity_mps` | 恒定二维平移速度m/s，模长不超过20m/s；零向量为静态假设 |

背景由已知先验固定。每个源按`center(t)=center_m+velocity_mps*(t-reference_seconds)`移动，各源贡献与背景先转毫瓦相加，再转dBm。不是相加dBm，也不是对互不重叠圆形障碍的分类。拒绝额外字段、非有限数、布尔值充当数值、代码或源生灭脚本。

显式高斯合成基线仍可使用`center_m/sigma_m/peak_dbm/velocity_mps`四字段，尺度限制5m至地图对角线、峰值−150至0dBm；同一假设不能混用两类源，也不能在单个源中混写参数。高斯格式保留不代表旧实验已经验证新传播协议。

验证保留最近128条原始观测，重复测同一网格也保留各自时间；评分只用最近`belief.max_age_seconds`秒内的数据，默认35s。每条样本按自身时间计算预测，功率残差为`测量dBm−预测dBm`，权重为`exp(−样本年龄/窗口)`。联合目标为年龄加权功率Huber损失（转折5dB）＋`source_bearing_weight_db2×方向损失`＋`source_count_penalty_db2×源数`；分别报告功率RMSE、方向RMSE、分项损失及最差3组残差。这个目标只检验已有观测一致性，不是真实定位误差、未见点验证或安全概率。

方向预测先将所有候选源合成到无噪声波束响应，再提取可分辨角峰；不是逐个真源与观测配对。每个观测角峰与最近预测角峰计算环形角差，允许多个观测峰匹配同一预测峰，避免把峰数当源数。无预测角峰却观测到角峰时记180°不一致；观测无角峰时不加方向项，也不反推远处安全。候选预测峰门槛复用公开检测模型并下调2倍波束功率噪声标准差作启发式容差，不读取本次实际噪声。

方向残差以`sqrt((波束宽度/2)²+方位误差标准差²+方位间隔²/12)`归一化（至少1°），使用转折1的Huber损失。相关扫描先按最大公开相关时间划分年龄块，每块做年龄加权平均，再对块加权平均，避免把密集相关扫描直接相加；0相关时间按单次扫描处理。这不是校准似然、完整协方差模型或独立样本数量证明。方向项只解释已检测角峰，不因缺少角峰惩罚额外预测方向；多余源另受复杂度惩罚，假设仍可能不可辨识。

参考时刻错误、没有有效观测或功率RMSE超过默认8dB均拒绝；有可用方向证据且方向RMSE超过默认45°时记`rejected_bad_bearing`。非空新假设须比有效期内旧假设和纯背景两者的联合目标都更低；过期旧假设不阻止重新建模。空源提议可在优于旧假设时撤销旧源解释。复杂度惩罚默认每源1dB²，方向权重默认9dB²，均为研究参数，不保证正确源数。拒绝不覆盖旧假设；旧假设过期、功率失配或方向失配时停用于预测地图，方向失配状态为`suspended_bad_bearing`，保留记录供模型修订。`power_only`模式不生成或强加方向约束。

输入`source_inference`提供状态、模型自提参数、至多32条时间戳点测、当前联合拟合和最近6次新观测预测检查，不提供隐藏场；`public_propagation_model`只含公开建模参数，`source_fields`说明推荐协议。测向原始线索由`directional_sensing`提供。`source_refinement`提供轮数及上一轮数值评价。一次决策点默认最多3轮；无新飞行和新测量，每轮仍须提交完整行动，均计入总调用预算（默认24次）。省略源字段、连续两轮源假设完全相同、输出错误或任一预算耗尽即停止；仅最后一轮行动进入传统求解。省略源字段保留既有假设，不是清空；后来行动解析失败会回退，但不抹掉此前通过检验的源假设。固定0.5s决策悬停只按本次执行决策计一次，真实各轮耗时另记。提示词允许证据不足时不提交源，但须说明歧义或补测意图，不靠规则补造模型答案。

源假设激活后按当前时刻生成预测栅格，底层RRT*／A*直接使用更新后的功率代价。无观测支持的格子仍保持未知误差（默认15dB）、年龄−1和`unsupported`；预测不会增加观测支持。附近有支持处使用`当前源预测+点测值−源在该点测时空的预测`，避免把移动源的旧峰值固定在历史位置；支持半径、时效和启发式误差机制不变。假设失效则退回原局部外推。

必须分清两类误差：`innovation_db`仍是本次测量与更新前地图估计的绝对差，不是地图更新开关，每个有效测量都会更新；`source_residual_db`是把本次测量加入数据集之前，旧假设对该新点的有符号预测误差。后者与创新量共同参与原7dB／至少3s的提前咨询条件。窗口拟合误差不得冒充此新点检验结果。

`source_bearing_check`同样在把新观测加入窗口前，用旧源版本计算预测角峰及方向残差；保留源版本，不随后续修订重算成更小残差。单次新方向残差RMSE超过配置容限可触发`source_direction_mismatch`提前复核，仍受最小3s间隔约束，不是自动定位或强制绕行。窗口拟合和更新前检查在可读日志分别显示，包括任务末尾没有后续决策的观测事件。

目前只维护一个被接受的解释，不做多假设后验或置信区间，不识别源出现／消失机制。多源、不同功率／尺度或镜像位置可能解释同一批样本；仅沿单条轨迹的数据未必能区分移动与大静态场，需要LLM根据带时序证据选择现有补测、再修订。地图随当前时刻更新，但规划器仍使用当前快照，不按航路到达时刻逐点预测，不是时空避碰或未来安全保证。全域预先探测、远程圆盘扫描、全波传播和真实场标定均未实现。

## 3. 决策与模型权限

默认每10s常规复核；新测量与更新前估计的绝对差，或旧源假设的新点预测残差绝对值，达到7dB且距上次决策至少3s，可提前咨询；补测完成或到期也触发。空间中新发现的干扰与时间变化都可能导致偏差，因此不能把每次创新都解释为同一点的时间突变。无人机无法凭空发现远处未测区域的变化；周期复核不是未来预知，也不是持续安全证明。

旧源预测与新测向的方向RMSE超过默认45°也可请求复核，仍受最小间隔约束；它只意味着该假设与观测不一致，不自动判定源移动、源数变化或测向设备出错。

`none`为数值基线，`mock`为固定工程响应，`local`才是真实本地模型。决策时刻在调用预算内直接咨询，未训练门控。无效输出、预算耗尽和求解失败均记录数值回退，不自动修复模型JSON。

模型行动为继续、到终点重新规划、到候选位置补测；偏好为`balanced`、`avoid_interference`、`explore`。默认优先RRT*；兼容的采样规划器可接收最多3个区域，仍保留全局随机探索。模型不能放宽几何、能量或外部评价标准，不能生成执行代码。

### 行动协议与代码扩展位置

下例为格式示意，不是一次真实模型结果。JSON（JavaScript Object Notation，JavaScript对象表示法）解析不接受代码块或额外文字：

```json
{"action":"replan","planner":"rrt_star","profile":"avoid_interference","reason":"比较替代走廊","stage_plan":{"objective":"搜索到终点的替代航路","focus":"goal","assumption":"未知航段仍需测量","revision_condition":"新测量偏差增大或求解失败时复核"}}
```

| 字段／接口 | 当前含义与维护位置 |
|---|---|
| `action` | `continue`保留路线；`replan`向目标重新搜索；`probe`到候选位置取点测量 |
| `planner` | `rrt_star`或`astar`，不是尚未实现的增量规划器 |
| `profile` | 三种预设软代价；`explore`仅降低不确定性惩罚，不是信息增益最大化 |
| `reason` | 简短解释，不能替代数值复核 |
| `target_id` | 仅`probe`可用，必须来自本次候选，不能自行编造位置编号 |
| `regions` | 可选最多3项，每项含二维`low_m`／`high_m`及正`weight`；仅主动随机树搜索可用 |
| `stage_plan` | 可选阶段计划，字段与生命周期见下文；提示词要求模型提供，省略时不补造 |
| `source_hypothesis` | 可选等效源假设，参数／验证见第2节；不是已知真实源，不包含可执行代码 |
| `context.build_context` | 修改上下文摘要；输入估计快照，不接收真值环境 |
| `context.probe_candidates` | 修改候选补测机制；当前仅未知程度启发式，不是真实信息增益 |
| `advisor.parse_decision`／`build_prompt` | 修改严格协议及提示词，拒绝重复键、未知字段、非有限数、非法目标与区域 |
| `simulation.simulate` | 行动执行、预算、回退及日志；新行动需先在这里有真实执行与验证 |
| `decision_state.execution_feedback`／`update_stage_plan` | 将实际执行和点测摘要送回下一轮，维护阶段计划状态，不接收环境真值 |
| `planning.plan`／`PlanningProblem` | 数值搜索和代价；当前干扰为软目标 |

首轮无航路或补测结束时，`continue`会被覆盖为重规划并记录；不能把“模型请求”和“实际执行”当作同一个字段。新增行动必须同步修改解析、上下文能力列表、执行、回放和测试，不能只放开提示词。

### profile的数值含义

`profile`只是传统求解器的路径代价偏好，不是模型推理配置、阶段计划或硬安全约束。边代价为边长m乘以沿边采样的平均代价密度：

```text
1 + wI × clip((估计干扰dBm − 参考dBm) / 10, 0, 4)
  + wU × clip(估计不确定性dB / 15, 0, 2)
```

| profile | 干扰权重wI | 不确定性权重wU | 含义 |
|---|---:|---:|---|
| balanced | 2.0 | 0.4 | 当前默认折中 |
| avoid_interference | 5.0 | 0.5 | 更重视已估计的强干扰惩罚 |
| explore | 1.0 | 0.15 | 降低未知／不确定性代价，非主动信息增益优化 |

权重及归一化是研究性设定，见`planning.PROFILES`与`PlanningProblem.edge_cost`，不是经真实平台标定的风险模型。默认−80dBm只是软参考，任何profile均不能证明未观测区域安全。

### 实际模型输入及长度

本地模型接收规则／JSON协议加结构化上下文，包含：

- 无人机当前位置、终点、剩余能量及已知地图边界、几何障碍和净空m。
- 干扰估计、未知标记、不确定性dB、数据年龄s、最近当前位置点测与更新前创新量dB。
- 当前剩余航路、候选补测点及其航路关系，上一阶段计划和实际行动／求解／点测反馈。
- 调用和补测剩余预算、当前可执行行动及支持的传统规划器／代价偏好。

模型不接收隐藏源位置、功率、运动／出现脚本、未来观测或完整真值。默认41×31栅格不逐格发送；`coarse_samples`最多5×7=35项，另有南／中／北3个走廊统计、最多8个航路点和最多3个候选补测点。粗采样可能漏峰值，走廊摘要额外保留有观测支持的峰值与年龄；摘要不是完整场重建。

2026-10-27真实日志`outputs/interference_stage_plan_local_actions_seed7_20261027/episode.json`的3次输入分别2602、3065、3316词元，含规则及聊天模板。第三次上下文各字段值独立使用同一本地Qwen分词器、紧凑JSON计数：干扰摘要990、航路428、执行反馈301、补测候选250、已知几何地图88词元。独立字段计数不含其外层键和分隔符，不能直接相加还原完整输入。主要开销不是两个障碍物的坐标；本轮只统计，没有改变输入或模型权重。第三次输出不完整的原因未确定，不能归因于输入长度。

输出是受限JSON策略：行动、传统规划器、profile、短原因、可选阶段计划及等效源假设；补测只引用已提供的目标编号，RRT*可选至多3个二维采样盒。模型不输出逐格完整电磁场、整条飞行轨迹或可执行算法；数值层验证源假设、生成预测图并求解和复核路线。

在线压缩仍未接入：可优先减少重复规则／历史，按任务保留走廊连通关系、已观测峰值及其时效、未知比例、关键转折／瓶颈和候选编号，由数值层保留精确坐标及完整估计地图。不能盲目截掉强干扰证据或把未知编码为低干扰。文本中列出数值向量仍会消耗词元，不等于将地图压成少量模型可理解的隐向量。2026-11-04已加入独立随机多场景数据、小空间编解码器训练与时序任务B数据，见`map_encoding.md`；尚未实现LLM投影／对齐或RL，不改变本节的实际模型输入。编码仍为辅助实现，不扩展信息查询等新行动；研究安排只在`current_roadmap.md`维护。

### 非代码阶段计划与反馈协议

`stage_plan`只能有以下4个非空字符串，每项最多160字符；拒绝额外字段、代码字段及非法分区：

| 字段 | 含义与限制 |
|---|---|
| `objective` | 当前阶段要解决的问题，不是自动执行的多步动作列表 |
| `focus` | `goal`、`south`、`middle`或`north`；后三者只是地图摘要分区，不是推断出的源边界 |
| `assumption` | 待验证的环境认识，不能把未知描述为已知事实；解析只验证结构，不能证明文字正确 |
| `revision_condition` | 提醒模型何时重考虑的自然语言条件，不执行为程序，不新增触发器或改变复核间隔 |

每次咨询仍只接受一个`continue`／`replan`／`probe`，不是长计划自动执行器。运行时分配`stage_N`编号，并在下一轮`context.stage_plan`提供提议、来源、创建／确认时刻及`active`或`suspended`状态。`active`仅表示对应策略被接受，不代表阶段目标完成、假设证实或航路安全。

生命周期：有计划且原行动实际通过复核，首次为`created`，更换计划为`revised`，同一活动计划再次明确提交为`confirmed`。没有新计划的`continue`可记`retained_without_new_proposal`；没有计划的新重规划／补测会暂停旧计划。模型错误、预算回退、规划失败、行动覆盖或其他提议／执行不一致同样暂停旧计划，不激活被拒提议。没有旧计划则为`untracked`。历史电磁版决策可以省略计划字段，但不因此声称具有计划能力。

下一轮`context.execution_feedback`提供：

- `previous_execution`：上次原请求、实际行动、实际航路算法、后端、覆盖／错误／失败、求解摘要及计划更新类型。不会把请求算法误记成实际算法。
- `interval`：自上次决策检查点开始的仿真秒数、实际飞行距离m和实际扣除能量Wh，包含该区间已发生的决策悬停能耗；不是模型实际推理耗时。
- `point_measurements`：此区间新点测的数量、最低／最高／最新功率dBm、超参考点数和最大创新量dB；点数不是暴露秒数，不读取事后真值积分。
- `probe_event`：补测到达或到期、目标编号与当前测量；没有补测事件则为null。到达只表示拿到新信息，不表示探明整个走廊。

反馈不含完整环境、源参数或未来脚本。实际求解耗时保留在求解日志，不输入确定性反馈摘要；当前不在求解迭代中暂停咨询模型，只有原有决策点的前后反馈。`remaining_budgets`报告剩余调用数、剩余补测数及单次补测飞行预算。

`available_actions`明确本轮可执行行动：没有有效剩余航段、补测完成或到期时不提供`continue`，没有候选时不提供`probe`。提示词要求遵守；执行器仍保留原有覆盖与预算复核，模型忽略能力提示时原请求会保留，并记录实际覆盖，不伪装成模型主动重规划。

候选补测点新增所属分区、对目标直线距离的减少量m及到候选点直线段的估计摘要`approach_route`，便于模型比较探测成本与任务关系；仍是有限启发式候选，不是真实信息增益。走廊摘要增加有支持栅格的估计最大功率与平均数据年龄s，避免仅靠稀疏采样表达局部强干扰。未知量仍为null，数据年龄与外推误差不代表安全概率。

本地模型默认最大输出为1024词元，以容纳短阶段计划和最多3个源假设；此前阶段计划版本为512词元，历史试跑仍按其原预算解释。可用`--model-max-tokens`显式覆盖；最大输入仍为8000词元，超限拒绝而不静默截断。源摘要增加了输入内容，在线尚未接入地图编码器，不能宣称已减少实际LLM词元。输出不足、JSON不完整或模型不遵循协议仍记录失败，不保证小模型每次均能提供有效计划。

`LocalModelConfig.generation_seconds`默认`None`，表示不设生成墙钟时限；底层显式传入`max_time=None`。实验入口默认不启用`--model-timeout`，只有显式提供有限正数才启用相应秒数的生成软时限，0、负数、布尔值及非有限值无效。不限时仍受最大输出词元及调用预算约束，实际耗时照常记录，不保证JSON完整，也不是硬实时执行。当前先在本地观察完整响应和决策行为，后续云端4090上统一运行条件再测时延；仿真时间推进机制未改。

## 4. 代价与评价边界

路径代价为长度乘以沿边采样的平均代价密度：1加干扰超参考值惩罚及不确定性惩罚。默认干扰参考值−80 dBm仅是软参考，不是失效、损伤或禁飞阈值。几何、能量为硬约束。当前允许穿过较强干扰区，是软代价权衡，不能单纯解释为模型暂时不会避让。若要禁止进入，须独立定义硬约束及未知区域策略，不能只依靠提示词；当前穿越不代表真实平台安全。

当前为定高二维恒速折线，有三维距离损耗、简化棱柱穿透和有限一次墙／地面反射，尚无转弯动力学、多次反射／绕射、真实阵列／频谱响应、导航退化或收发协议。模型在本地研究进程运行；实际推理和求解耗时另记，仿真只计固定0.5s决策悬停，不按实际计算时间飞行。

2026-10-30默认演示改用−2／−5dBm的传播源，保留活动与运动脚本；旧35／30m及85／65m高斯场属于历史实验。默认可绕性仅由离线真值离散测试检查，测试路线不进入在线规划。更换仿真基础不是已实现避让或LLM收益，新的策略实验须重新运行。

真值只用于事后沿飞行线段积分：报告超过参考值的飞行暴露秒数、超参考值的dB·s积分。该积分不是物理吸收剂量，不含决策悬停暴露，不是事故概率，也不是控制中的隐藏安全盾。

- `metrics.json`：到达、航程、能耗、强干扰暴露、超参考积分、调用／失败／回退、补测和算法分别计数。
- 测向扩展：观测事件保存完整`directional_scan`及`sensing_warning`，帧保存可见方向历史；上下文新增`directional_sensing`。`directional_scans`／`directional_detected_scans`／`sensing_warning_reviews`不是定位正确或模型收益次数。两图叠加同一份日志测向扇区，左图方便与真源对照，但不重新用真源方位生成扇区；长度仅为显示，不是扫描范围。
