# D1的假设等效源：实际流程与功率延续问题

2026-11-20，依据D1冻结源码、原始回复和缓存说明。[带源标记回放](../outputs/interference_d1_source_markers_20261120/index.html)是独立显示副本；原飞行、预测、GIF和模型权重均未修改。本次没有新飞行、拟合、场查询或LLM决策调用。

## 图上画的是什么

左图底色来自已保存的真值网格，黑三角T1/T2是当时开启的仿真源，运动从其开启时刻起计算；这些只用于事后展示。右图底色来自当时已保存的规划器聚合预测，不重新计算。紫叉Hn/Bn是当前所选假设中的等效基元中心，按该版本已有的速度传播到当前帧；虚圆半径为高斯尺度，不是硬影响边界。

页面每次只画一个有源假设，默认选择有源模型中原始权重最高者，并可切换其他替代假设。GIF也采用这个默认规则。显示保留原权重，不对有源模型重新归一化；即使整个有源池只剩极小权重，图中仍能检查它提出了什么。Hn随原始模型ID固定，不同假设中的基元不能理解为同时存在。一个假设中若有同心不同尺度的基元，叉会重合。

源假设尚未出生时不画；GP、功率延续参考不制造源位置。基元移出地图时保留参数并注明，不把越界中心夹成地图内的假源。

右侧背景是**所有假设及GP融合后的实际规划场**，不等于所选单个源假设的场。换标记不换背景；不能据此把一个低权重解释写成规划器已采信的源定位。显示时刻的预测也可能晚于最近一次路线提交时冻结的版本。

源参数、原始权重与出生后证据本来已经进入LLM的公开请求；本次新增的是供人检查的回放标记，不是给LLM增加真值、传感信息或决策能力。

## 功率延续为何还在

需要区分两个作用。

1. **独立对照。** “最近点测延续”是便宜、无空间辨识能力的参照，用于检查复杂方法是否超过简单策略。保留对照不表示把它作为研究主线，也不需要围绕它继续追加开发飞行。
2. **当前推断池成员。** D1不仅单独跑了延续参考，还把两个延续模型放在N/I/P/J的池中。它们在所有位置使用最近一次点测，残差标准差分别为4和12dB。新源解释在后续点测上失配后，延续模型可重新获得接近全部权重，进而把支持外预测压成接近同一个值。这是当前表示/证据机制需要检查的问题，不能仅用“保留基线”解释其主导规划的合理性。

例如J在27.5秒，有源解释总权重约0.00011908（0.0119%），延续约99.9881%；约86.31%的网格不受GP支持，那里保存的聚合预测仅在约−69.37850至−69.37770dBm间变化。全图近同色的主要原因是延续占优，不是线性叠加多个局部基元必然产生均匀场。不确定性转为线性功率期望还会改变颜色，因此背景不等于简单的dBm均值。

现有证据也不能写成“本轮源假设已经优于延续”：D1中延续、N、I的真实T+Q均为145.99，P为155.24，J为161.28；单个已见开发场景不支持普遍优劣结论。点测一步预测较准也不等于远处空间外推正确。这里的缺口是没有得到有效空间决策收益，且错误解释降权后旧路线没有立即重新复核。

建议下一版保留延续作评价参照，单独检验其在规划器中的适用范围；不能再默认把一个点代表整张未观测地图。支持外应明确保留未知/替代解释，解释失配应进入有限预算内的修订和路线复核。具体如何约束远处延续、表达未知和安排触发，需独立方法合同及对照；本显示任务没有静默改权重、目标或D1算法。

## 当前假设源从输入到执行的流程

### 1. 输入与初始化

UAV每次只得到当前位置的`位置、时间、带噪总功率`。没有测向、全图扫描或真源坐标。初始化只有两个无空间结构的延续模型，权重各0.5；**不是起飞就已经有了一幅源地图**。

后续到达测量位置时先冻结旧版本的预测，再读取点测、评价旧模型、更新权重与局部GP。拟合历史不能反过来作为该新模型的出生后验证。

### 2. GP与前方预警

GP使用原始点测的近期网格缓存，最多64点，支持距离80m、年龄35秒；空间/时间尺度为60m/20秒，标准差未校准。D1沿剩余路线以15m间距、预计到达时刻查询未来10秒；有GP支持的加权dBm均值达到−78dBm即可咨询，不先要求已经找到更好的绕路。至少4条点测、重复间隔8秒、最多4次事件。

这不是−80dBm禁行规则：−80仅为Q的归一化单位，−78是开发预警线。D1首次咨询为23秒，当时本机点测已经越线；尚未证明比当前位置检测获得有效提前量。

### 3. LLM安排两轮受限拟合

一次事件先pilot安排1个作业，拟合前缀排除最近3条已见点测；工具返回这3条上的回顾误差。随后refine安排2个作业，使用当前历史拟合。尾段已对LLM可见，属于开发反馈，不是独立未来验证。N/P由数值反馈规则安排；I/J由真实LLM安排，使用相同数值工具。

每个作业只能选择：静态、平移、强度变化三类机制之一；相对朝向goal的全任务圆盘/左半/右半；最多1或2个基元。LLM选择检验内容与计算分配，**不直接生成可信源坐标或手改权重**。

J在23秒的真实操作：pilot选择全任务圆盘、静态、最多2基元；回顾尾段发现持续低估约3.4、3.4、12.0dB，refine分别检验强度变化与平移，每项最多2基元。这是两种替代解释，不是把两类机制直接叠为真世界。I同事件则先试1个静态基元，再试2基元静态和1基元强度变化。

### 4. 数值工具生成有限候选字典

中心以拟合锚点为基准按80m间隔枚举，保留地图内、160m任务圆盘内且符合所选半区的候选。pilot锚点在截掉尾段后的最后位置；refine锚点在当前位置。

| 参数 | 当前候选 |
|---|---|
| 高斯尺度 | 40、80、160m |
| 平移速度 | 东、西、南、北，3m/s |
| 强度变化率 | −0.5或+0.5dB/s |
| 单个解释容量 | 最多1或2个基元 |

这不是所有参数的自由反演，也不是对真实发射机EIRP的估计。建筑传播由仿真器计算，代理使用平滑高斯团，不直接反演反射路径。

### 5. 贪心选基元，连续拟合幅度，GP作软约束

每作业使用最近最多12条真实点测；按残差与候选响应的相关性贪心选基元，再用有界非线性最小二乘优化**峰值幅度**。中心、尺度、速度和变化率从字典选取，尚无自由连续位置细化。同机制旧模型在合法时可热启动，但pilot没有旧模型热启动。

幅度约束为−140dBm至窗口最大观测+6dB。D1另从该拟合前缀构造GP软形状约束：最近5个位置各取y方向0/±20m，最多15个合法位置，仅保留GP支持且标准差≤8dB的点，权重归一化，软项强度0.25。pilot的GP也排除尾段。它们是同一批原始点测的派生约束，新增独立证据数为0。

每事件最多3个作业、6次小求解、240次残差调用；每次小求解最多40次残差调用。保存候选字典、窗口、求解轨迹、幅度、拟合误差和消耗。拟合成功不代表未飞区域正确。

### 6. 新生版本进入假设池

成功且非空的模型先传播/重基准到事件时刻，登记新ID、出生索引、评分点数0和4dB残差标准差；同一事件全部新模型合计分得0.25权重，旧模型合计乘0.75。这是预先规定的出生分配，不是模型被证实有25%真实概率，也不是LLM选择的置信度。

### 7. 用真正后续点测检验

每次新点测前，各版本先预测该位置/时刻；测量后按高斯似然更新原始对数权重，再归一化并增加出生后评分点。旧模型按自身运动/强度规则传播，不每点偷偷重拟合。修订是新版本，不继承重复历史成绩；当前也没有完整的长期淘汰/合并机制。

因此“持续更新”并不等于“持续变准”。模型可能因新读数迅速失去权重，而延续因短时点测相近获胜；这仍不能说明延续的全图空间假设被验证。

### 8. 每个假设如何变成场、融合GP并给路线评分

同一假设内部，把−100dBm背景与各高斯基元的线性功率相加，再转dBm；不能把dBm直接相加。静态/平移/强度变化给出未来时刻的中心和峰值。

D1在每个替代世界内部按GP支持、距离、年龄、预测时距和不确定性混合GP与源预测；期望线性功率按同样权重混合。支持外GP权重为0，没有因此获得观测保证。然后按各候选路线的未来到达时刻积分各世界的Q，再按证据权重加权，与航时构成`C=T+Q`。对于这个期望型可加目标，先混合场再积分与先逐世界积分再加权等价；仅改画法不会改进路线选择。

### 9. LLM提议与共同接受器

路径LLM查看公开点测、GP局部提示、假设参数/证据和候选路线反馈，可提出保持、直达或经一个中间点的路线，使用共同采样额度。数值接受器在同一冻结预测下比较剩余路线，检查几何、能量和全程≤1.25D0；只修改未飞部分。执行短段后新点测继续检验旧版本。

J首次提出经[550,285]，冻结预测评分下降15.92并被接受，但整次任务真实T+Q反而更高。J在27.5秒有源权重已经极低，仍到31.5秒才再次咨询。这说明拟合—证据—路线复核之间的衔接仍有缺口，不能把“提出了源、工具接受了路线”写成优化收益。

## 哪些已做，哪些还没有

已经做的是：有限源字典、幅度拟合、GP软约束、两轮LLM工具组织、新版本出生后检验、联合路线评分、实际飞行及事后真实代价评价。

尚未做的是：自由连续源位置/尺度/速度细化、可靠方向消歧、失配后的即时预算内修订与路线复核，以及把支持外未知和全图延续分开处理的新机制。还没有证明LLM优于共享数值工具，也没有证明GP辅助拟合改善预测。下一步优先按[唯一待办](current_roadmap.md)冻结小型机制对照，检验解释初始化、失配修订及路线复核；不是继续美化均匀热图或调权重制造绕行。
