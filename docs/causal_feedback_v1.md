# 因果可靠性反馈与在线算子选择：小规模合同检查

2026-11-11。实验前冻结设计。承接风险状态诊断，保持任务效用、GP和v3接受器不变；不把更换预测器、私有评分或真值方向当作LLM能力。

## 具体方法

把三件事明确分开：任务最终评价是航时+连续归一化真实功率；在线接受器是相同公式作用于当前GP及声明未知先验的代理C；证据可靠性是历史上GP**尚未读到该次测量之前**的预测与后来实际收到读数的差异。可靠性反馈仅解释证据，不改C、权重、GP或支持范围。

对每条已收到点测，先用更早测量重建GP，在该点/该时刻记录预测均值、标准差和支持标记，随后才更新该读数。公开最近8条预序贯检验及支持样本的偏差/RMSE；不把这些稀少相关样本称为校准置信度。另对35s内航迹的中心化位置及位置—时间设计矩阵做SVD，报告秩与第二/第一奇异值比。近共线航迹不能可靠识别侧向分布，匀速单航迹可能混淆空间/时间变化；不得据此伪造源或正确绕行侧。数值计算使用已有点测，不是新增传感器或源推断。

LLM只组合已有六个搜索profile（global_uniform/global_focus/local_pad1/local_pad3/via_left_near/via_right_near）或停止。数值库按当前剩余路线计算区段、采样区和中间点，模型不生成浮点参数或任意代码。每状态最多2次选择、每次搜索额度≤700，原共同池700已记入2100样本/10000边总账，几何/能量/固定初始全程1.25D0约束不变。同一状态/相同profile/相同当前路线/相同搜索腿使用配对种子，与其他调用数量无关。重复profile只反馈重复、计一次选择、不再搜索。无主动补测/GP选择/树复用。

每次反馈给出候选和当前最佳的C、航时、支持功率、未知先验代价、航程差及实际采样/边消耗，连同几何/搜索失败原因。保留所有当前可行候选，接受器全池选择最低C；模型只能选择计算过程，不能绕过接受器。历史残差大不自动证明加搜索有效，也不能作为硬暴露阈值。

## 固定研究额度与比较

只复制前一诊断的4个历史因果快照和**原v3共同池**，不引入其扩大诊断池、事后参考、真值评价或其他方法反馈。共同开始前按80m间距插入共线锚点以明确局部区段，几何和分数不变，不修复已飞过的路径。复用池的原实际资源记录，所有方法从同一记录开始且共同支付一次终检；它是从已付成本池继续的配对快照实验，不是重新运行共同池或新的完整飞行。

四方法×四状态共16配对：pool_only直接停止；fixed_two按local_pad3→global_focus；numeric_feedback同样先local_pad3，当前C改善≥1%则停止，否则global_focus；llm_feedback在六profile/停止中在线选择，最多2次。1%仅为预声明数值停止规则，不是安全线。数值策略与LLM得到相同字段，LLM额外调用和墙钟另记；不声称相同CPU或部署实时性。

最多4个新独立决策会话、合计8个真实响应，不是第5份离线生成。各会话只读本任务public合同/control/requests/自己的responses及同任务记忆，fork-none；不读源码、根交接文档、场景、seed、episode、前一诊断或其他实验。不向模型透露已知失败、事后正确侧或真值。共享文件系统是流程allowlist而非OS隔离。实际请求、原始响应、解析接受、执行、错误/回退分别留存，无法取得的词元记null，不伪造内部推理或token。

无效/超时响应计实际咨询错误，保留当前路线并结束该过程，不用额外搜索恢复制造收益。固定两次调用的规则同时限制数值和模型选择。缺失任务不补挑替代快照，不追加模型/搜索/飞行预算。旧4份离线产物及24飞行额度不动；不生成/读取验证或测试。

## 评价与结论边界

全部16结果、候选和最终路线先冻结，才做事后真值评价。原GP评分C差、长度/功率分项、共同初态/额度/种子/失败/咨询/墙钟分别核验。固定路线从快照后0.5s出发、≤0.25s积分，无新点测/后续重规划、不计悬停；全程和前10s报告真实航时/Q/联合分及超参考积分。每状态GIF展示四种实际所选路线，**不画真值最优参考**。

主描述比较llm_feedback相对numeric_feedback：同状态当前C、未来真实T+Q和搜索资源是否共同改善；任何退步逐状态保留，格式合法或少搜索不自动算路径收益。四个相关开发快照无泛化/显著性结论，固定路线不是在线飞行控制器。即便模型选路更好，也不证明新增可靠性字段的因果贡献（尚未做去字段消融）。若更少搜索却真实更差，则明确报告权衡，不声称推理优化成立。

入口`tools/run_causal_feedback.py`；新输出`outputs/interference_causal_feedback_20261111`拒绝覆盖。prepare冻结输入/合同/源码；numeric运行12数值任务；model逐任务等待独立agent；freeze冻结全部16结果；evaluate/report才评价与生成集中replay。结果运行后追加，不覆盖实验前版本。

## 实际结果

16项配对已完成，4独立fork-none会话/7真实响应，0模型/数值错误及额外恢复，529测试通过；所有结果先冻结后评价。35个前一研究共有源码不变，四方法初始公开状态逐项相同。LLM在20/25.5/35.5s均local_pad1→stop，45.5s直接stop。25.5s真实T+Q101.573→101.165（−0.401%）、超参考91.778→90.914dB·s（−0.941%），其余路线不变。四求解总边39748→34110（−14.18%），主要来自最后状态避免无收益搜索；模型等待/咨询92.9—217.4s/任务，包含调度/文件等待，不是纯forward时延且无总时延优势。0.125s事后积分复核仍保留该微小改善，未据此重选路线。

没有宏观绕行或LLM必要性证据：前三状态同一操作可由固定过程解释，尚缺固定local_pad1对照及去可靠性字段消融；不能事后添加第17项。每次700的额度上限与实际边消耗使首轮几乎用尽边账，反馈存在但后续修订空间很小。可靠性预计算未纳入选择函数墙钟，不据局部计时作完整CPU比较。
