# 当前点功率仿真环境

更新：2026-11-09。当前主配置为`configs/local_power.json`。研究使用合成城市建筑、隐藏动态发射源和机载点功率测量，不依赖外部数据、GPU或传播引擎；不做预先稀疏测量、完整地图补全、地图编码或训练。实际信息字段见[信息合同](llm_information_contract.md)，后续方法见[研究设计](research_method_20261109.md)。

## 几何、源与总干扰功率

已知地图边界、建筑轮廓/楼高、起终点；UAV定高30m，垂直净空5m。低于飞行高度且满足净空的楼体可被飞越，但仍可影响传播。自定位和机载计算假设可用，未模拟GNSS压制、接收机失效或低层飞行控制。

场景可使用显式配置，也可由`src/uav_em/scenarios.py`生成：有界矩形建筑不重叠，检查起终点连通及任务时长；随机源不在建筑内部，完整移动线段避开楼体并保持在地图内。生成器当前源高1.5m、频带内EIRP在−12至10dBm采样，源可静止或以0.2至1.5m/s移动，并有开关时间。具体实验可以预先固定构造场景而不使用随机生成器，必须在协议中区分。

源位置、数目、功率、运动/开关脚本仅供仿真器，不提供给在线策略。生成分布、材料与损耗参数是研究设定，不是实测城市/发射机统计。多源在同一所选监测频带内贡献总干扰功率，当前主频为2.4GHz。

对位置x、时刻t，主`single_reflection`传播先计算活动源的直达/等效穿楼项：

```text
lambda = c / f
 d = max(sqrt(horizontal_distance² + (uav_height - source_height)²), reference_distance)
P_direct_dBm = EIRP_dBm - 20 log10(4 pi d / lambda) - L_buildings_dB
```

其中穿过每栋楼计一次等效损耗，不是每米材料损耗。有限一次墙/地面反射使用有效反射点、总路径长度及Fresnel功率系数；反射点必须位于有限表面，两段路径不能穿楼：

```text
P_reflected_mW = 10^(EIRP_dBm / 10)
                  * (lambda / (4 pi total_path_length))² * Fresnel_power_coefficient
I_dBm(x,t) = 10 log10(10^(background_dBm / 10) + sum(all_received_path_powers_mW))
```

例如2.4GHz、0dBm EIRP、100m三维距离，仅自由空间直达约−80.05dBm；距离加倍下降约6.02dB，两份等功率贡献叠加提高约3.01dB。dBm不能直接相加。

图中的较强干扰区域是`I(x,t) >= reference_dBm`的等值区域；不是先画一个影响圆，也没有圈外信号截止。建筑、反射、多源叠加和源活动会改变等值区域形状。−80dBm仅软代价参考，不是设备失效线或绝对禁入区；dB·s不是物理剂量。

当前是有限几何传播近似，不包含多次反射、绕射、相干快衰落或全波求解。它支持受控仿真研究，不代表已经实测标定或可直接迁移任意平台。

## UAV测到什么

`power_only`在飞行当前位置返回位置、时间戳和带噪总干扰功率；当前噪声尺度1dB。不返回源方位、距离、数目或位置，不直接扫描周围空间圆盘。取消测向是当前研究的简化选择，不是在论证全方位射频接收不可实现。

假设载荷能够取得指定频带的外部干扰功率，例如监测资源内没有不可分离的期望信号，或上游已提供功率估计；本项目未实现信号分类、期望信号分离或接收机响应。设备论文支持沿航迹采集有限射频读数的能力抽象，1dB等数值仍是仿真参数。

初始无电磁地图，只从起点点测开始；没有外部初始点测、预飞行巡测或免费真值采样。后续信息必须来自已经执行的飞行与点测。恒速折线、能耗系数和固定0.5s决策悬停是研究近似；计算墙钟时间不推进仿真，悬停不补测，当前暴露指标仅积分飞行段，不能据此宣称实时性能或完整任务暴露保证。

## 如何外推周围功率

局部时空GP只使用已经收到的点测。空间为Matérn-3/2核，时间为指数核，当前参数如下：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| 背景均值 | −100dBm | 未知区域的计算先验，不是低功率观测 |
| 先验标准差 | 15dB | 模型设定，未校准 |
| 测量噪声尺度 | 1dB | GP观测噪声假设 |
| 空间/时间尺度 | 60m / 20s | 功率相关性假设，不是设备测量范围 |
| 有效点数上限 | 64 | 近期已访问网格的最新有效点测 |
| 最大数据年龄 | 35s | 超期点测不参与当前拟合 |
| 局部支持范围 | 80m | 仅在距有效点测不超过该值处公开估计 |

邻近支持区外的公开功率为`null`。实际本轮请求另保留最多8条近期点测摘要和兼容`source_inference`字段中最多32条历史点测，以及基于已收读数的公开背景模型残差；这不是新传感信息，也未启用源定位。模型另接收预测标准差、最近训练点年龄/距离和局部训练点数；这些是估计依据，不是安全概率或独立信息量。GP公式与字段来源见[信息合同](llm_information_contract.md)。

一个点不能唯一确定周围分布；沿一条线也不能保证发现墙后强源。普通核可能跨建筑过度平滑，且预测标准差未经实测校准。时间衰减让旧估计回归背景，不代表收到了新低功率读数或源已经关闭；沿航迹功率变化可能同时包含空间梯度、时间变化与误差。
