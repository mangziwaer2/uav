# E3：新首分岔与分岔证据，单场开发配对

- 固定一个未使用的开发场景 43821，两个局部移动干扰区，同一地图和测量噪声初始化；一条强 N、一条 LLM，不筛种子、不重试、不读取封存场。按既定 `1.25D0`、净空、能量、时间和终点约束运行。只做仿真，咨询期间仿真暂停。
- 起飞共用几何最短合法余程。此后只用普通位置点测、2.5D 建筑、承诺余程和已用资源。先验证已冻结的一步预测，再用新点更新同一 GP。预警沿用 `-80 dBm` 和原 1–4 秒探针；在一次连续预警里，首次有合格分岔或出现新的合格首目标时复核。合格指未来 6 秒、双方仍在飞的同时位置差最大值达到地图一个网格（20 m）；按共同前缀后的首目标坐标去重，不按路线编号。低于预警线重置当次预警记忆，未知风险不拒绝复核。
- 两臂共享原菜单及删点重连；本轮不开放图外动作。每次以 0.5 秒中点为基础，同时按路线窗内结束及分岔时刻切片；仅在所有仍在飞的候选有支持时积分，续行未知不补值，已到终点不是未知。强 N 在全菜单最小化完整余程 `T + Q_common_tail`，按完整 T 和编号破同分。给 LLM 同一菜单、时空几何、原始点测与已发生残差，逐路线列完整 T、分岔后同掩膜的线性功率期望差和逐点上尾差、共同秒数及未定价时长；不传 N 的答案、其他臂、隐源、种子、真值或未来点。每次新独立会话，必须选一个合法 ID，合法回复直接执行，保留原始回执。
- 公共资源：至多 61 次普通点/GP 拟合、90 秒仿真、每帧至多一次复核、每次最多 126 条合法路线、70M GP 逻辑查询。没有整程复核或咨询配额，没有累计等待配额，墙钟只记录；回执最多 800 B，输入最多 64 KB。回复无法获得或无效、资源/时间耗尽时照实结束该臂并保留合法进展，禁止数值代选或重新试飞。无合法新增分岔不等于任务失败。
- 两臂冻结后才以真场沿各自实际到达时间积分并用共用双图发布。录像保留轨迹、每次菜单和实际选择、分岔证据、点测、GP 支持与未知。报告合规到达、实际 `T`、`Q`、`T+Q`、差值、操作者及模型用时；若未到达不把部分代价当完整成绩。此单场将触发和证据包一起改变，只验证组合能工作，不能分离两项贡献或声称普遍、实时收益。
