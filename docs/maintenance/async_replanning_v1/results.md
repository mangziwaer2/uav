# 异步调度最小接口：实现与检查

2026-11-19，按[先冻结的合同](../../async_replanning_v1.md)完成。当前主线新增`async_replanning.py`和`async_transport.py`，不恢复旧实验，不生成新的研究飞行或GIF。

## 完成内容

调度器只接宿主提供的当前公开状态和因果冻结预测，每次先检查数值执行条件，再轮询咨询回复，最后决定是否派发。数值复核不依赖咨询门控；默认规则gate可以被未来小模型替换，目前没有学习权重。

LLM路径回复先验证原请求ID和额度，再将合法意图绑定新请求，从当前位置重建候选、按最新预测与整程约束评分。保持原execute的状态检查，不直接执行原航迹。keep只确认；已越过的中间点、迟到、非法或不改善的方案均不能覆盖当前航迹。

执行边复核、数值候选、返回候选与RRT*共享任务账本。默认2800采样、40000边、12次工具事务、4次咨询，允许显式零额度。通道最多1个在途请求；后台线程超时无法取消时仍占通道，直到实际结束。后台提交/完成不等于真实模型调用；通用回调无模型回执时记录null，合成传输记录false。

## 可直接读的四个例子

完整逐步输入、输出和日志在[synthetic_traces.json](synthetic_traces.json)。读数和预测均为预先声明的合成夹具，不是隐藏城市场查询，也不是LLM生成结果。

| 例子 | 发生了什么 | 检查结果 |
|---|---|---|
| 延迟回复后重建 | t=0在[20,60]请求；t=1到[30,60]，t=2到[40,60]才收到中间点 | 用t=2新位置/预测重新评分，合法且改善后提交；未恢复原起点 |
| 等待时出现观测变化 | 请求要10s才返回；t=4的声明读数从−85变为−70dBm | 数值层当场复核，旧请求仍在途，未等待或另堆请求 |
| 超时无法取消 | TTL12s，t=13未收到回复且worker不可取消 | 关闭请求但保持通道忙；t=20旧回复被忽略，之后才允许新请求 |
| 中间点已飞过 | t=0提议[30,60]，t=2返回时UAV已到[40,60] | 拒绝旧中间点，保持当前剩余路线 |

这里的“改善”仅是指定合成预测下的接受器结果，不是实际LLM或真实环境收益。
