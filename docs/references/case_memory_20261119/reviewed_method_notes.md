# 飞行经验检索与工具选择：定向阅读

2026-11-19。实际通过arXiv API检索，按题名核对后下载三篇全文HTML。搜索中出现的同名天体物理/视频论文未作为依据。下载全文不等于完整精读；未复现算法，未启动经验采集、记忆提取LLM、训练或飞行。

- **ExpeL: LLM Agents Are Experiential Learners**，arXiv:2308.10144v3。选读§3任务条件、§4.1–4.3。原文经验阶段允许同任务失败后重试；成功/失败配对与跨任务成功列表用于经验提取，支持ADD/EDIT/UPVOTE/DOWNVOTE。推理阶段检索相似成功轨迹作为few-shot，并加入经验总结。原文采用Faiss、kNN及文本embedding，目标环境在该文中设为确定性环境。借鉴“经验＋可修改建议”，不把其成功轨迹检索等同于在噪声动态电磁场中恢复隐藏源，也不复制无限重试或源真值。

- **Voyager: An Open-Ended Embodied Agent with Large Language Models**，arXiv:2305.16291v2。选读§2.2–2.3。技能库的键是程序描述embedding，值为程序；任务建议及环境反馈形成检索上下文，返回相关技能；执行错误和环境反馈用于修订。借鉴已检验的受限数值算子及适用条件库，不允许任意Python、不启动自动无限探索，Minecraft反馈也不是无线功率测量的替代物。

- **Reflexion: Language Agents with Verbal Reinforcement Learning**，arXiv:2303.11366v4。选读引言、§3框架/算法与Actor、Evaluator、Self-Reflection段。把任务评价总结为反思记忆，辅助后续尝试，不依赖更新LLM参数。原文也指出依赖反馈或自评价质量、没有成功保证。本项目若借鉴，只让实际已发生反馈支持经验，LLM反思不能新增物理证据；不据题名启动主体RL或微调。

对本任务更合适的案例单元是：公开前缀→源解释及失败类型→工具修订计划→冻结预测→后来实际点测及执行后果。经验应帮助选择受检验的修正过程；“上次左绕成功”不能直接证明当前应左绕，达到goal也不证明源解释正确。城市分组及检索公开字段必须先定，测试城与未来信息不进入检索。
