# 原文能借什么，以及当前项目怎样落地

日期：2026-11-20。以下中文迁移方案是本项目的判断，论文没有验证本项目的动态电磁推断或UAV收益。仅选读方法与局限段，不声称完成全文系统综述。精确范围和哈希见[reading_manifest.json](reading_manifest.json)。

## 优先采用的控制流程

最匹配的设计是：**LLM选任务相关的待检验问题和受限修改→共享数值工具拟合/检查→返回具体批评→LLM最多作少量修订→共同接受器决策**。这比把LLM仅放在已经精确评分的候选池上选最小值，更有清楚的可检验增量。增量仍必须与有同等工具能力、信息和预算的强数值组织比较。

首先补齐推断组织前的公开任务上下文。除近期点测、GP支持和源证据外，应有当前未飞路线、可行竞争路线、未来到达时段、每个世界下的路线代价差分解，以及几何/能量/航程约束摘要。LLM若只看局部拟合历史，无法可靠地挑选会改变路径决策的检验。这些摘要必须由公开预测生成；不得给隐藏源、未来读数或事后评价。

建议在后续独立合同中定义以下闭环；本轮没有实施或运行它：

1. 固定公开快照、活动世界/版本、现有权重、未飞路线和总资源上限。共同机制先覆盖当前最优路线与公开代价最接近的可行竞争路线，即使二者下一短段相同，也检查后段风险/到达时段。最低覆盖规则由N/I共享，不能留给模型任意跳过。
2. LLM提交可执行的受限作业：`路线对/世界/到达时段/许可参数族或区域/共享工具/期望区分的问题/预算`，或明确keep。可以提出“联合幅度与变化率是否可在相容集合内改变这两条路线排序”，不直接宣称某个源真实或调整可信权重。
3. 数值工具在许可域内拟合，报告真实历史点测的绝对相容性、GP软项、约束、路线差值及求解状态。若做差值极值搜索，要区分找到一个相容见证、局部搜索未找到、以及有证明的全域界；有限求解的失败不能当成“排序不会翻转”。共享工具质量先独立核验。
4. 批评器返回具体、带出处的反馈，例如“该修订降低拟合误差，但在所检时段的两条路线差值不变；最近竞争路线仍未覆盖”，或“候选违反许可半域”。保留作业/参数/版本与预算账本，避免重复同一无信息作业。可优先返回一个最影响任务的具体批评，未处理项仍在账本中可见。
5. 仅在冻结预测树上允许小规模替代分支和回溯：一轮反馈后有限修订，保留原可行方案作为退出选项。分支宽度/深度和终止条件必须事前冻结；不要照搬几十个rollout。工具评价发生在模型内，既不是新点测，也不能撤销真实飞行。
6. 共同接受器统一检查整路`T+Q`、几何、能量和全程`1.25D0`。若假设修订被接受，要按新版本出生规则记录；改进同一历史拟合不继承出生后成绩。之后若获授权进入新飞行，新点测先检验旧冻结预测再更新。

这里“批评器通过”只表示：在已建模型、公开观测和冻结假设下通过了所检查的条件。几何检查可以有明确的模型内有效性；未知电磁场的真实性、未飞区预测准确和真实任务收益都没有由此被认证。

## 1. LLM-Modulo：把提案与可信检查分工

原文：Kambhampati et al., **Position: LLMs Can't Plan, But Can Help Planning in LLM-Modulo Frameworks**, ICML/PMLR 235, 2024；所存arXiv `2402.01817v3`，2024-06-12。选读§3–3.2（PDF页5–7，对应文本460–630行）。[摘要/版本](https://arxiv.org/abs/2402.01817v3)，[PDF](https://arxiv.org/pdf/2402.01817v3)。

可核对锚点：原文把核心称作“Generate-Test-Critique loop”，区分hard critics与soft critics；可以从二元拒绝、一个错误、全部错误到建设性替代建议。Meta Controller汇总反馈并决定下一轮提示；也讨论重规划从已有方案开始。可靠性依赖外部检查器的soundness，完备性依赖生成器覆盖候选的能力。

能借：LLM提出机制/许可域/路径搜索方向，由已测试的数值工具处理连续参数和检查，具体反馈后有限修订；反馈聚合器可以是普通确定性代码，不必增加另一个LLM角色。保留可行原方案和明确退出条件。

局限：这是立场/框架论文，其对自验证能力的广泛判断不是本项目已验证的命题。其soundness讨论要求对应检查器本身可靠；我们不能把一个由局部点测建立、支持外未校准的等效场称为真实风险验证器。框架也不自动保证比强数值求解更省资源或找到更优路径。

## 2. Compound LLM-Modulo实证：具体批评有价值，堆历史不必然有价值

原文：Gundawar et al., **Robust Planning with Compound LLM Architectures: An LLM-Modulo Approach**, arXiv `2411.14484v1`，2024-11-20。[原文/版本](https://arxiv.org/abs/2411.14484v1)。选读§3/§3.1–3.3、§5.1、§5.4、§7（PDF页2–4、7–9的选段）。本轮按所存预印本引用，不额外宣称已核对后续发表版本。

能借：先格式检查，再约束检查，Meta Controller汇总反馈，成功或预算耗尽停止；主配置最多10轮。§5.4在Calendar Scheduling/GPT-4o-mini上比较具体全部批评、第一条批评和二元失败反馈：二元反馈较差，第一条与全部批评相近。这支持优先返回有信息的具体批评，同时避免提示塞满细节；不是对所有任务通用的最优规则。

同时要保留负证据：§5.1中，附带全部历次批评并未总显著提升效果，历史数量增加后的收益也会饱和。不能以“更长反思/多几轮”作为已经有用的设计。

局限：四类任务是给定完整信息的日程/旅行约束问题；论文利用基准自带评价代码作critics。这与我们不完整、动态且只能沿航迹点测的场明显不同；不能把其“每份输出正确”的条件性表述迁移为UAV安全或风险预测保证。其10轮限制、§5修改只用一个模型等成本局限在§7明确说明。

## 3. ReAct：把工具返回变成下一步决策上下文

原文：Yao et al., **ReAct: Synergizing Reasoning and Acting in Language Models**, ICLR 2023；缓存`2210.03629v3`，2023-03-10。[原文](https://arxiv.org/abs/2210.03629v3)。本轮重读缓存§2、§3.2/3.3部分、§4的受控Act比较/失败讨论及§6；未重新下载。

能借：受限行动API、实际工具返回、后续修订构成闭环。每步日志应分别保存提议、调用、数值观察和提交结果；理由不能替代观察。最小迁移不要求自由长篇思维文本，可以用短的“目标/待区分问题/动作”结构说明作业。

应做的归因：同上下文、工具和预算下比较一次性LLM作业与收到数值反馈后有限修订；再与强数值调度比较。保留keep、重复作业检测和预算退出。

局限：原文QA/事实核查、ALFWorld/WebShop的结果不等于UAV路径优化效果；其§3.3已观察到反复生成旧动作、非信息性检索使模型难恢复。在本项目重复拟合或重复剖面也可能耗预算。论文外部工具能取回数据库事实，而我们的预测工具不创造独立电磁观测。

## 4. LATS：可借反馈树，不能借真实环境可回退或自评分可信

原文：Zhou et al., **Language Agent Tree Search Unifies Reasoning, Acting, and Planning in Language Models**, ICML 2024；所存`2310.04406v3`，2024-06-06。[原文](https://arxiv.org/abs/2310.04406v3)。选读§3.2、§4.1/4.2、§6局限和附录B的选段。

能借：节点保存输入、动作与观察，分支经工具反馈后再选择；失败节点保留反馈，之后回溯到早先可行节点。可用于“同一公开冻结快照下，先检验哪个机制/路线对”的计算过程。每个分支末尾由同一数值工具报告代价与约束。

不能直接借：LATS§4.2的中间值混合LLM自评分与self-consistency；多次生成一致不等于真实源可信，不能当场假设权重或路径风险概率。本文还明确依赖环境可回退，并承认比ReAct/Reflexion高的计算成本。真实UAV不能撤回已飞路段或免费获得另一条航迹的读数；允许复制的只有冻结预测/工具状态。原文例子`n=5,k=50`等配置不能照搬成当前预算。

## 5. ToT：分解与回溯有用，评价器换成共享数值反馈

原文：Yao et al., **Tree of Thoughts: Deliberate Problem Solving with Large Language Models**, NeurIPS 2023；所存`2305.10601v2`，2023-12-03。[原文](https://arxiv.org/abs/2305.10601v2)。选读§3、§6局限、附录B.3成本分析。

能借：把问题分解、候选生成、状态评价与搜索算法分开；小的beam或深度优先回溯可以保留不同解释，而不陷入一次提案。项目中的一个“thought step”应对应一个可检验作业，例如选路线对/选择可辨识参数族/选择许可搜索域，不应只是增加一段自然语言。

局限：原文以语言模型评估中间状态，不是可靠连续场风险估计器；本项目应由共享数值评价器给分。原文只测试Game of 24、写作和小填字三类任务，且附录B.3明确指出可能要5–100倍生成token。预算内应先试很浅的树，至少与相同总资源的数值搜索和独立采样比较，不能把计算量增加的收益归LLM组织。

## 补充：SayPlan的分层、ReEvo的比较反馈

**SayPlan**（Rana et al., CoRL/PMLR229, 2023，[出版社页](https://proceedings.mlr.press/v229/rana23a.html)）本轮仅核对旧缓存的出版社摘要。摘要明确包含：检索任务相关子图、经典路径规划降低LLM规划跨度、scene-graph simulator反馈迭代重规划。可作“高层选任务相关问题、低层经典工具执行”的出处，但未取得版本一致全文，不据此描述未读算法细节。这里没有已知语义源图；建筑图与等效场图也不能混为已知真实干扰源。

**ReEvo**（Ye et al., *ReEvo: Large Language Models as Hyper-Heuristics with Reflective Evolution*, [所存arXiv原文](https://arxiv.org/html/2402.01145)）本轮重读既存§3/4与§7选段。其直接比较两份启发式的相对表现再生成修改，可启发把反馈写成“这项修改改善了哪条路线差值、另一项为何没有”。但原文个体是代码片段，目标是在实例数据集上演化归纳启发式；它属于离线算法搜索，不是当前飞行中的局部源推断。本项目只借比较反馈，不恢复离线算子演化、训练或RAG，也不引用其COP表现当UAV收益。

## 共享工具与公平参考

| 需求 | LLM组织可做 | 强数值参考必须同样具备 |
|---|---|---|
| 任务上下文 | 读竞争路线、世界差异、到达时段与预算 | 同一快照与完整摘要 |
| 最低覆盖 | 完成规定覆盖后再选剩余检验 | 相同最近竞争路线覆盖规则 |
| 受限假设修订 | 选参数族/许可域/检验顺序 | 同样的联合幅度/动态/几何工具、约束和版本规则 |
| 路径搜索 | 提许可中间点/走廊/搜索顺序 | 同样表达空间、几何检查与路线评价器 |
| 工具反馈 | 根据具体失败/差值作有限修订 | 数值敏感度/尚未覆盖差值驱动的重分配与多起点机会 |
| 退出 | keep或提交共同检查器 | 相同可行原方案与硬停止上限 |

N不能只做残差最大的源或固定轮询，然后把更强工具留给LLM。可用公开的近竞争代价差、跨世界差值分歧、时间窗和已覆盖账本组织强数值优先级；具体公式须新合同冻结，不能以旧真值选择。随机/轮询可作为附加消融，不能替代主要强N。

工具调用、求解次数、参数/路线评价次数、模型调用/token、墙钟应分别报告；模型调用的成本不能凭空折算为免费数值预算。至少冻结共享工具上限并完整报告LLM额外开销；若主张计算效率，另需同时间/总成本的对照。保留项目既定N/I/P/J归因，把假设组织、路径组织和共享工具本身的改善分开。

仅同状态的“找到相容排序见证/候选变了/接受率提高/冻结预测代价下降”都是机制诊断，不能代替出生后预测或完整任务收益。真正收益最终仍需独立合同下的新预测冻结、新点测检验和有限闭环任务评价；本轮没有开展这些运行。

## 当前不建议做

- 直接让LLM报源坐标、可信权重或路径真实风险，或把多次自评分一致当证据。
- 没有竞争路线和任务时间窗就反复做源几何细化，再以接受率作为主结论。
- 把未覆盖的近竞争路线省略后称“排序已稳定”，或把有限局部搜索未找到反例当全局证书。
- 把LATS的可回退环境、额外工具观察或大量rollout带入真实飞行；给决策会话未来点测/事后评价。
- 用更大的搜索、更多LLM调用、权重调整制造绕路，或先恢复ReEvo/FunSearch式离线算子生成、训练/RAG。
- 直接把他域基准成功率、可行性保证或摘要中的机器人演示写成当前UAV方法有效。
