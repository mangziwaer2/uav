## 1. 唯一主比较

在三个预登记的独立开发场景，各运行一次 **强 N** 和一次 **LLM**，最多三对。共用地图、动作域、估计器、预测证据、触发与点测规则；只有选路权不同。两臂从同一初态独立起跑，随后只能用各自已发生的点测，不强配咨询时刻。每对用同一冻结噪声初始化、按测量序号取噪声，不跨臂交换测量。不中途扩样、补跑、挑种子或因结果不好改合同。

| 开发场景 ID | 噪声初始化 ID | 设计目标，不是先验贴标 |
|---|---|---|
| `43901` | `43902` | 局部移动干扰；候选菜单里可能已有绕行。 |
| `43911` | `43912` | 局部移动干扰；同一通道内偏移可能需要图外引导点才能表达。 |
| `43921` | `43922` | 更困难的动态覆盖；可能找不到划算的绕行，也可能存在方向歧义。 |

冻结前单独锁定这三场的生成器、输入字节和哈希，不预飞或按真场筛选。表中的设计目标允许不实现；事后分层不符照报。不是三个独立随机抽样层，不能从中估计普遍收益。若以后加入互斥等效世界，每个世界独立出结果，不把不同真场合并为一条轨迹。封存的验证和测试场不读取、不生成、不替换。

## 2. 公共观测、触发和动作域

- **公开几何与硬约束。** 复用 E3 的公开 2.5D 建筑和 20 m 显示网格；起终点为 `(40,300)` 与 `(760,300)` m。定高 30 m、速度 15 m/s，水平及垂直净空各 5 m；总航程上限为原始 `1.25D0 = 900 m`，初始电量 100 Wh、保留 15 Wh、巡航功率 350 W。完整余程要连续无碰撞、在剩余时间与电量内到终点；不以网格点无碰撞代替边核验。
- **因果顺序。** 共用最短合法余程起飞，随后每推进至多 1 s 在当前位置获得一个带噪总功率点。先用新点验证上一步冻结的预测，再拟合固定先验时空 GP（空间 Matérn-3/2 尺度 60 m、指数时间尺度 20 s、先验均值 `-90 dBm`、先验及测量标准差 15/1 dB）。至少 10% 先验方差缩减为支持；40 m、35 s 只标近测/延伸，不当作安全距离。无全图最近值续接、补测或新传感。
- **触发。** 在已承诺余程上检查未来 1–4 s 支持内均值，达到 `-80 dBm` 为预警。原菜单和合法重连共同寻找未来 6 s 内双方仍在飞时最大分离至少 20 m 的首分岔。持续预警时只为未比较过的合格首目标开启新选择；记录分岔两侧，原路变备选不重复触发。未预警重新武装；未知或风险证据不足不否决已触发的机会。无机会沿当前合法承诺推进，单记状态，不计作 LLM 决策。
- **动作。** 原菜单保留 3 个公共门 `x={240,400,620}` 与 5 个横向格点 `y={180,240,300,360,420}` 的既有枚举、已承诺余程和可行删首点路线。新增算子枚举所有锚点对：直连或经 `(320,210)`、`(320,390)`、`(490,210)`、`(490,390)` m 中一个图外点重连。坐标仅由公开几何选定，两臂相同；只改未飞子段，原终点不变。合并连续重复顶点、拒绝非连续重复顶点；两组都只使用这个有限域，不声称连续空间最优。相同折线只查一次 GP，保留所有原路线与锚点来源；不得因某一个来源缺分岔后支持而丢弃整个几何动作。

## 3. 同一张决策表，两个控制器

**证据对等已在合成夹具接通。** [共同动作表](../../src/uav_em/passive_repair_actions.py)在选路前定价重连，强 N 从全表选，LLM 收到同表并返回其中的动作 ID。前版只给 LLM 原菜单定价而事后为重连补价，不用于 E4。真实接收端容量尚未验收。

1. 在同一检查点先用原菜单锁定 6 s 窗的共同支持时间片：0.5 s 中点积分，按原候选到达时刻切片。对完整合法重连按自己的到达时钟复核这些片，不缩窗。风险列用归一化线性功率的期望和沿用的逐点上尾均值；不是整路安全概率。仍在飞但缺冻结片支持、无基准证据，或相对生成原路分岔后可比不足 **0.5 s** 的重连，保留合法性，风险列为 `null`。分岔后可比只统计从分岔时刻起的完整冻结片，不为凑时长重新切片。已到终点不算未知或继续暴露。
2. 两控制器消费同一张**先冻结、再选择**的无损动作表。每行含稳定 ID、原路线与 `(left,right,via)` 或等价原路线 ID、完整余程 T、相对原路 `ΔT`、分岔时刻和分岔后可比秒数、期望及上尾 `Q` / `ΔQ`、窗内未知、支持但未比、窗外秒数与状态；几何可用索引无损重建。同一折线多来源共用风险采样，各来源分岔证据分列。分岔后差值和整段共同窗差值不得混用。原表不按预测前几名截断，也不暴露 N 的答案。
3. **强 N** 穷举全表，在有风险证据时最小化 `T + Q_common_tail`，同分依次按完整 T、稳定 ID。只有原菜单完全无共同风险证据时，才按完整 T 在整个合法域排序，并标 `time_only`。有证据时 N 不给未定价动作编造 `Q`。额外离线从同表报告期望 `Q` 排序是否会复现 LLM 的选择；不增加试飞，不用此排序取代主 N。若差异只复现为简单的期望/上尾切换，结论限于策略差异，不声称 LLM 独有能力。
4. **LLM** 收完全相同的动作表及当前臂过去和当前点测、已发生预测残差、建筑和机载余量。每次合格机会交付至一个新会话，必须明确选择一个动作 ID 和理由；保留原路是有效选择。合法但未定价的动作仍可选，不被 N 或 GP 否决。冻结公共 allowlist 和确定的序列化；排除场景 ID、隐源、真场、未来读数、事后标签、其他臂、会话历史和 N 排名。受信接收端验实收字节哈希；原始请求/回执、收发哈希、会话 ID 与结合当前状态后的落地路线全部留存。

## 4. 资源与停止

每臂至多 61 次普通点测和对应 GP 拟合、模拟时间 90 s、7000 万 GP 逻辑点查询。查询统计含预警、共用动作表及下一步冻结预测；绘图网格和关闭后的真值审计分账。不限制 LLM 咨询次数或累计等待；每次合格机会都交付，不沿用旧三次上限，不设代理配额。咨询时仿真暂停，墙钟和报文字节数照实记录，不作实时性主张。冻结前须用合成最坏包验证选定接收端可以无损读取整表；容量不够须先改编码或接收方式，不在线裁掉候选或跳过 LLM。

按有限域计算：原菜单上界是 `5³ + 1 + 1 = 127`（已用夹具核对）；原门路线至多 5 顶点，承诺路线与删首点路线至多 9、8 顶点。按全锚点与四个引导点计，每帧尝试重连不超过 6055 次。原菜单冻结片不超过 139 个；每条动作只在同一批冻结中点查询一次，即使每帧都复核也少于 5300 万点查询。完整原候选和合法重连不得截断。当前按规范化顶点序列去重，纯共线插点不触发新分岔；不宣称所有连续空间等价的路线已合并。

到达合规终点优先判 `arrived`。无合法起飞或余程、时间/点测/计算用尽、交付失败或无有效回执，停止该臂并保留已飞合法前缀；另一臂照常完成，不重试、不让 N 补飞。完整公共决策表若无法生成，不送不完整表做主比较；已作出的合法承诺不撤销，推进前仍须能冻结下一步预测，否则记录「已承诺、未推进」。共用流程在理论上界内不应因公共额度截断咨询；发生时按资源异常报告。

## 5. 怎样判断效果和失败

- **主结果。** 逐场列两臂的合规到达、实际 T、沿各自实际航迹和到达时钟的真值 `Q = ∫10^((dBm+80)/10)dt` 与 `T+Q`。仅两臂合规到达时列 `Δ = (T+Q)_LLM - (T+Q)_N`，负值是该场开发改善。积分沿折线以不超过 0.25 s 的中点步长；报告 T、Q 分项。不把未到达的部分低成本算赢，不把未飞路线或共享算子的收益算给 LLM。三场全报，包括同轨、反向结果和不完整配对，不作显著性检验或总体结论。
- **归因顺序。** 双臂关闭后在各自检查点锁定已飞前缀和剩余资源。以原菜单、动作扩展集、独立有界几何参考三个嵌套域分别核对同到达时钟的真实余程。参考再加 40 m 网格内任意一个或两个不同引导点（有序，直接连至终点，仍核同一组硬约束）；用全批合法路线，不只找一条事后最优。以承诺路为参照，低暴露候选须同时 `Q` 至少少 20%、真实余程 `T+Q` 至少少 1。分别记录：`参考域内未找到`、`原菜单缺路但扩展补到`、`共享算子域仍缺路`、`有路但未触发/旧分岔去重`、`有路但线上缺证据或排序分歧`、`同表有明确证据却另选`。最后一项要求共同支持达到门槛且期望与上尾两种 `T+Q` 代理同向；不以事后真值倒推模型当时应该知道。不能执行、无回执等管线故障另列，不归因为选错。
- **审计帧和回放。** 每个实际复核帧及首个持续预警但无新分岔的帧做归因；无预警的臂另审计共同起点，明示未覆盖帧。记录复核前承诺路、点测前缀、GP 版本、完整冻结表、触发状态、选择及第一步真实推进。每场保存一份可直接打开的双图：左真场和已飞轨迹仅供事后，右图只显示当时 GP、未知区、原候选、被替换段、引导点、补全余程和实际推进。主表和原始回执与回放互链。

归因口径：参考域从地图原点按 40 m 枚举，参考域包含原菜单和共享动作；一个或两个有序引导点的完整余程全批核验，不把未找到读作连续空间不可绕。检查未选动作时，除了相对承诺路达到上述门槛，还要求它比实际选择的整条未飞余程少至少 1 单位真实 `T+Q`。线上证据仅从记录的冻结区间和两条动作的报价判断；未触发帧只重建几何，不补做 GP 计价。无有效回执和已承诺未推进单列；余程不计入配对成绩。

## 6. 冻结前验收

1. **证据对等。** 用合成点测验两控制器消费同一规范表，同一折线一次采样；覆盖多来源、完全缺证据的 `time_only`、保留可执行但 `null` 的动作、不会缩窗，以及 127 条边界和最坏包容量。模型与会话运行配置、接口和提示另锁定，不能将事后材料转交给决策者。
2. **执行对等。** 在模拟回执中验证实际途经点、缺回执保留前缀、连续四次以上机会无旧调用上限、两臂无内部备选覆盖 LLM 选择。复核前后状态及未触发原因都能由日志复盘；用双图核对到达与停止两种路径。
3. **版本冻结。** 上述验收完成后登记算法、公共字段与模式、三场的独立输入哈希、资源计数、停止条件、裁决模型配置、评估输出目录和跨臂隔离检查。保存源码、依赖与冻结清单的哈希；任一实质修改须新版本和独立成绩，不能继承 E1–E3。另获新运行授权后才能生成正式轨迹或打开真实 LLM 会话。
