# RP2：当前会话子 agent 与数值工具调度的三场配对试飞

2026-11-26。用户明确授权跳过当前网关模型校准，使用当前会话新开的子 agent 开始下一轮实验并交付飞行回放。本合同独立于已关闭的 RP1、EP1 和 MC1，不复用其预算、场景、输入或成绩。

## 本轮问题与边界

在三个预抽新随机开发场中，两臂共用已通过静止验收的正预测残差预警、持续预警复核规则，以及路线前向进展、回撤与剩余绕行余量反馈。只改变工具调度者，比较合法到达和实际全程 `T+Q`。预警与新增反馈的公共收益不归为LLM贡献。本轮是开发机制验证，不是正式论文检验或模型性价比比较。等效源预测和完整余程优化仍为独立研究线，本轮继续使用原GP和现有路径修复算子。

一次冻结三个新开发场：单侧建筑、横跨直线的单楼、错列双楼各一场。严格沿用RP1已经声明的随机场生成分布，以系统随机抽取全新独立64位布局与噪声种子，高位设1。只生成一次，不先飞、不查询点测或真场筛选、不按LLM结果换场。封存验证和测试场不读取、不生成。首场运行前封存合同、所有活动Python/JS/HTML源码、相关测试、依赖、提示、环境、三场公开配置、场景指纹和资源清单。

两臂各建立同参数、同噪声种子的独立环境；每次普通点测间隔1秒，按各自实际位置和时钟取得带1dB高斯噪声的总功率。没有主动补测、额外传感或未来信息。原世界/真场仅由仿真器持有；两臂关闭后才进行事后真场积分与双图发布。

## 共用方法、强N与资源

两臂均使用 `fly_repair` 工具模式、nominal GP、原始全程 `1.25D0`、同建筑净空、时间和能量约束。先冻结预测，新普通点验证旧预测后再更新。6秒参照锁窗、分岔后共同支持至少0.5秒、未知Q留空；支持不等于安全。目标保持实际全程航时加归一化线性功率暴露，模型等待另外记录。

共同预警固定为：原前视1–4秒的受支持均值达到−80dBm，或当前读数至少−85dBm且支持内旧预测正残差 `z≥1`；相对上次复核读数或前视峰值恶化3dB、新正残差或新前视越线时允许重开；连续两个普通点缓解后重新布防。精确状态转移以冻结 `RepairAlert` 为准。两臂工具均给出首段和前2秒在原起终点轴上的进展、回撤投影/航段距离，以及提交后可用航程余量；这些是优化反馈，不是新增硬约束。

强N保留原完整 `run_numerical_tools`：枚举全部可见角点、8个局部偏移及适用的最短可见余程引导点，逐一生成，并对新路与R0同窗比较，以 `ΔT+Δ上尾Q` 最小化，R0完全无报价时只按航时；R0参与排序。不得删减数值菜单、放宽LLM硬约束或用错误复核拒绝合法提议。LLM可在相同连续参数域生成 `via`/`offset`，指定比较对象，并明确提交任何已核验合法余程，包括原路或缺报价路线。只有提交后才推进，没有数值代选。

每场每臂最多61次点测和拟合，90秒仿真时限。令公开可见图角点数为C、`G=C+8+1`，每臂整程几何尝试上限 `59G`，决策GP查询点上限 `300+59×13×(G+1)`，显示查询单列 `61×网格节点数`。失败和重复尝试均计费。两臂拥有相同总资源和信息规则，实际用量分别报告。本次完整N是预登记对照，尚未加入自适应数值调度消融，不能据三场结果宣称优于所有数值策略。

## 当前会话子agent与公开输入

采用内置 `multi_agent_v1.spawn_agent`，每次工具回执新建会话，`fork_context=false`，不设置模型覆盖，推理档位显式为 `medium`。根据当前会话运行期元数据，预期模型ID为 `gpt-6.1-sol`；每次均从实际原始会话核验，发生不同则停止整批。运行期ID是平台报告，不当作已核验的上游权重快照。此调用渠道不经过额度不足的旧网关，不能与MC1的请求费用或身份混为同一渠道。

唯一科学输入是 `RepairToolWorkspace._request` 当时生成的精确UTF-8公开包，加冻结隔离指令。白名单包含工具说明、请求/检查点绑定、公开建筑和边界、当前位置及资源、截至当时的点测和已发生残差/预警、已注册合法余程、已发生的比较、最近反馈和剩余工具预算。不含布局与噪声种子、隐藏源、未来读数、真场、事后图、另一臂轨迹/成绩、父会话讨论或旧实验结果。默认维护指令与系统上下文另列为平台注入，不当作科学数据；要求决策子agent不打开其中引用的文件。

子agent只返回一行绑定请求ID的JSON工具提议，不使用任何外围工具、文件、网络或其他会话，不发评论。父agent只原样传递公开包与最终原始回答，不编辑参数或理由、不建议方向、不根据数值成绩代选。同步标准输入/输出只是该轮人工工具接力；不实现后台服务、恢复网关或跨会话记忆。原始请求、隔离消息、spawn/wait回执、子agent原始会话、完整回答、实际模型/推理元数据、usage（如有）、哈希及工具反馈均留证。

每次模型接力至多180秒，每个LLM臂累计至多1200秒，三场合计至多3600秒，包含父agent接力开销。没有额外调用轮数配额，已发生调用全部记账。模型费用无账单时未知，不从token量推断便宜；推理token若含在输出里不重复计费。

## 停止与交付

合法到达、工具/点测/拟合资源耗尽、无合法余程、时限、缺失或无效回执按执行器关闭该臂，保留实际前缀，不重试、不补场、不换场。单个超时或坏JSON不由N代选，其他预定场继续。公共输入或会话历史泄漏、外围工具活动、身份/档位错绑、冻结或数值记账失效则停止整批，保留已完成合法进展。
