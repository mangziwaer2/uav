- 逐点触发：沿用当前6dB累计上升且当前仍上升，冷却2秒，最多4事件；无初始/到期咨询，不在看到结果后调参或追加。每秒左右机载点测，最长100仿真秒。没有主动补测。四事件上限可能耗尽，此限制须显示。
