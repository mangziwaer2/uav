# D2-M3：源几何细化改变了行动，但没有降低任务总代价

2026-11-20，按用户“继续”和[独立合同](source_geometry_pilot_v1.md)完成2条数值飞行、3个固定历史状态诊断和2条新GIF。0次新决策LLM调用；没有全图功率延续。两组均到达，几何细化降低真实暴露7.02%，但增加航程16.53%，T+Q增加1.13%。本轮没有获得任务收益，不升级默认方法，也不把经典最小二乘称为LLM创新。预算结束，不追加飞行/求解/真值查询。

直接看[两组回放](../outputs/interference_source_geometry_d2_m3_20261120/replay/index.html)；[几何细化GIF](../outputs/interference_source_geometry_d2_m3_20261120/replay/geometry_bounded.gif)、[幅度对照GIF](../outputs/interference_source_geometry_d2_m3_20261120/replay/geometry_amplitude.gif)。左图是真值与当时活动真源，仅用于评价；右图为实际规划聚合场，紫叉标出一个互斥等效源解释，虚圆为其高斯尺度。源集合相对权重不代表绝对可信。

## 对照与操作

两组沿用M1的源池、75/25出生、GP软形状约束、8秒初始化、集体失配及前方支持内预警、每事件50个侧向候选、最多4事件，以及原T+Q/整路航程/能量约束。M2硬替换关闭。

每个原字典拟合后都增加一次同预算细化：`geometry_amplitude`只重拟合幅度，`geometry_bounded`还允许中心每轴±40米、尺度除以/乘以√2并限于[20,240]米。源数、速度和强度变化率固定；中心仍须符合原任务圆域/左右区域。仅在收敛、合法且目标改善超过1e-8时接受，否则保留原拟合，不重试。pilot最近3点同时从拟合和先导GP中留出；新参数完成细化/重基准后出生，出生后评分从0开始。

对照12次额外幅度求解均未达到接受改善量，观测、动作及已发预测与M1侧向版缓存一致。几何组接受10/12次；20.5秒的2次未通过，分别存在未收敛及区域不合法，原拟合保留。这里的局部优化不保证真实源位置可辨识。

## 实际动作从哪里改变

25秒之前的25条观测相同。8/20.5秒两组均选择同一路线，分别为`lattice_15`/`lattice_13`。25秒时仍是相同公开历史及当前位置，对照选择`lattice_14`，几何组选择`lattice_46`；下一15米端点相差0.339米，25.5–26.5秒出现首段真实动作差异。此后观测分开，33.5秒分别选择`lattice_02`/`lattice_48`，后者形成更大的南侧绕行。完整缓存见[配对诊断](../outputs/interference_source_geometry_d2_m3_20261120/reports/paired_cached_diagnosis.json)。

25秒时，幅度对照对`lattice_14`/`lattice_46`评分为125.97/126.67；几何组对同两条几何路线评分为151.10/150.09，预测排序确实翻转。33.5秒已不是同状态，不能继续作配对因果比较；几何组在自身冻结预测下将`lattice_02`/`lattice_48`评为274.50/254.63，于是执行更大的绕行。共同接受器的评分算术与argmin均通过缓存核验，但整程真实收益仍为负。
