# D2-M3：固定预算的源中心/尺度局部细化

2026-11-20，用户要求继续。M0/M1/M2已结束，不追加原预算。本轮独立冻结合同、源码、输入和预算，仅开发种子109，0次新决策LLM调用，目标是补足后续数值/LLM共享的几何细化工具并检验其任务作用，不把最小二乘优化称为LLM创新。

## 唯一处理差异

仍采用无全图功率延续的源池、原75/25出生规则（M2硬替换关闭）、原GP与软形状约束、8秒初始化/集体失配触发、4事件、50侧向路径候选、T+Q与整路约束。

每个原字典拟合作业结束后，增加一次有界局部细化调用；两方法都获得相同调用上限。

- `geometry_amplitude`：只再优化已有基元的幅度，中心、尺度、速度和强度变化率固定。
- `geometry_bounded`：同时优化已有基元的幅度、中心x/y和log尺度；不增加源数，速度与强度变化率固定。

中心各轴最多移动40米（原80米网格半步），裁剪至公开地图边界；尺度限制在原值除以/乘以sqrt(2)，再限于[20,240]米。优化结果仍须符合拟合时的160米任务圆域及原左/右区域条件，否则拒绝并保留原拟合。幅度沿用原拟合[-140,已测最大值+6]dBm边界。使用解析导数，不用有限差分扩张残差调用。

优化目标与原拟合完全相同：最多12条真实点测的平均平方残差，加原强度0.25的GP软形状项。pilot细化只使用其训练前缀，最近3条留出尾点仍只作事后诊断，不进入该次拟合/GP；refine阶段可用当轮已有全部前缀。新模型出生前先完成细化和重基准，出生后得分仍为0。只有优化收敛、参数合法且目标至少改善1e-8，才提交细化；否则保留原版本。失败不重试，不增加另一次隐藏求解。

这不是完整自由多源反演，也不保证中心可辨识。沿一条航迹的点测可能对应多个同样拟合但前方预测不同的几何解释；训练目标下降不等于未来准确或路径更优。

## 任务作用与验收

除训练/GP目标及未来预序误差、航程/T/Q/T+Q外，还从已经保存的逐假设候选评分计算每个假设各自的最优可行路线及下一15米执行端点，记录假设间是否导致不同真实可行动作。该诊断不增加场查询，不改变本轮决策，也不把互斥源叠加。候选编号变化而执行前缀相同时照实报告。

两方法共享总资源能力，实际使用量分别报告。幅度重复细化应通常不改变已收敛参考，但不预设其结果与M1字节相同；对比实际模型、预测和动作。三个同状态结果无论正负全部报告，反事实整路收益与闭环收益分开。若仅降低拟合残差，没有未来或任务收益，不能称源定位/LLM创新已成功。

解析导数、边界/失败保留、pilot信息隔离及共享预算的组件测试先通过，再冻结运行。C1/D1/M0/M1/M2原件字节不变；完整性检查仍保留21个既有缺失。预算结束不追加。后续LLM应在独立会话中依据公开行动分歧组织有限细化调用，与同工具数值参考比较；根会话已见真值，不作为盲决策LLM。
