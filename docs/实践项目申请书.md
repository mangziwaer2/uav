# 项目（课题）实践申请书

## 一、项目（课题）名称

**动态电磁环境下基于大语言模型辅助决策的无人机动态重规划研究**

## 二、实践开始时间与结束时间

- **实践开始时间：** 2026.10.15。
- **实践结束时间：** 2027.9.15。
- **时间说明：** 实践区间为11个月，核心任务按约10个月工作量组织，预留机动时间用于阶段调整、补充实验及成果整理。

## 三、项目（课题）简介

本课题面向部分可观测动态电磁环境中的无人机航路规划，研究大语言模型（Large Language Model，LLM）辅助动态重规划的方法。以未知电磁干扰的局部探查与航路优化为主要对象，构建多源叠加、可随时间变化的合成环境。无人机依据有限先验生成初始航路，飞行中获得局部测量，更新干扰分布估计、数据时效与不确定性；在周期复核或观测显著偏离原估计时咨询模型。重点研究信息不完整、环境变化和计算资源受限时的可验证策略决策，不以通信服务站覆盖优化为研究核心。

系统通过结构化上下文与可解释区域摘要，提供当前航路、局部干扰估计、未知区域、飞行能力、剩余能量及历史反馈。模型提出继续执行、调整路线、主动补充探测等策略，并为兼容规划器建议候选采样区域和代价偏好。数值算子生成航路，独立程序复核几何、能量和执行预算；探测围绕当前任务的信息需求开展，而非默认绘制完整环境地图，并计入额外时间、能耗和计算成本。

底层以渐近最优快速探索随机树算法（Rapidly-exploring Random Tree Star，RRT*）为主，A星搜索算法（A* Search）作为离散搜索对照；按实验需要扩展轻量动态A星搜索算法（D* Lite；D*表示Dynamic A*）及快速重规划采样算法RRTX（原论文全称：RRTX: Asymptotically Optimal Single-Query Sampling-Based Motion Planning with Quick Replanning），研究状态复用与算法协同。完整环境真值仅用于评价和展示，不向决策泄露未观测信息。

课题围绕任务相关信息获取、有限上下文下的区域筛选与可解释编码、策略条件化采样搜索开展对照及消融。基础方法稳定后，可在任务前提明确时探索受限中断穿越、局部启发式代码生成和选择性调用；模型决策评价与基于可验证反馈的调优不依赖这些扩展成功。拟形成可重放仿真系统、实验场景、决策数据、评价协议及研究报告，明确合成干扰模型与真实平台效应之间的适用边界。

## 四、实践计划

实践按“电磁干扰环境与执行闭环—模型策略与任务相关探测—采样引导及按需算法扩展—对照验证—模型评价与成果整理”的路线推进。受限中断穿越、局部代码生成和选择性调用作为条件具备时的探索分支，不阻断主体交付或模型评价。核心任务按约十个月工作量分阶段组织，在实践区间内保留机动，不对每个月作固定功能承诺。各阶段可交叠，依据运行结果、模型能力与实验条件调整。初期在决策时刻直接咨询大语言模型（Large Language Model，LLM），不以训练门控或搭建高保真传播系统作为前置条件。

### 第一阶段：电磁环境与基础重规划闭环

建立统一的环境、飞行器配置、能量记账、航路评价和可视化接口。构建已知几何障碍与未知电磁干扰区域并存的合成地图，支持多个干扰源叠加、移动及出现和消失。明确当前点测量、附近估计和完整真值的区别，记录观测位置、更新时间、支持范围及启发式不确定性。以渐近最优快速探索随机树算法（Rapidly-exploring Random Tree Star，RRT*）形成初始规划、飞行测量、地图更新和重新规划闭环，A星搜索算法（A* Search）仅作为可选对照。采用同步双图展示完整环境和无人机局部认知，检查几何、能量及预算约束，确保未知真值不进入决策。

### 第二阶段：模型辅助策略与任务相关探测

将局部干扰估计、未知区域、数据时效、当前航路、预计到达时间、剩余能量及执行反馈编码为可追溯上下文。结合固定周期和观测偏差触发咨询，由模型提出继续、重规划或局部补测策略。探测目标由任务需求约束，限制额外时间和能量，防止无效绕行或盲目全域建图。建立严格输出协议、候选合法性检查、独立数值复核和失败回退，保存原始输出及最终执行行动。模型异常或预算不足时由本地机制处理，避免将校验与回退产生的成功全部归因于模型。

### 第三阶段：区域筛选、上下文编码与采样引导

研究有限上下文和计算预算下的任务条件化区域筛选，保留与目标、当前航路及探测需求有关的局部干扰、信息时效和不确定性，减少无关地图内容干扰。先采用可解释摘要，再根据证据评估是否需要训练编码模型。模型提出少量候选采样区域及权重，引导兼容随机树规划器的搜索，并保留必要全局探索。可视化建议区域、实际航路和反馈，比较无引导、规则引导及模型引导的路径发现效率与执行效果。按需求再适配轻量动态A星搜索算法（D* Lite；D*表示Dynamic A*）或快速重规划采样算法RRTX（原论文全称：RRTX: Asymptotically Optimal Single-Query Sampling-Based Motion Planning with Quick Replanning），明确重新搜索与增量修复的差异，不为增加工具数量盲目扩充算法。

### 第四阶段：动态场景对照与创新假设验证

在不同地图、干扰分布、变化机制、观测噪声和计算预算下开展闭环对照。固定可用信息与任务约束，对比无模型、规则和真实模型策略，消融主动补测、区域摘要、代价偏好及采样引导，分别记录到达、航程、能耗、强干扰暴露、探测成本、调用量、回退率和总计算开销。按地图和变化机制划分独立场景，避免只展示成功案例。解释合成干扰参考值的软代价含义，不将其直接当作真实无人机失效概率或安全阈值。

基础闭环稳定后，可另设场景研究受限中断穿越，先明确通信中断与导航、控制失效的差别，以及预设指令、地图可用性、恢复和撤退条件，再讨论探测是否足以支持穿越决策。局部代码生成先研究采样评分或探测排序等短启发式，不直接生成完整飞控；数据充分且调用成本确为瓶颈时，再探索多层感知机（Multilayer Perceptron，MLP）门控。上述分支分别验证，不以全部成功作为核心研究完成的前提。

### 第五阶段：后期模型评测、可选调优与成果整理

在基础场景、接口和日志稳定后，即可独立整理约束理解、未知信息识别、策略可执行性、探测价值及反馈修正等模型评价任务，无须等待代码生成或门控取得效果，也不以中断穿越研究完成为前提。区分原始模型输出、独立程序校验与数值回退的贡献，评价失败案例和推理成本。数据与计算条件允许时，使用可验证轨迹或候选偏好开展调优，并检验未见场景中的收益；即使可选扩展或调优未取得提升，也保留可复现评价与失败分析作为成果。最后整理代码、配置、复现实验、决策日志、失败分析和研究结论，形成实践报告与论文材料，并保留必要补充实验时间。
