# EP1 · 等效场假设选择的静止预测实验

**2026-11-26 冻结研究设计，尚未运行。** EP1 使用新建的合成点测表。问题是：看到同一段观测和过往预测误差后，真实 LLM 从三个等效场结构中选两个，能否提高随后六个普通点的预测质量？实验单位是一整张独立点测表。每张表只有一个选择时刻，结果衡量受限词表内的结构选择。论文最终的任务指标仍是合法到达和实际全程 `T+Q`，将在单独的决策实验中评价。

## 方法与文献依据

| 文献 | EP1 采用的方法 |
|---|---|
| Li、Fox 与 Goodman，*Automated Statistical Model Discovery with Language Models*，ICML 2024 | BoxLM 让语言模型提出并批评统计模型。EP1 将可检验的自由度缩小为依据点测和逐点预测误差选择结构，共用数值工具估参。[原文](https://proceedings.mlr.press/v235/li24v.html) |
| Yao 等，*Using Stacking to Average Bayesian Predictive Distributions*，2018 | 借鉴用样本外预测密度评价模型组合的思想。我们用时间上靠后的四点比较组合，最终版本重新以等权出生，随后用新点更新。原文的留一法和 stacking 权重估计均未移植。[原文](https://doi.org/10.1214/17-BA1091) |
| Gneiting 与 Raftery，*Strictly Proper Scoring Rules, Prediction, and Estimation*，2007 | 采用对数评分比较观测发生前已给出的完整分布，同时报告 dB 误差与预测区间覆盖率，检查均值偏差和过度自信。[原文](https://doi.org/10.1198/016214506000001437) |

三个候选为固定空间分布 `static`、空间分布随时间平移 `translate`、分量强度随时间变化 `strength_change`。同一结构内最多两个非负分量，在 mW 域与背景相加后转为 dBm。每个结构单独用有界最小二乘拟合已发生的总功率点测。沿用 `fit_job` 的字典、贪心增添分量、幅度边界和合法进展保留规则。这是有限字典内的近似拟合。背景沿用 −100 dBm，每个假设的点测预测分布沿用 `Normal(μ_h, 4²)`，4 dB 是冻结的建模假设，覆盖率由留出点评价。[拟合器](../src/uav_em/event_inference.py) · [线性功率叠加](../src/uav_em/equivalent_field.py)

## 样本与盲法

24 张合成表分四层，每层六张。每张表有 `t=0,…,17` 共 18 次读数。直接生成采样坐标和标量读数，不调用飞行器、传播仿真器或场景配置。坐标和观测噪声的分布在四层相同。无建筑，公开边界为 `[0,400]² m`。本轮检验的是位置与时间变化相混淆时的结构选择，楼宇遮挡和真实设备留待外部验证。

- 对 `layer=0,…,3`、`rep=0,…,5`，用 ASCII 串 `EP1-v1/{layer}/{rep}/{tag}` 的 SHA-256 前 8 字节（大端无符号）初始化 NumPy `Generator(PCG64(seed))`。`tag` 分为 `samples`、`signal`、`noise`、`alias`、`order`。按 `order` 的种子由小到大执行，同值按 `(layer,rep)`。四层全部保留，无效病例也保留。
- `samples` 流依次抽 `x0~U[70,130)`、`y0~U[140,220)`、`c` 从 `[6,9,12]` 等概率取一项、`b` 从 `[-6,0,6]` 等概率取一项。第 `t` 行坐标为 `(x0+10t, y0+b·max(0,t−c))`。位置由固定表给出，模型没有选点动作。
- `signal` 流依次抽 `m~U[−90,−78)`、角度 `a,φ,ψ~U[0,2π)`、符号 `j` 从 `[-1,1]` 等概率取一项、整数 `q` 在 12 至 17 含端点等概率取值。记 `S=7 sin(2π(x cos a+y sin a)/240+φ)`、`V=7 sin(2πt/32+ψ)`。四层潜在 dBm 均值依次为 `m+S`、`m+V`、`m+0.7(S+V)`、`m+9j·1[t≥q]`。最后一层的前缀没有揭示突变符号和时刻。每张表加 `noise.normal(0,2,size=18)` 的独立 dB 噪声。该生成式特意与拟合器的分量字典不同。
- 采样器隔离保管分层、种子、生成参数、干净序列及后缀。提议者仅见本场公开包；每个新点的坐标和时间可在查询时给冻结预测器，随后才揭开该点的读数。场景编号、后续坐标、其他场、历史试飞、归档和封存种子均不进入请求。RP1 及已有镜像夹具只供开发说明。

## 一个场景怎样运行

1. **公共试拟合。** 用 `t=0…7` 单独拟合三个结构，分别冻结，生成 `t=8…11` 各点的预测后再揭晓相应读数。三个试拟合在这四点上均不更新。保留逐结构的四个均值、预测标准差、实测和残差。对三个二选组合各算一次四点平均 `−log[(p_a(y)+p_b(y))/2]`，其中 `p` 是对应的高斯预测密度。
2. **选择。** 在 `t=11`，提议者只得到过去 12 行 `(t,x,y,y_dBm)`、公开几何、三个匿名候选及其试拟合预测、全部三组组合分数、允许选择的个数。`alias` 流对固定顺序 `[static,translate,strength_change]` 做一次 `permutation(3)`，结果依次对应 `A,B,C`，各臂共用此映射。语义可见臂另获第一节的三个结构释义及单位。公开包只展示匿名 ID 的试算结果。用未舍入的 float64 产生规范 JSON，同一公开包同时供数值与 LLM 使用。
3. **公共正式拟合。** 对选定结构用 `t=0…11` 从头拟合。两阶段每次作业均用 `region='task_disk'`、`max_bases=2`、无旧模型、无 GP 派生点、无额外几何细化。适配已有公共接口所需的 `goal_m` 固定为 `(390,200)`。两阶段分设 `Budget`。返回的纯背景也是合法模型。各版本绑定拟合前缀哈希，出生时新证据数为零。
4. **先预测再评分。** `t=12…17` 参数固定。每个入选结构初始权重相同。在揭晓每个 `y_t` 前冻结每个世界的预测和当时权重；记录逐世界分数及组合分数 `−log Σ_h w_h p_h(y_t)`，然后令 `w_h←w_h p_h(y_t)/Σ_k w_k p_k(y_t)`，供下一点使用。只混合互斥解释的**观测概率**。各世界内的物理功率分别计算。即使某个相对权重很高，仍报告所有预测对新读数的绝对误差。[对数域运算](../src/uav_em/probability.py)

## 比较与资源

| 臂 | 在 `t=11` 的决定 | 每表拟合作业上限 |
|---|---|---|
| N-选二 | 取四个时间留出点上组合负对数似然最低的一对，平分时取匿名 ID 字典序最小的一对 | 3 次试拟合 + 2 次正式拟合 |
| N-全三 | 直接拟合全部三个结构，以相同的逐点评分与权重更新执行。完整覆盖本轮结构词表，成本更低 | 0 + 3 |
| LLM-语义 | 真实 LLM 看结构含义、点测与同一份试算结果，选择一对 | 3 + 2 |
| LLM-匿名 | 同模型独立会话，删去匿名 ID 到结构释义的映射，保留同一组数字、时序和预算。用来估计提供语义的作用 | 3 + 2 |
| 滚动 GP | 每次预测前取最近 12 个已揭晓点，以窗口均值为先验均值，使用项目的空间 Matérn-3/2 乘指数时间核，幅度 8 dB、空间尺度 80 m、时间尺度 16 s、观测噪声 2 dB。训练矩阵另加 `10⁻⁸ dB²` 对角项，预测观测方差含一次噪声。收到新点后移动窗口 | 6 次最多 12 点的分解 |

LLM-语义与 N-选二是主比较，N-全三检验挑选结构是否值得。语义消融只解释显式结构说明的作用。GP 用于判断相同数据下更简单的预测能达到什么水平。[GP 核](../src/uav_em/point_gp.py)

每个选二臂每表至多 10 次最小二乘调用、400 次残差与 400 次雅可比调用、4,992 个字典核项。N-全三相应为 6、240、240、3,276。上限由公开字典最多 13 个中心、3 个尺度，各结构分别有 1、4、2 种变化参数得出。相同输入的试拟合只计算一次。各臂的选择或失败状态落盘后才执行正式拟合，按相同前缀与结构缓存。分别报告各臂独立应计工作和实际共享计算。全批实际拟合至多 144 个作业、288 次求解、11,520 次残差和同数雅可比、131,040 个字典核项，另有 144 次 GP 分解。

两个 LLM 臂沿用 RP1 公开清单的 `gpt-6.2-sol`、`medium`。每表每臂一次独立请求、一次原始回执、180 秒截止，最多 48 次请求和 8,640 秒累计模型等待；无重试。会话无仓库、历史会话、网络、外部工具或隐藏表访问，逐次留模型标识、可获得的版本指纹、token 用量和墙钟。固定提示语为「根据给定的历史观测和预测诊断，选择两个不同的候选来预测未来普通读数。只返回 JSON，其中 request_id 原样返回，ids 是两个候选代号，reason 是一句基于已给证据的理由。」回执须绑定公开包哈希，两个合法代号不分先后，理由不参与评分。适配器直接校验回执；已有 `run_event` 的数值回退会改变提议者，故不作为本合同的 LLM 执行入口。

## 终点与停止

- 主终点是逐场六点平均负对数似然，单位 nat/点，越低越好。报告每场的 `LLM-语义 − N-选二` 和 `LLM-语义 − N-全三`。四层等权，层内六场等权。分别给配对均差和分层 bootstrap 百分位 95% 区间：`PCG64(438271)`，10,000 次，每次在各层有放回抽六场，对所有臂用相同索引。不同时间点不当作独立场景。
- 另报预测均值的 RMSE、MAE，等尾 90% **观测**区间覆盖率及宽度（用混合分布的 5% 和 95% 分位数），两臂选中同一对的次数，逐场有效率、资源、全失配点数（所有入选预测均值距实测超过 8 dB）。GP 同表。语义与匿名给配对差和区间。留出点揭晓后的最佳结构仅作诊断。
- 本次采用开发筛选阈值：两项主均差各 `≤−0.05 nat/点` 且两项区间上界均 `<0`，语义臂相对 GP 的平均 NLL 差 `≤0.05 nat/点`，才进入独立的决策实验设计。仅在语义相对匿名的区间上界也 `<0` 时报告本语义消融有正面证据。24 张合成表只有一套生成规则，各场只有一次模型选择，解释范围限于本设计。
- 固定样本量。超时、错绑、无效回执或模型不可用如实记为失败，保留已完成合法结果，无代选、补场或看分数后加样。个别回执失败时继续其余场，完整场列描述性配对结果及分母；任何预定臂或场缺失，晋级判据记为未通过。公共数据泄漏、不能核验冻结顺序、共享算子或资源账本失效则立即停批并保留原件。模型标识不可用时停该模型实验，不临时换模型。
- 下轮先实现静止适配器，用独立手制夹具验证输入白名单、前缀冻结、账本、分布评分、原始回执及失败语义。正式取第一张表前落盘本合同、提示、适配器、拟合代码、环境与输入生成器的哈希，封存后按既定顺序执行。交付逐场预测与回执、配对表、置信区间和资源表。若达到判据，下一份飞行合同先固定同一规划器、只换预测来源，再评价合法到达、实际 `T+Q` 与同期双图。EP1 本身没有飞行回放。
