# 统一任务接口v1（2026-11-20，组件集成）

本轮承接[共享工具v2](shared_tools_v2.md)及[唯一实施顺序](current_roadmap.md)第2步。用户“继续”授权接口实现和合成组件测试，不是新科学运行，不命名为M8。不读取开发状态缓存/评价真值/封存数据，不进行真实决策LLM调用、新科学飞行、点测或训练，不重开旧预算。旧原件、GIF、冻结源码和接受记录保持字节。

## 修改前约定

新增显式`scenario_loop.run(..., timing='task_source', revision_settings=..., joint_settings=...)`接口。旧timing调用合同与默认保持；新入口使用SourceOnlyBank，初始unknown_prior仅为声明的未知先验，主池禁止persistence及最近功率全图延续。允许数值/LLM推断与数值/LLM路径四种组合；选择LLM组织须有显式advisor，禁止把测试桩称真实LLM收益。咨询沿用显式RevisionSettings及现有支持内预警，等待仍冻结物理时间、固定0.5秒约定。

1. **推断前任务快照。** 只从当前public state、冻结预测、已知geometry和共享WorkBudget生成。包括未飞路线、建筑（完整洞环）、资源、共同候选、未来到达时段、逐世界差值、最近竞争路线和当前模型相对证据/外推局限。共同候选沿用已有pool＋最多50项确定性侧向提议，计入同一次700采样/10000边上限；所有数值/LLM组织都先付同样费用。最近不同路线按整路T+Q差选取，不以首15米距离门控。最小覆盖只针对声明的有限共同池，不能称全局辨识。
2. **有界两阶段源作业。** 最多pilot/refine两份请求，最多3拟合作业、6基础求解、240基础残差；pilot拟合与GP仍排除最近3条已知尾点，尾点反馈明确仅为回顾诊断。新任务schema允许propose或keep，keep可提前结束；propose的pilot为1作业、refine为2作业。只选family/region/max_bases及refine至多1项geometry_job，不允许手设源参数/权重或修改已飞路线。
3. **受约束反馈工具。** 新入口几何工具只使用constrained_refine_fit与best_feasible_v2，至多1调用、40目标/40梯度/5000核项；基本拟合与几何资源分别记录并汇总，总基础＋几何最多7求解/280残差。工具返回具体拟合、已知尾点、约束、非收敛/预算原因与任务局限，不把工具输出当新传感证据。N使用相同请求、工具和上限，按共同任务分歧/出生后证据选择作业；本轮不宣称它已是最终充分强基线。

`keep`明确表示保留事件前活动源池，不提交本事件新版本。refine阶段keep时，pilot拟合仍保留在诊断记录中，但不birth、不成为新证据；pilot本身不会提前改变任务快照或权重。只有完成propose流程后才合批提交合法候选。
4. **绑定与提交。** 请求包含task_snapshot_id，快照同时绑定当前历史/源版本/状态/geometry/冻结预测；任何输入在回调间变化都须在拟合前拒绝。新版本出生后scored_points=0，不继承拟合历史成绩。更新池后，在新的同一冻结预测下重评之前共同候选，最终路径候选统一按整路未来T+Q、几何/能量/航程接受。
5. **保留恢复机会。** 新入口共同池没有可行保留路线时，仍允许在剩余共享预算内使用数值direct修复或LLM路径提议；keep不能执行无效旧路线。全部许可尝试仍失败后才记录受控结束，记录未找到可行保留解，不声称几何全局无解，也不把搜索/预算失败自动归咎于LLM。

## 验证边界

组件测试使用明确人工点列、地图、模型和测试advisor。可执行隔离的脚本化传感/动作主循环测试，验证调用顺序及因果记账，不产生outputs科学运行或新研究GIF；实际实验模型调用数为0。检查快照字段白名单/内容绑定、洞环、近竞争覆盖、pilot尾点、keep/非法回复、共享上限、受约束工具调用、版本出生、后续点测先检验旧预测，以及共同池无解后的恢复和失败记账。

本轮不扩展复合动态机制、改变源权重/绝对可信度或外推寿命，也不改静态路径搜索代理。论文的有限反馈修订对照、强N及必要前瞻/闭环仍须下一步独立冻结科学合同。
