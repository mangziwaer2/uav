# GP辅助等效场与前方预警设计

2026-11-19交接设计。交接时未实现的联合预测、GP软形状拟合及前方阈值预警，已在用户随后授权的D1开发版本接通；具体冻结参数见[D1合同](joint_gp_pilot_v1.md)。本页保留总体设计，不代表D1或联合LLM已经获得收益结论。唯一实施顺序见[current_roadmap](current_roadmap.md)。

## 定位与过程

复杂动态电磁环境中的局部观测UAV避让重规划。通信受干扰是背景动机，不新增断联执行、通信恢复或链路研究。目标是在有限信息下提前避让，并通过新点测持续修正预测和路线。

GP提供近期局部场；等效场提供与局部证据相容的大尺度形状、移动/强度变化解释；LLM根据旧预测失配和路径相关分歧组织检验/细化，再提出中间点或路径搜索。连续参数由数值工具求解，所有路线使用同一冻结预测复核。

当前源工具最近最多12条原始读数，GP最多64个近期网格点，主配置80m支持/35s年龄。因此GP场可能传递当前源工具窗口之外仍有效的历史结构，但仍源自同一批机载点测。沿单线、当前各向同性核的左右镜像歧义不能靠密集查询GP消除。

## 源如何拟合GP场

保留真实点测拟合，加少量有支持/近期/误差较低的GP场软约束：

\[
L(\theta)=L_{\mathrm{point}}(\theta)
+\lambda\frac{\sum_j q_j[f_\theta(z_j)-\mu_{GP}(z_j)]^2}{\sum_j q_j}.
\]

第一项拟合真实读数；第二项使等效场保持GP支持区的局部形状，两者均在明确的dBm误差约定下比较。q反映覆盖、时效和误差指标，λ及两项尺度、总约束强度需冻结。总权重归一化不等于已完整处理GP相关性，这只是工程正则，不是新增独立似然。

不拟合全图未知默认值，不用网格变密虚增证据；GP查询/残差调用计预算。保留多种未来解释，不强求所有解释服从不确定GP均值。GP更像不是成功标准，最终看后续真实读数和任务收益。

旧模型若需要修订，可给一个有界中心/尺度细化工具并重估强度，机制先保留有限候选。LLM决定修订对象/许可区域/计算，而不是报可信坐标或任意权重。工具输出参数、原始点测误差、GP形状偏差、边界/失败和开销。

## GP和等效场如何共同预测

第一版候选是显式局部过渡：

\[
\widehat P_h(x,t)=g(x,t)\widehat P_{GP}(x,t)
+[1-g(x,t)]\widehat P_{h,\mathrm{source}}(x,t).
\]

P是线性功率，g在[0,1]内，是对同一总场的两种预测加权，不是物理功率重复叠加，也不是独立传感贝叶斯融合。每个h仍是完整替代世界，再按证据质量算路线；未知/延续解释保留。

g由支持、年龄、时距和误差指标决定，近期支持处偏重GP，边界/较远时距逐渐减弱，支持外为0；公式和参数在新合同冻结，不由LLM看真图调权重。均值/标准差/支持/线性期望须分别保存；现有GP标准差含噪声且未校准，不能称安全概率。方差经对数正态转换带来的代价抬升需显示，首轮不静默改原代价约定。

联合预测接入和GP软拟合分开核验，不同时改权重、目标和规划器。源趋势＋残差GP可作后续候选，当前不同时实施多种融合模型。

## 新点测怎么修正假设

1. 执行前保存旧版本对将接收点/指定时距的预测。
2. 新真实点测到来，先评价该旧冻结预测，再同化进GP和解释池。
3. 根据失配更新证据，必要时由LLM组织机制检验、局部细化和新路线。
4. 修改参数是新版本，不能继承旧历史再重复赚预测成绩；看过的开发尾段不是独立验证，GP派生点不当出生后证据。

这样边飞边修订，不等完全辨识后才规划；动态变化也可能扩大不确定性，不能声称越飞必然越准。先用当前GP，主线记录多时距误差、强干扰低估、越线漏报和支持距离；有系统性问题再有限调参，不以扩支持半径代替提高精度。未飞区域若需真值诊断，须冻结预测后另计事后评价，不给在线算法。

## 简单前方预警与路径执行分开

每点更新后沿未飞路线按未来到达时刻查询。有支持的前方预测越过任务预警线即可咨询，不等当前位置越线，也不要求监测器先证明有收益绕路。支持外是未知；源解释仅作有来源/不确定性标记的补充。

第一版可用透明的支持内均值越线规则；误差余量若加入，应由开发期后续预测残差设定并冻结，不把未校准标准差称95%上界。再次武装/解除门槛用于防重复调用，迫近时不因等待多次确认而错过窗口。旧解释明显失效或重要路线分歧也可作为限定预算下的咨询理由。

预警线是任务开发参数，需报告灵敏度/提前量/漏报误报；−80dBm仍是Q归一化值，不代表设备失效。背景风险要尽早避让，但现有仿真只计干扰软代价，不能据此声称已证明任何实际设备的硬安全边界。

咨询后，LLM可决定keep，或组织源修订和新路径。数值层按C=T+Q及整路几何/长度/能量复核，短峰值绕路若更亏可继续，持续高风险若绕行有效则执行。便宜候选收益只能作诊断/后续效率增强，不是咨询必要门槛；监测查询也计计算预算。

当前同步等待冻结物理时间，尚不能证明实际推理时延下的提前避让。MLP暂缓，先在主线观察简单规则不足再考虑；不把复杂调度工程作为等效场研究前置。
