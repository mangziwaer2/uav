## 信息与执行边界

- 已知建筑轮廓/高度、起终点和自定位；合成隐藏多源传播含穿楼、有限一次反射、毫瓦叠加和源运动/开关。环境参数是研究设定，不是实测设备保证。
- `configs/local_power.json`仅点功率测量；UAV只能取得当前位置带噪总干扰功率与时间/位置。没有角度、测距、源数/源位置或未来脚本；初始无电磁地图，无预飞行稀疏测量/全图重建/编码训练。
- GP仅根据已收到点测作局部时空外推。80m是支持范围，不是圆盘扫描；未知功率为null，标准差未经实测校准，单点/单航迹无法唯一辨认源。总干扰dBm越大越强，−80dBm是软参考，dB·s不是物理剂量/失效概率。
- 每个决策agent必须新建独立会话，只读对应public合同/实际请求/本任务记忆；不能读本文事后结论、场景、episode、真值图或其他实验。共享目录是流程allowlist，不是OS隔离。模型原始响应、解析接受、执行和回退分别留证。
- 修复只针对剩余路线，默认RRT*，无持久树复用。旧离线版本使用R10+1窗口，独立v3接受器按全程航时+连续功率代理选择；新aligned_search仅在池后增加一次C一致搜索，共同池仍旧J，其余旧模式保留旧J搜索、固定全程1.25D0/能量及2100样本/10000边总账，最多6节点。新目标在tools/run_balanced_objective.py中启用，未修改旧模式或主配置。
- 已有算子的离线有限过程生成保留；独立causal_feedback新增在线六profile/停止的最多两次组合，不是生成新算子或在线选整份离线过程。无主动补测、GP选择、自由Python执行、训练/RL、门控或通信中断。
- v3阶段36配对/24飞行及因果反馈16配对预算已完成；本轮结构研究另冻16配对/8飞行亦已完成，不追加旧模式/seed/生成。多接回点/分批竞争本轮另冻16配对/16飞行已完成；新离线结构生成4会话/16配对/16飞行额度也已用尽；不追加第5份，下一步另冻归因协议。4份旧生成名额仍用尽；验证701/709及测试1601/1607/1609/1613/1619/1621继续不生成读取。
