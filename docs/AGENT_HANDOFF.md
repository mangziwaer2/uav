## 代码地图

以下文件均在 `src/uav_em/`。

| 文件 | 作用 |
|---|---|
| `strategy_graph.py`、`strategy_search.py`、`strategy_examples.py` | 建筑走廊、条件策略评价、精确信念DP、人工用例 |
| `conditional_policy.py` | 策略与功率积分/几何公共基础，仍被strategy使用 |
| `scenario_loop.py`、`scenario_planning.py` | 飞行循环与路径评分；`task_source`为显式统一接口 |
| `point_gp.py`、`joint_prediction.py`、`equivalent_field.py` | 局部GP、联合预测、等效场工具 |
| `source_revision.py`、`task_revision.py`、`candidate_ledger.py` | 无延续源池、复合修订、候选生命周期 |
| `task_context.py`、`task_decision.py`、`feedback_*.py` | 公共任务快照、受约束工具及反馈组织 |

其余模块为环境、传播、运动与数值基础。旧循环仍保留兼容分支；新研究必须显式选无功率延续接口。`src/run_experiment.py describe`只输出状态，不运行实验。
