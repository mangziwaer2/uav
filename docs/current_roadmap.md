# 当前研究路线

更新：2026-11-09。本文件是当前研究顺序的唯一入口；已实现能力见[first_version.md](first_version.md)，方法设计见[research_method_20261109.md](research_method_20261109.md)。过去尝试不作为当前待办。

## 研究问题

在已知城市几何、可用自身定位，但只能沿飞行轨迹获得带噪干扰功率点测的条件下，LLM能否利用局部估计、证据时效和数值求解反馈，改善动态航路的航程—干扰暴露—任务完成权衡？

“复杂电磁”具体指本仿真中的建筑传播损耗、有限一次反射、多源叠加以及源运动/开关；不泛指全波城市传播、设备失效或任意平台抗干扰。局部GP是提供有依据且可能出错的信息的基础，不是本研究主要创新，也不把不确定性本身当作必须使用LLM的证明。

当前流程仅为：**合成建筑与隐藏动态源 → UAV当前位置功率点测 → 局部时空GP → LLM策略提议 → 数值规划/复核 → 短段飞行与新点测。** 不预先巡测，不导入初始稀疏地图，不重建完整地图，不使用地图编码或启动训练。

## 已完成：基础信息与闭环验证

已用新的独立子agent进行两场景验证，20响应且无失败/回退，出现实际补测、绕行和后续观测触发的修订；原始响应与实际执行均保存。静态与动态积分降低，但航程均增加，动态场景暴露时长增加。结论是当前信息能支持基本绕行，稳定避强和公平优化收益仍待解决，见[本轮结果](../outputs/interference_point_agent_20261109/index.html)。数值层默认RRT*，A*可作明确标注的可选对照。

验收同时检查到达、航程、飞行干扰暴露、能量和搜索/咨询次数。仅到达不能证明绕行有效，必须同时核查实际路线变化和暴露权衡；本轮证明基本避让而非全程零暴露。模型失败后的数值恢复不算模型优化收益。少量构造/随机场景只证明基本可用性，不宣称统计优势或泛化。

若未达标，依次检查模型提议、数值执行、任务预算、估计误差和观测可辨识性，不能直接增加无来源的源方位/远场真值。任何新传感信息都须有独立获取依据和显式成本假设。旧输出、退出主线的代码/配置/依赖和歧义文档已清理，当前结果有唯一入口和集中GIF。

## 下一步：实现可检验的推理优化方法

只收敛到以下两个相互配合的候选贡献，尚未实现或证明新颖性：

1. **电磁观测条件化的局部航路修复操作选择。** 用点测变化、支持/时效、不确定性、剩余路线和能量，选择要修复的航段、保留端点、搜索操作及参数；依据可以是“疑似恶化，需要绕行/补测”，不能编造真实源机制。局部修复本身不是创新。
2. **固定目标与预算下的数值反馈推理优化。** 在同一观测快照上有限轮比较候选；数值层返回可行性、代价分解、改进量和失败原因，LLM据此修订操作。统一接受器保留更好的可行候选，目标权重/约束不由LLM改变。一般LLM反馈循环本身不是创新。

下一步按[具体合同](research_method_20261109.md)固定J目标和每决策总资源台账，最多3轮反馈；先实现少量清楚的操作：局部接回、替代走廊、可行快捷连接及必要时全局重搜；补测沿用现有行动。不要用改中间点的基础验证冒充区段修复或同点多轮优化，也不要仅给RRT*改名就声称实现增量算法。

## 之后：受控验证，而非扩大功能清单

固定共同观测接口、估计器、任务目标和总计算预算，比较全局重规划、数值局部修复、同操作集合的数值自适应、LLM单轮和LLM多轮反馈。分开检验修复范围选择、反馈修订和保留候选的贡献；报告实际航程/暴露/完成率以及总搜索消耗、模型调用/词元/墙钟耗时。

先在开发场景冻结方法和参数，再用未用场景及多个种子验证。评估应包括估计误差、噪声与变化速度敏感性，以及静态/动态源的分层表现。不能把更高传感能力、更多求解资源或事后改权重混作模型推理收益。

本地模型迁移仅在强LLM机制得到证据后再讨论；不以旧模型模仿数据为最优标签。通信中断穿越、硬暴露容忍、等待/爬升、代码执行、门控、地图网络和训练均不属于当前实现阶段；若要引入，先另定问题与前提。
