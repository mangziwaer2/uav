# 当前研究路线与阶段边界

更新：2026-11-02。本文件是研究阶段、优先级和扩展候选的唯一维护入口；实际能力与协议见`first_version.md`，新agent先读`AGENT_HANDOFF.md`。正式申请书保持阶段性表述，不是功能完成清单。

## 1. 研究主线

部分可观测时变电磁干扰环境中，大语言模型（Large Language Model，LLM）辅助无人机动态航路优化。无人机从有限先验出发，飞行中测量局部干扰，更新地图和不确定性，在周期或观测事件发生时直接咨询模型，执行经过数值复核的策略。

按用户2026-10-27最新确认，核心仍是地图不确定性下的LLM辅助决策：模型结合自身知识／经验与当前可见证据，提出补测、绕行和规划策略，并根据执行反馈修订。知识／经验只能支持假设和决策，不能把未知源或未观测区域当作已知事实。继续既有阶段安排，不新增按需地图展开、表达不确定性分解或新的信息查询行动等独立方向，也不扩展已有后置分支。

地图编码仅是减少输入词元、帮助模型理解地图状态的辅助实现，不要求独立创新。若简单有效，可以采用轻量编码及LLM对齐微调；需要保留未知、观测支持与时效语义，验证压缩后是否损害决策。当前未实现编码器或相关训练，不将其设为非代码决策或后续局部代码生成的前提，本轮不启动训练。

按2026-10-29本轮授权，阶段①加入等效源假设闭环：LLM基于带时序的局部点测，提出源数、中心、功率贡献、尺度及速度，数值层验证观测一致性后生成预测地图；新点测先检验旧预测，再反馈模型修订。允许同一决策点多轮推测，不要求实时生成，但每轮计入总预算。此为既有地图不确定性决策主线的具体实现，不新增代码执行、全域预扫描或训练方向。

2026-10-31用户确认：可以假设具备含误差的干扰探测能力，但不能由传感器直接给出源坐标，再让LLM机械接受。现已把源提议扩展为匹配公开传播近似的位置／EIRP／源高／速度，并联合检验功率与方向；LLM依据证据提出假设、补测和修订，数值层不替它反演源位置。源协议适配与真实模型能力验证是两件事。

电磁环境不再定义为服务站覆盖或通信质量；采用背景加多源合成干扰功率，支持固定、移动、出现和消失。左侧完整真值仅供研究者观察，右侧局部估计才是决策信息来源。环境的时间变化和新观测引起的认知变化分别处理。

## 2. 当前实现

2026-10-30用户要求先完善基础仿真再支持研究。本轮只补传播、范围感知、观测触发、日志及验证，不扩展训练、门控、生成代码执行或硬安全行动。细节见`simulation_foundation.md`；新的环境与旧高斯实验不能直接作收益对照。

- 定高二维几何、恒速与能量模型；背景和干扰源在线性功率域叠加。
- 默认三维对数距离传播及简化棱柱损耗；机载总功率与360°含噪波束快照，可在强干扰区外发现方向，无直接测距／空间圆盘真值扫描。点测局部外推、年龄失效及未知标记继续保留，测向不增加远处观测支持。
- 默认传播源假设与时间戳功率／测向联合检验已接入，显式高斯源基线仍保留；公开传播参数不含源真值，拟合和更新前新观测检查分开。不能声称完整源识别、真实传播反演或排除模型失配。
- 默认渐近最优快速探索随机树（Rapidly-exploring Random Tree Star，RRT*），A星搜索（A* Search）仅为可选对照。没有必须先运行A星搜索的流程，两者均重新搜索。
- 模型直接咨询；可继续、重规划、补测及提出兼容的候选采样区域；输出校验、几何及能量复核、显式回退。
- 非代码版阶段计划已接入：模型声明目标、关注分区、待验证假设及修订条件，运行时保存计划，下一轮提供实际行动、区间点测、补测事件及传统求解反馈。回退／覆盖不激活未执行的计划。
- 源假设默认每点最多3轮、任务最多24次咨询；0至3源在线性功率域叠加，支持恒速平移。拟合误差与更新前新点预测残差分开记录，未测区域不因预测而标为已知；真实模型是否能有效利用该接口仍待实验。
- 观测偏差、首次角峰发现、持续增强、软参考跨越及旧源预测与新测向显著失配可提前复核；最小间隔仍有效，没有接收到的远处变化不会用真值触发。
- 强干扰和不确定性是软代价，尚未标定平台故障；图、动画和日志使用干扰语义及版本2。

## 3. 创新假设，尚待验证

1. **任务相关的主动信息获取与重规划**：模型能否在不必全域建图的情况下，选择有价值的补测、调整航路？应对比无补测、规则及数值信息获取，并计额外航行成本。
2. **有限上下文下可解释的区域信息筛选**：保留与目标和航路有关的干扰、未知程度、数据时效，减少无关地图内容干扰。当前为摘要，不是训练后的注意力编码；应匹配上下文预算做消融。
3. **策略条件化采样搜索**：模型能否用候选区域和代价偏好引导随机树，改善发现路径速度、航程或暴露？保留全局探索，计入模型、求解及补测成本，不能只报最佳案例。

等效源接口服务于上述假设，特别是把“环境可能怎样”转化为可检验参数，再用补测消除歧义。应区分当前窗口拟合改善、后续新点预测改善和实际路径收益；源数／位置未必可唯一恢复，移动源也可能与大静态场混淆。不能只看同一批测量拟合得更好便宣称LLM理解了未知地图。

多规划器选择是后续可检验机制，不必为了给模型更多工具而扩充核心流程。合法输出和回退到达不构成模型优化收益。

局部观测不足导致路线继续深入干扰区，是有价值的研究问题，但不是模型一定能解决或已经更优的证据。模型同样不能凭空知道未知源边界；应验证它是否更有效地组织补测、比较替代走廊、识别信息不足并利用执行反馈。

## 4. 四阶段研究安排

### ① 非代码LLM辅助决策：当前实现与验证主线

主线为飞行探查、地图更新、模型决策、数值求解、短段执行和反馈。基础仿真只需提供可信的观测、算子执行、约束检查与反馈，研究核心是LLM根据环境认识提出并修正决策计划，不以先把无模型策略优化到较高水平为前提。先把部分观测、强干扰避让与未知区域处理的语义做清楚，不追求把仿真做成完整物理系统。当前已有真实本地模型适配及小规模试跑，不等于正式算法已经集成优化完成；不重复搭建模型接口，也不急于宣称收益。

初期研究绕行、在较弱干扰处通行和任务相关补测，不默认允许中断穿越。局部场空间尺度35／30m保留离线检查的绕行通道，但当前干扰仍是软代价，尚无强干扰禁入机制。不能用真值在线拦截冒充无人机感知；未知区域也不能标为已确认低干扰。

本地继续使用已有Qwen3-1.7B验证接口、记录格式及失败，不把小模型能力当作方法上限。后续可在有4090的云端主机运行更强模型；模型规模、精度、上下文和推理预算需实测适配，不能承诺所有更大模型都能运行。现有接口仅加载本地目录，尚无远程服务客户端；在云端直接运行仓库与从本机调用云服务是两种部署方式，后者需要独立适配、超时和日志支持。

本地生成默认不限墙钟时间，先让模型在现有输出词元与调用预算内完成响应；显式设置时仍可启用生成软时限。实际推理耗时保留记录，不以本地资源受限造成的速度直接判断策略能力；后续云端4090上统一运行条件后再分析时延。不限时不等于取消词元／调用预算，也不保证合法输出。

区域摘要、候选采样盒与主动补测是当前可用研究接口。根据实验需要再扩展轻量动态A星搜索（D* Lite；D*表示Dynamic A*）或快速重规划采样算法RRTX（原论文全称：RRTX: Asymptotically Optimal Single-Query Sampling-Based Motion Planning with Quick Replanning），不为工具数量提前实现所有算法。

### ② LLM局部代码生成：非代码版可用后的下一项研究，当前未实现

按用户2026-10-27确认，先完成并稳定阶段①，再实现LLM解决阶段性问题的代码生成；不必先完成中断穿越，也不要求先证明非代码版优于数值基线。第一步只选一个局部接口，如候选补测评分或候选采样点评分；同一观测、地图、约束与底层规划器保持不变，避免同时改写估计器、采样器和规划器而无法归因。

实施顺序：①定义纯函数输入／输出、可见特征和数值限制；②离线生成短候选函数，保存提示词、代码、版本及生成成本；③在真正隔离、限时限内存、无网络和无任意文件权限的环境中验证；④由主进程复核返回值、几何与能量，只接受评分或候选建议；⑤再独立决定是否开展在线按阶段生成。语法树检查不是沙箱，禁止以模型编写的检查器替代独立约束；当前代码没有exec、动态导入或生成代码执行入口。

对照至少区分：非代码LLM选择固定算子／参数、LLM选择人工预置评分函数、LLM生成局部函数。固定可见信息和总预算，计入生成、验证、失败、回退与额外探测成本；按不同地图／干扰机制与多种子检验，不以一次可执行或一条短路线作结论。若代码生成在未见场景中显示稳定实际收益且额外复杂度可接受，再把项目核心收敛到该方向；无收益则保留非代码决策主线，不预先承诺生成算法最优。

地图估计代码是后续候选，不是阶段②首项：稀疏观测一般不足以唯一恢复完整场，必须保留未知／支持／时效，检查新到测量上的预测残差，不能用隐藏真值选算法或把补全图当事实。完整规划器生成、底层飞控生成不在初期范围。

### ③ 中断穿越、增量规划与门控：按前提开展的独立可选分支

受限中断穿越需先区分通信中断、导航退化与机体受损，定义机载控制和观测是否可用、恢复条件及撤退策略；不能把−80 dBm软参考改称失联阈值。专门场景和约束不足时不实施，也不阻断阶段①②。

RRTX等增量算法只有在明确持久搜索图、变化边代价及更新传播方式后再适配，不能仅按路径变化大小切换算法名。多层感知机（Multilayer Perceptron，MLP）门控只有在日志足够、调用成本确为问题时才研究，并与直接咨询、周期和规则触发比较。地图学习编码同样可选，不作为阶段①②的前提。

### ④ 模型能力评价与可验证反馈调优：独立研究分支

只要阶段①的接口、场景和记录基本稳定，即可组织模型评价；不以阶段②代码生成成功或阶段③完成为条件。普通软件测试和闭环算法对照始终需要，专门模型能力评价则另设问题与协议。

重点评价：未知信息识别、约束理解、探测价值判断、替代路线比较、反馈修正、可执行性以及模型建议的实际收益。固定环境可见信息、上下文和计算预算，区分原始模型、解析校验和数值回退的贡献；同时报告失败、暴露、额外探测与推理成本。按地图／场景机制而不只按时间步划分训练与测试，避免同一轨迹泄漏。

数据和资源允许时再用可验证轨迹、候选偏好或执行反馈调优，对照未调优模型与未见场景。若无法训练，也能形成有效的评价与失败分析，不把调优成功作为项目结题的唯一条件。

## 5. 决策候选：不是当前协议的扩充

当前只有`continue`、`replan`、`probe`三个行动。绕行不是独立算子，而是重规划结合代价与采样建议；下表其余项仅为讨论候选，需实现执行器、约束、日志与测试后才可开放给模型。

| 决策 | 当前状态／适用前提 |
|---|---|
| 保持当前航路 | 已有`continue`；不等于证明未知航段安全 |
| 绕行／改走另一走廊 | 已有`replan`及偏好／采样盒建议；不保证一定绕开强干扰 |
| 主动补测 | 已有`probe`；只能选本次候选，预算有限，不能随意全域建图 |
| 调整搜索偏好与采样区域 | 已有接口；不放宽几何、能量或外部约束 |
| 退回最近有依据的低干扰位置，再探测替代走廊 | 未实现；需要时效检查，历史低干扰不是现在仍安全的保证 |
| 在已评估位置短时等待／复测 | 未实现；必须计悬停能耗和暴露，不能默认场一定消失 |
| 调整复核间隔／补测优先级 | 模型决定复核间隔未实现；需限定上下限并保留本地观测事件处理 |
| 无可行航路时中止任务或请求外部接管 | 未实现模型行动；当前仅有程序终止原因；需定义外部处置，不伪装成成功 |
| 受限中断穿越 | 阶段③候选；当前没有对应能力或安全保证 |

不默认增加高度／速度优化，因为当前飞行器是定高恒速模型；先实现对应动力学和约束再讨论这类策略。
