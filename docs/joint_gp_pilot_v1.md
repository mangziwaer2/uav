# GP辅助等效场与LLM决策：开发实验D1

2026-11-19。用户已要求继续实验；本合同先于本轮研究运行建立。目标是检验LLM依据预测失配组织等效解释检验和路线搜索的增量；GP/预警为所有核心方法共享的能力。本文是开发合同，不是论文性能结论。

## 冻结范围

准备阶段复制 `configs/local_power.json` 为独立场景，保存配置、活动源码、测试和本合同的SHA256。只用这个已见开发场景、原配置种子109；不读取封存验证/测试。新目录 `outputs/interference_joint_gp_d1_*`，拒绝覆盖。准备后禁止修改源码和配置再续跑。

最多8次飞行，每方法一次：source_numeric（源预测/原点拟合）、joint_point_numeric（联合预测/原点拟合）、joint_N（联合预测/GP软拟合/数值两环节）、joint_I（LLM推断/数值路径）、joint_P（数值推断/LLM路径）、joint_J（LLM两环节）、gp_numeric、persistence_numeric。N/I/P/J的预测能力、软拟合、触发、工具和资源上限相同。前两项只作分步开发消融。

每飞行最多100模拟秒、102个传感点、4次咨询事件，每事件最多3拟合作业、6求解、240残差调用、700路径采样、10000边检查；初始几何规划另700/10000。真实LLM最多3个独立会话（I/P/J各一）、24个回复（I8、P4、J12），不追加。无LLM方法不伪造回复/调用。超时/非法回复用原有数值回退并单列。同步回调冻结物理状态，固定0.5秒悬停，墙钟另列。

## 联合预测

在相同预测前缀上，GP与源预测线性功率期望作凸插值：E[P_h]=g E[P_GP]+(1-g)E[P_source,h]。每个h是完整替代世界，之后按现有出生后证据权重评分，权重更新规则不变。保留延续/宽残差解释。

g=支持标记 × exp[-(最近点距离/80m)^2] × exp[-最近点年龄/35s] × exp[-前瞻时距/20s] / [1+(GP标准差/8dB)^2]。支持外g=0；支持沿用GP自身80m/35s规则。各参数作为工程开发设定冻结，不宣称校准概率。公开保存GP均值/标准差/支持、g、各源均值及联合线性期望。dBm描述矩按表示混合计算，路线代价直接使用单独保存的线性期望，避免重复对数正态变换。

## GP软形状约束

原始点测拟合项保持为最近最多12点的平均dBm平方误差。额外取最近5个观测位置及其y方向±20m偏移，共最多15个合法位置，在本次拟合时刻查询仅该拟合前缀建立的GP；仅保留支持内且标准差≤8dB的点。软项为0.25×按g归一化的平均dBm平方误差。网格数量不能增加总软强度。先导拟合排除最近3个已知尾点，GP也必须排除它们；尾点仅作回顾开发反馈。派生点不增加模型出生后计分次数。

字典、参数边界、家族、原点拟合、证据更新、路径池、目标T+Q和硬约束保持既有规则。软项参与字典选择及求解接受；同时报告原点误差与软项误差，不能把训练改善当未来预测收益。GP查询和新增核项另记账。

## 透明的前方预警

每个新点测同化后冻结一个监测预测，沿剩余路线按到达时刻、10秒前瞻、15m间距查询。GP支持内的联合预测dBm均值按原证据权重平均，达到−78dBm即为风险信号；−78仅是开发任务线，−80仍仅是Q代价单位。无须先证明绕路有收益。未知保留标记，不当低风险事实。

少于4个已收点测不咨询。解除线−81dBm；风险解除后重新武装；持续越线且距上次咨询≥8秒允许再次咨询，最多4次。触发只提出咨询，实际路线由同一冻结联合预测下的共同接受器决定。单独保存预测越线位置/到达时刻/支持和预算阻挡原因。

## 评价与展示

所有声明飞行及显示预测冻结之后才查询事后真值。飞行与固定悬停各按≤0.5秒中点积分评价真实Q，执行积分真值接收点≤4000；冻结监测路线的预警真值接收点另限≤9000。回放每飞行最多32帧，21×16网格，总真值网格点≤86016；包含所有决策前后状态，超限不丢事件而报错。预测显示网格查询≤86016，监测查询≤9000，软拟合GP查询≤960，预序点预测查询≤816；这些预算独立记录，不冒充传感点。

报告到达、航程、真实T/Q/T+Q、约束、调用/工具资源、先预测后点测误差和强干扰低估。预警用触发时被冻结的当前路线进行事后核验，统计支持内越线预测的点级误报/漏报，以及每次报警到预测/实际越线的提前量；改路后的实际低暴露不能自动算误报。全到达不证明优化，单场景不证明泛化。I/P/J分别对N及J对I/P只给描述性结果。
