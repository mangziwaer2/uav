# 电磁干扰环境与局部信息模型

更新：2026-10-30。研究对象为部分未知、可随时间变化的电磁干扰影响场中的无人机动态重规划。服务站覆盖和连接保持不是本版研究目标。当前传播／范围感知细节、文献依据和未实现物理项统一见`simulation_foundation.md`，阶段优先级只在`current_roadmap.md`维护。

## 环境量与简化假设

采用同一观测频带的总干扰功率，单位dBm（相对1毫瓦的对数功率）。默认以三维对数距离传播及简化棱柱损耗计算源接收贡献，加背景在线性功率域叠加后取对数；源可固定、移动、生灭。高斯场仅保留为显式合成基线。一个位置的值由全部活动源共同决定，不能把区域重叠简单视为互斥圆形障碍。

这仍不是完整电磁传播仿真或设备数字孪生。已加入载频、机高／源高、简化遮挡和归一化阵列波束功率；暂不模拟多径／绕射、真实阵元流形、频谱协议、导航欺骗或平台易损性。参考值是研究软代价，不代表必然失效；参数未由真实设备标定，不能把不同电磁风险压成一个已验证概率。

## 信息边界

- 已知：几何、任务、飞行器能力、均匀背景先验及预算；不存在服务站距离先验。
- 可测：当前位置带噪总功率、360°波束功率及可检测远源角线索，带位置与时间戳；无测距或周围网格直接扫描。
- 估计：局部点测外推，或有效等效源预测加点测残差；保留数据年龄、未知标记和启发式误差，预测与背景先验都不是低干扰证明。
- 隐藏：源位置、EIRP／高斯峰值、源高、活动时间、速度及未测真值。模型不接收隐藏脚本。

## 动态重规划的两种来源

1. 即使场固定，无人机也会因新观测发现未知区域并重规划。
2. 场随时间变化时，局部测量可能与旧估计不一致，触发再次咨询大语言模型（Large Language Model，LLM）。

新测量偏差只能说明当前认知不匹配，不能独立区分空间变化、时间变化和噪声。远处变化没有被探测到时，系统不会使用真值提前触发。定期复核和测量过期用于处理信息时效，不等于可靠预测。

## 评价和展示

左图给研究者完整当前真值及真实活动源位置，黑色虚线为总干扰功率达到软参考值的等值线；这是人为定义的显示范围，不是高斯场天然硬边界，也不是禁飞线。右图只展示局部估计，不显示源真值。右图青色斜线为有测量支持的强干扰估计，左图斜线为该估计与真值区域的重合，不表示整片直接测过。青色圆点才是含噪点测值达到参考值的真实测量位置。两图同一色标，未知／过期为灰色；真实地图仅由环境脚本演化，不因探测改变。

主要考察航程、到达、能耗、强干扰飞行暴露、信息获取与计算成本。暂不实施通信中断时间约束，不以软场暴露推断真实平台安全。

## 当前场景修正与避让边界

旧高斯源曾从85／65m缩小为35／30m，属于2026-10-29及以前的实验。2026-10-30默认场改为−2／−5dBm EIRP、高度1.5m的传播源；仍离线检查起终点和低干扰绕行通道，测试路线不传入决策。不能把新旧环境暴露差异当成模型改进。

场景修正不能替代算法约束。当前依然是干扰软代价，不是禁止进入强干扰；局部外推也不能可靠恢复未知边界。后续初期避让应分别定义：已观测强干扰如何限制候选航路、未知区域何时先补测、短段执行前何时复核。不能让模型只凭提示词保证安全，也不能用隐藏真值进行在线拦截来伪装为感知决策。单点测量设定下无法保证从未进入未知强干扰，应如实报告首次发现、暴露、退避与失败。

## 实际测量输入输出

默认传播公式与同步波束功率公式见`simulation_foundation.md`第2、3节；传感器只输出接收观测，不输出真源坐标、数量或距离。2026-10-31源假设也已适配公开传播近似，数值层联合检验功率与方向，参数与误差语义见`first_version.md`。此前高斯合成基线及显式高斯源预测使用以下公式（不再是默认传播真值或推荐源协议）：

```text
I_mW(x,t) = 10^(background_dbm/10)
            + sum_k 10^(peak_dbm_k/10) * exp(-||x-center_k(t)||^2/(2*sigma_k^2))
I_dbm(x,t) = 10*log10(I_mW(x,t))
measurement_dbm = I_dbm(vehicle_position,t) + Normal(0,measurement_noise_db^2)
```

传感器每次输入当前位置、时间，返回本位置总功率和360°波束快照；波束中先叠加所有活动源，再加噪声和检测。角峰可能混叠、漏检或虚警。源参数仅在环境内部使用。点测支持默认40m局部外推，测向历史给模型推断但不增加远处格子观测支持；二者均非直接空间圆盘扫描。

### 2026-10-29已接入：等效源假设闭环

LLM可根据原始带时间戳点测，提出0至3个等效源的中心、尺度、峰值接收功率贡献和恒速速度；并不是获取上面的隐藏源脚本。数值工具按各点自身时刻计算多源叠加功率，报告拟合误差及复杂度惩罚，拒绝坏提议并保留旧假设。同一决策点可以反馈迭代，默认最多3轮、计入24次总调用预算；没有飞行或新测量夹在这些咨询轮之间。完整协议及限制统一见`first_version.md`第2节。

通过检验的假设生成当前时刻预测地图，规划器仍使用原固定数值算子。下一个实际测量到来时，先保存旧假设预测和有符号残差，再加入数据集；由这些新点检验推动模型再修订，不能用更新后的拟合冒充预测正确。未观测区域继续保持未知支持和误差，已有观测不会变成全域扫描。

此处是低维等效场近似，不是恢复完整矢量场、求解麦克斯韦方程或识别真实EIRP。旧源接口测试使用同族高斯环境；当前默认真值已是传播场，源协议仍是高斯近似，数值评价暂只检验点功率，不含方向残差，必须重新检查模型失配。没有真实接收机标定，不能承诺真实平台安全。

移动假设利用时间戳平移中心，而不把每次测得的强干扰固定留在旧位置；但一条短轨迹可能同时兼容大静态场、多个源或移动源。当前只保留一个合格解释，没有后验置信度或源生灭识别，也不保证数据足以区分这些情况。应让模型利用可见残差与现有补测选择积累证据；不能用提示词强行保证不会误判成大静态场。当前路径代价不是按未来到达时刻计算，尚非时空规划。

全图预先探测、远处空间逐点扫描和多机建图未实现，也不作为规划前提；机载被动接收远源的360°测向能力已实现。阵列假设、方位分辨率、灵敏度和噪声明确配置，探测距离随传播条件变化，不能用局部外推半径替代传感器能力。2026-10-29真实检查的6次响应均省略源字段，不是收益验证，记录见`../outputs/interference_source_local_seed7_20261029/review.md`；历史结果不移作新环境验证。

对数距离损耗及源开关已进入默认环境，相关阴影衰落仍未实现。当前不立即建立全波平台；先验证观测噪声、方向混叠、遮挡、未知、估计失准和老化这些可控制条件。不得描述为已通过真实设备标定。

大语言模型（Large Language Model，LLM）可以建议补测位置、绕行方向、复访时刻和预算；不能生成或修改实际传感器读数。应与规则补测、不确定性最大点选择或数值信息获取作对照，不能以调用更多次证明贡献。

## 地图摘要、学习编码与微调：研究预留，未实现

按用户2026-10-27最新确认，这部分只是减少输入词元并帮助LLM理解地图状态的辅助实现，简单有效的编码／对齐微调即可，不要求独立创新。核心仍是地图不确定性下LLM结合自身知识／经验和可见证据提出合理决策；不由此新增地图查询行动、分辨率调度或其他研究主线。阶段顺序只按`current_roadmap.md`执行，当前没有启动编码训练。

当前采用可解释结构化上下文：任务和飞行器、几何障碍、当前测量、稀疏地图样本、南中北走廊摘要、剩余航路、候选补测及近期反馈。未知功率为null，启发式误差不解释为已校准风险概率。传感器、局部建图和模型的职责应分开。

后续候选区域摘要可加入有支持功率范围、支持比例、信息年龄、与当前航路的关系及额外航程。以下为拟议格式示意，不是当前真实输出，也不是已经实现的字段：

```json
{
  "region_id": "candidate_north",
  "bounds_m": [300, 440, 480, 560],
  "supported_fraction": 0.25,
  "supported_estimate_range_dbm": [-92, -84],
  "unknown_fraction": 0.75,
  "relation_to_route": "north_alternative",
  "note": "low supported values do not establish safety of the unknown part"
}
```

若后期研究地图编码，可把障碍、干扰估计、未知掩码、误差、年龄及航路／目标组成多通道局部图块，再训练编码器。变分自编码器（Variational Autoencoder，VAE）的连续隐变量不会自动变成语言模型能理解的词元；可考虑向量量化变分自编码器（Vector Quantized Variational Autoencoder，VQ-VAE）离散码本，或把连续图块嵌入经投影层对齐到模型输入。两者都需要位置／时间信息和地图—描述—行动对齐；不要求必须先把地图离散成文本词元。

地图重建只证明压缩／补全能力，不等于规划推理。若使用仿真完整真值作补全目标，应称为合成监督训练；遮盖已有观测再恢复可构成自监督任务，二者不要混称。训练阶段的真值标签不能在测试决策时成为输入。应检查未知掩码、狭窄通道和功率峰值的保留，以及下游补测／航路收益，而不只报告平均重建误差。当前继续使用摘要，训练不作为本轮开发内容。

## 局部启发式代码：下一阶段计划，未实现

用户2026-10-27确认先完成非代码LLM的阶段计划与反馈闭环，再实现局部代码生成；若同预算、未见场景下的收益足够稳定，再考虑把项目收敛到代码生成方向。唯一阶段顺序、接口选择、隔离前提和验收清单见`current_roadmap.md`阶段②，此处不维护第二份开发计划。当前非代码实现见`first_version.md`。

让模型建议一个短小的候选采样评分、采样分布或补测排序函数，比让模型一次生成完整最优规划器更容易限定接口和验证。两种方向应分开：离线生成多种启发式并在独立地图验证；在线输出调用既有规划／测量接口的短策略。前者不是一次提示就得到最优算法，后者也不是直接输出底层飞控。

当前只接受结构化策略，不在线执行生成代码。后期若引入代码，只允许产生候选建议，保留独立几何、能量和研究风险约束。执行需要真正的进程或容器隔离、时间／内存限制、禁用网络和文件访问以及受限接口；语法树检查本身不是安全沙箱。不能把模型编写的检查代码作为唯一安全边界。

- Romero与Kim，Radio Map Estimation: A Data-Driven Approach to Spectrum Cartography，2022，arXiv:2202.03269：稀疏空间测量到无线电地图的综述背景，不是LLM规划方法。

- Liu等，Visual Instruction Tuning，2023，arXiv:2304.08485：编码器与语言模型对齐的相关思路，不是本项目已实现能力。

- Liu等，Evolution of Heuristics: Towards Efficient Automatic Algorithm Design Using Large Language Model，2024，arXiv:2401.02051：生成、评价和迭代启发式的相关方法，不提供一次生成最优解的保证。
