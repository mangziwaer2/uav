# 论文问题与待验证贡献

2026-11-19，依据用户最新确认：复杂电磁环境为应用背景，动态路径重规划为经典优化任务，研究核心落在LLM辅助决策优化。以下是待验证贡献定位，不等于文献优先性或性能已证明。

研究问题：在仅有航迹功率点测、环境解释存在歧义、计算和LLM调用有限的条件下，LLM能否根据后续预测失配及任务相关分歧，更有效地组织环境假设修订和路径搜索，从而降低实际飞行代价？

候选贡献及其证据要求：

1. 由LLM组织面向任务的假设检验与计算分配：选择机制、许可区域、修订对象和搜索方向，由数值工具求解参数。需对比同状态前缀、同工具和同总预算的数值反馈，检验后续未见点测及路线排序，不能把同池argmin或增加调用量算成贡献。
2. GP辅助、多解释保留的推断—规划闭环：以局部GP软约束等效场，持续用出生后真实点测检验各版本。其作用是给LLM提供可检查的结构与反馈；GP自身新增预测能力必须通过单独数值对照归因。不能将等效源宣称为真源定位，也不承诺有限轨迹能够消除全部歧义。
3. 基于前方风险的有限咨询与共同数值接受：前方支持内预测越线即可咨询，LLM可以keep或组织修订和新路线，实际提交仍按同一冻结预测复核。需报告预警提前量、漏报/误报、约束、真实T+Q与调用开销；已有同步原型不能证明实机时延下的收益或安全保证。

核心归因保留N/I/P/J：J对N检查整体，J对P及J对I分别检查推断组织和路径组织的增量。若J没有更好，诚实定位瓶颈，不通过提高解释权重、调整功率代价、削弱数值参考或选择性展示来制造收益。

D1只推进可回放的开发闭环与能力消融。沿用的数值反馈规划器不是论文最终强优化基线；正式实验还需要有竞争力的数值搜索、独立冻结的开发/评价范围与必要重复。封存验证/测试当前不读取、不运行。相关工作须完成方法级比较后再确定创新措辞，不使用“首次”等未经核对的表述。

2026-11-20的[D1实际结果](d1_results_20261120.md)：闭环和N/I/P/J已跑通，I未改善任务代价，P/J代价升高，尚不支持LLM优化或联合协同结论。下一步应检验解释失配后的修订与路线复核是否能改善未来预测/任务，再检验LLM在同工具与强数值参考下的组织增量，不以提出池外路线或减少数值求解次数代替总收益。
