# 去除全图功率延续：D2-M0开发机制合同

2026-11-20。用户要求移除会冲淡空间假设的功率延续并继续看新replay。本合同先于新科学运行冻结；只用已见开发配置`configs/local_power.json`及种子109，不读取封存验证/测试，不追加D1。

## 本轮问题与范围

主假设池不再含“最近点测在所有位置/未来时刻延续”的成员。先完成两条数值组织飞行，检查空间源表示及失配后的修订；本轮0个决策LLM会话/调用，不声称LLM收益。N/I/P/J仍是后续主实验的归因结构；功率延续只留历史参照，不重新飞独立延续对照。

两飞行：`source_early`与`source_revise`。二者均移除延续、在8秒且至少9条点测时首次拟合，之后沿用支持内前方预警；后者另允许全部已有源版本在最新出生后点测上均失配时提前拟合并重新评分未飞路线。二者共享工具、字典、目标及预算上限。D1只作历史描述，不把跨版本闭环差异冒充单因素因果效应。

## 无源初始化与权重含义

没有源模型时仅有显式`unknown_prior`：均值为声明的−100dBm背景、标准差15dB；完全不读取最近功率来外推其他位置。GP仍由已有点测提供局部预测。支持外显示灰色未知，不能按背景低均值解释为已知低干扰；路径评分若需查询该处，采用这一宽先验的线性功率期望，不能按零暴露处理。

首次成功产生非空源版本时，移除占位未知模型，源版本等权归一化。从此仅保留有空间基元的解释；权重是**条件于当前源模型集合的相对证据**，不代表集合中必有正确世界或远处已可信。后续新版本仍采用旧池75%/本事件新版本25%的出生分配，并仅用出生后新点测计分。若拟合全失败，未知保留、失败与预算如实记录，不制造源。

## 触发与修订

每个点测先评价上一冻结预测，再同化更新。源预测检验使用点测前已发出的各版本预测。首次源拟合条件为已收点数≥9且时间≥8秒。两方法沿剩余路线按未来到达时刻查询10秒、15米间距，GP支持内加权均值≥−78dBm触发风险咨询，解除线−81，持续风险再咨询间隔8秒。

`source_revise`额外检查：最新点测相对**每一个**已有源版本的绝对预测误差都≥8dB，即最小绝对误差≥8dB（固定4dB残差标准差的2倍）。这是开发失配规则，不是变点后验或校准显著性；双侧处理，不预设失配就是新源。未知占位模型不参与此检验。修订最小间隔2秒，共享每飞行最多4次事件，包括首次初始化；预算耗尽只记录阻挡，不追加。每次获准拟合后使用同一新预测立即重新评价未飞路线，不必等待另一轮路径咨询。

## 不变项与因果边界

GP参数/支持、GP软拟合0.25强度、源有限字典与幅度求解、两轮pilot/refine、单事件3作业/6求解/240残差、数值路径候选/反馈策略、`T+Q`、全程≤1.25D0、几何及能量约束沿用D1。先导拟合和先导GP均排除最近3条已知尾点，尾点回顾不当独立验证。没有自由连续源位置优化、主动补测、新传感器、训练、调暴露权重或LLM调用。

同步回调及固定0.5秒悬停照实记录；不称实际推理时延或实机实时。没有证据时保留源多解；移除延续不会自动消除左右歧义，也不保证更好的路线。
