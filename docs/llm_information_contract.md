# 当前信息边界

2026-11-19，服务于[唯一方法](method.md)。环境公式和文献见[环境说明](local_power_environment.md)。

| 信息 | 来源与含义 |
|---|---|
| 位置、时刻、已耗能量、已飞航迹、目标与边界 | 公开定位、任务及已发生执行 |
| 建筑轮廓/高度和净空 | 已知几何，不由功率推断 |
| 历史点测 | 每条只有当前位置/时间/带噪总干扰功率，不含方向、源距离或周围圆盘 |
| GP均值、标准差、支持/年龄 | 仅已收点测上的局部常均值时空模型；未知应明确标注，不当低功率事实 |
| 等效场基元、机制、质量和证据点数 | 数值拟合的候选解释，不是真源定位，不是额外观测或校准世界概率 |
| 剩余路线、候选及各场景未来到达时刻评分 | 公开数值预测，未来真值不可见 |
| 已发生工具结果、调用延迟、接受/拒绝/超时 | 本任务已发生反馈，不混其他实验或未来反馈 |

禁止给估计器、小咨询模型或决策LLM：隐藏源位置/功率/运动和开关脚本、真功率图、未来真实读数、事后评价标签/GIF、其他方法结果或封存城市。

GP和等效场共享历史，不能作为两路独立传感证据相乘。支持区不是精确/安全区，方差未校准。多个解释分别评分再按证据质量混合；LLM不能选择最容易走的世界来修改质量。新生解释不重复评分拟合历史。

现有路径请求包含模型/观测版本、当前位置/时间/剩余能量和长度约束、共同候选及预算、少量GP局部样本、本任务反馈。输出是绑定request_id的keep/direct/via、中间点、有限采样额度和模式；推断接口输出有限family/region/max_bases作业。解析、预算和数值复核后才能执行，不运行任意Python。

当前参考飞行等待时状态冻结。[最小异步合同](async_replanning_v1.md)已冻结并实现路径意图接回与截止检查，真实飞行/异步推断重建仍需新合同；小咨询模型输入/标签设计见方法文档，不能把设计当已训练能力。

真实决策子agent必须新建独立会话，仅开放当轮public合同/请求与本任务已发生反馈。共享文件系统依靠allowlist流程，不宣称隔离。请求派发、实际调用、原始回复、合法接受、路径执行和回退分别记录。
