# 点功率环境与LLM信息合同

更新：2026-11-09。当前主线为`power_only`、无初始电磁先验、局部时空GP。本文描述信息如何获得和进入决策；物理功率公式及文献见[环境说明](local_power_environment.md)。内部兼容分支不构成当前实验的可用能力，实际公共协议禁止测向、源假设、策略模块和代码执行。

## 功率与点测来源

合成建筑和隐藏动态源由显式配置或`src/uav_em/scenarios.py`生成。当前总干扰功率在三维距离损耗、等效穿楼损耗和有限一次Fresnel反射后，以毫瓦域叠加所有路径与背景：

```text
P_direct_dBm = EIRP_dBm - 20 log10(4 pi d / lambda) - L_buildings_dB
I_dBm(x,t) = 10 log10(10^(background_dBm / 10) + sum(path_power_mW))
y_i = I_dBm(x_i,t_i) + measurement_noise_i
```

当前噪声尺度1dB，定位假设可用。原始读数只有已经发生的位置、时间和功率；没有源方向、距离或周围圆盘扫描。初始只有起点点测，不使用外部初始快照或预先稀疏测量。总功率不是期望服务站覆盖；监测频带中的外部干扰功率可取得是研究条件，未实现期望信号分离。

真实源位置、数量、EIRP、运动/开关脚本，以及真值功率栅格只在仿真与事后评价侧存在；不能进入估计器或LLM。建筑轮廓、高度和净空是独立公开先验，不是由射频读数识别出来的楼体。

## 从点测到局部估计

对有效点测D={(x_i,t_i,y_i)}，GP使用公开背景均值m0和设定的时空相关核：

```text
k((x,t),(x',t')) = sigma0² (1 + sqrt(3) r / ell)
                  exp(-sqrt(3) r / ell) exp(-abs(t-t') / tau)
r = norm(x-x')
mean(x,t) = m0 + k_*^T (K + sigma_noise² I)^(-1) (y - m0)
variance(x,t) = sigma0² - k_*^T (K + sigma_noise² I)^(-1) k_*
```

实现在线性方程求解中加入数值稳定项，不显式求逆；公开预测标准差为非负潜在方差再加测量噪声方差后的平方根。最近64个有效已访问网格点、35s过期、空间尺度60m、时间尺度20s、背景−100dBm、先验标准差15dB均为研究设置。只公开距有效点测80m内的估计，其他功率为`null`；内部背景数值不冒充观测。

80m支持范围不是设备覆盖半径；GP可使用有效窗口中的全部训练点，而`local_training_point_count`只数局部范围内的有效训练网格点。点数不等于独立样本数，`supported`不等于已测或安全，标准差也未校准为安全概率。

`nearest_support_age_seconds`是最近空间训练点的年龄，不是所有GP证据的综合年龄；`nearest_support_distance_m`是距最近训练点的空间距离。普通核可能跨楼体过度平滑，单条轨迹不能保证辨识完整周边场。GP时间回归先验不是源关闭证据；新点测与预测偏差还可能来自空间变化、噪声和估计误差，不能唯一诊断源运动。

## 实际发送给LLM的证据

外部决策接口保存真实公共请求与响应；当前实验保留完整的因果上下文，不沿用旧导航study的删字段压缩。各字段含义如下：

| 可见字段 | 来源 | 必须保持的解释 |
|---|---|---|
| `vehicle`、`time_seconds`、任务/约束/剩余预算 | 自定位、已发生执行和公开任务设置 | 不是未来状态，未模拟定位失效 |
| `map.known_buildings`、边界和净空 | 已知城市几何 | 不包含源坐标或射频真值图 |
| `measurement_evidence.recent_points`、`latest_observation` | 已收到的点测，近期摘要最多8条，另有下述最多32条历史展示 | 每条是一个位置/时刻的读数，不代表该点周围空间均已测 |
| `source_inference.measurements`、`current_fit`、`public_propagation_model` | 兼容字段：最多32条窗口历史点测、公开背景模型残差/拟合摘要和名义模型 | `hypothesis`始终为null，没有启用源定位；不是额外传感器。`measurement_count`统计全窗口，可能大于展示行数；残差点仍来自已收读数 |
| `electromagnetic_estimate.local_samples` | 当前位置附近最多9个可飞网格的GP输出 | 估计/未知/标准差/支持依据，不是实测栅格 |
| `coarse_samples`及`sample_columns` | 当前GP的全域最多5×7稀疏摘要 | 未知功率为`null`；全域采样与总体支持比例可能含建筑格，不代表可飞比例 |
| `estimator`、`information_sources` | 公开模型假设与来源合同 | 超参数不冒充设备精度，预测标准差未经校准 |
| `route`、走廊统计、`probe_candidates` | 已知几何和当前估计上的数值计算 | 路线按此刻快照评分，不预测真实到达时刻功率；候选补测点尚未测到 |
| `execution_feedback`、`previous_memory` | 已发生行动/读数/能耗/求解及该任务模型记忆 | 失败/回退与模型成功分开；记忆不是新增测量或事实来源 |

`information_sources`必须说明各信息来自测量、公开先验还是估计。模型能基于趋势提出待检验方向选择，不能将文字推测或自己保留的记忆当作测得的源位置。

## 当前输出与执行限制

当前点功率基础验证只允许选择`continue`、`replan`、`probe`以及公开预设偏好；采用标准RRT*，重规划可加一个中间点，补测必须引用给定候选编号。中间点只规定搜索端点，不代表安全走廊；数值层仍需对两段搜索与整条路线做几何/能量检查。

文件响应保留`request_id`、`decision`、固定`strategy:{"mode":"baseline"}`及长度受限的任务记忆。不允许测向模块、待拟合源假设、阈值修改或生成执行代码。使用两次搜索通过中间点比单次搜索多用资源，因此本轮仅验证基本可用性，不声称同总预算或固定共同目标下的优化优势。

公共请求按发生顺序发出，仿真等待对应响应；真实墙钟耗时另记，不推进飞行时间。仅固定0.5s悬停进入当前仿真，且不补测/不计入飞行暴露积分。不是实时部署或全任务安全实验。

## 审计与动态闭环

动态源只能通过后续当前位置读数改变在线认识，远处未测变化不会自动被发现。闭环为：点测→局部估计→模型提议→数值求解/复核→短段飞行→新点测。新估计、模型原提议、解析结果、实际行动、规划失败和恢复分别保存。

决策子agent使用新独立会话，只允许读该研究`public/contract.md`、`control.json`、请求及自己的响应。不得读父目录、源码、场景、其他结果/真值图或未来脚本。共享文件系统不构成操作系统隔离，必须如实标注流程约束。
