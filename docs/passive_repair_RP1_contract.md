# RP1 随机开发场配对合同（2026-11-26）

用户本轮授权启动。一次冻结三场，每场各运行一次现有完整数值 N 和一次真实 LLM。主问题是保持现有数值算子时，改用 LLM 调度是否改变实际合法到达与 `T+Q`。每个场景均发布同期 HTML 双图和证据。三场只作开发机制验证，覆盖范围由下述生成法定义。

## 场景与隔离

- 以系统随机生成的三个独立 64 位开发种子依次实例化单侧建筑、横跨原直线的单楼和错列双楼。每类由冻结实现随机确定地面几何、起终点、热点位置、随时间漂移和强度等。另抽每场独立噪声种子。每类只抽一次。冻结只构造参数和公开几何并计算资源，禁止先走路线、测功率、筛真场或根据模型结果换场。封存验证和测试场均不读取或生成。
- 两臂各用相互独立的仿真实例。恢复同一噪声种子，按点测序号取 `N(0,1 dB)` 噪声；分岔后每臂只在自己的位置和时钟取得总功率点测。真实场、未来读数、场景生成种子、另一臂数据及事后图均不进入请求。请求白名单为现有 `RepairToolWorkspace._request` 的工具指令、请求和检查点标识、公开建筑和当前位置及资源、点测前缀与已发生残差、候选、已发生的比较、最近一次反馈和剩余工具预算。冻结清单载两臂共用公开配置、实现与提示指纹以及仿真配置指纹，完整清单留在本地。

## 对照与资源

- 两臂使用现有 `fly_repair` 工具模式、`nominal` GP、单引导点 `via`/`offset`、`compare`、`commit` 和共同复核。先验预测先由新点验证后才更新。沿承诺路查未来到达的第 1–4 秒，存在受支持均值达 −80 dBm 即进入复核。6 秒参照窗口，分岔后共同支持门槛 0.5 秒；未知 Q 为空。起飞选共同初始最短合法余程；已飞加余程累计受原始 `1.25D0`、建筑净空、能量和时限约束。无新补测。
- N 使用完整可见角点及 8 个局部偏移枚举，并试最短可见余程引导点（如适用）。仅对注册新路相对 R0 比价，比较可用时最小化 `ΔT+Δ上尾Q`，仅 R0 完全无报价时使用航时，R0 参与选择。原有数值实现负责排序及平局。LLM 自选生成参数、比较对象和正式提交，包括 R0 或合法而缺报价的余程。合法提交立即结束本检查点，由执行器推进。两臂用同工具及参数域，候选可以不同。模型每轮单独新会话，从 stdin 收到精确公开请求且禁用外围工具；保留精确原文、哈希、事件、诊断、会话 ID 及反馈。采用现有连接配置及其模型标识，推理设置固定为 `medium`，具体指纹见清单。
- 每臂最多 61 个点测及拟合。设 `G = C + 8 + 1`，`C` 为公开图角点数。每场每臂整程几何尝试 `59G`，决策 GP 查询点 `300 + 59×13×(G+1)`，回放查询点单计 `61×网格节点数`。失败和重复生成计入预算。独立新会话没有轮数配额；单次故障截止 180 秒，每个 LLM 臂模型交互累计截止 1200 秒。模型等待另列，不计入仿真航时。

## 停止与交付

合法到达、资源耗尽、无合法余程、时限、缺失、错绑或无效回执按执行器规则关闭该臂。可修的工具参数或几何拒绝由工具返回给模型。中止保留已执行前缀与原始回执。每个预抽场保留首次结果，禁止在本合同下补跑、换场或由 N 代选。各场互相独立，一处早停不改变其他场合同。

每场一份 `replay.html` 和 `evidence.json`。左图是逐帧事后真场与实飞折线，右图是当时点测、GP 支持范围、候选、调用、反馈与提交。各臂停在自己的实际终点或中止位置，未飞候选留在候选层。先给回放链接，再按场报告停止原因、实飞 T 和 Q、资源以及真实模型调用。只有双方合法到达才报告 `Δ(T+Q) = LLM − N`。全程无触发须明确记录零模型调用。保留三场全部结果。
