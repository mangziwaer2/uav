## 问题与环境条件

建议研究表述：**部分可观测时变电磁干扰环境下，基于LLM与数值反馈的无人机航路修复优化。** 给定已知城市几何、起终点、可用自定位及任务预算，UAV沿航迹获得带噪总干扰功率；局部GP提供估计、未知和证据时效。LLM选择可检验的搜索操作，数值层求解并复核，执行后根据新点测重规划。

不预先测量完整或稀疏电磁地图，不要求地图编码，不以训练感知网络为前提。隐藏源及未来脚本不进入决策。建筑损耗、有限一次反射、多源叠加、源运动/开关构成这里的复杂电磁机制；不是全波电磁兼容、硬件损坏或失联控制研究。

局部信息不确定是问题条件，不能由此推出LLM必然必要或优于数值方法。研究要检验的是：在同样的信息、任务目标和总求解资源下，LLM能否更有效地分配有限的修复搜索，并通过数值反馈改进结果。

## 候选贡献一：电磁观测条件化的修复操作选择

将新点测与原估计差异、证据支持/时效、当前航路暴露分布及剩余能量转换为**修复范围和操作参数**，而非每次整条重搜或固定方向大绕行。拟议输出包括要替换的航段、保留连接端点、操作类型、搜索区域和资源分配。第一版新增独立修复协议，不混用基础动作解析器；已支持连接点区间、操作、采样盒与预算。

先限定少量操作：局部接回、替代走廊、可行快捷连接、必要时全局重搜；现有基础模式可补测，新修复模式暂不接入。当近期点测显示前方代价上升而侧向区域未知时，模型可以提议局部侧绕或先补测；它不能把这一证据直接断言为某个源移动，也不能假定未知走廊安全。操作参数必须落到实际搜索与整条拼接路线复核，理由文字本身不算操作有效。

待验证机制是：利用电磁证据位置、时效和可辨识性，选择**哪些航段值得修复、哪些部分可以保留，以及何时应先获取新点测**，减少无效搜索和不必要绕行。局部修复/图复用本身已有研究，不能仅凭LLM调用或换算法名称宣称创新。

## 候选贡献二：固定目标下的数值反馈推理优化

在一次决策的冻结观测快照上，LLM提出操作，数值层返回可行性、路径长度、估计干扰代价、不确定性项、能量、资源消耗以及失败原因。模型在有限轮次内修订操作；统一接受器只按同一目标与约束比较候选，保留当前最好的可行路线。

“推理优化”体现为结构化提议—数值检验—基于差值修订的可复核过程，不要求公开思维链，也不以长解释代替收益。操作失败保留原始反馈；原路线仍可行但候选无改进时可以保留原路线。观测更新后必须重评旧候选，不能声称动态全过程代价单调下降。

通用LLM反馈循环与超启发式已有研究。这里待验证的贡献在于电磁观测条件化的修复结构、有限预算分配及其实际优化效果，而非“首次让LLM选择算法”。必须以同操作集合的数值自适应、LLM单轮和LLM多轮对照证明反馈价值。

## 共同目标与约束

第一版固定使用同一当前快照目标，不再由LLM选择评价profile：

```text
J_t(route) = integral_route [1
  + 2.0 * clip((GP_mean_t(x) - reference_dBm) / 10, 0, 4)
  + 0.4 * clip(GP_std_t(x) / 15, 0, 2)] ds
```

其中`ds`单位m，参考值固定−80dBm，未知位置仍用公开背景先验与15dB不确定性供数值计算，公开输入继续标`null`。这是估计图上的研究性搜索目标，不是真实未来暴露或安全概率。闭环事后评价另报真实航程、暴露秒数和dB·s，不能只报告J改善。

模型只能改变修复区间、搜索操作及参数，不能改变上述权重、参考值或能量上限。本轮基础演示中profile可变，因而不作为下一阶段共同目标优化的证据。

几何与能量由数值层复核。强干扰只按当前研究软参考处理，允许穿越不等于设备可安全穿越；若后续任务允许有限暴露，应先明确定义超参考秒数或dB·s容忍，并独立记录真实违反。当前没有硬暴露约束、任务截止时间、最长连续暴露预算或通信中断模型。

当前航路评分使用此刻估计快照，不预测到达时刻的真实电磁场。若后续引入时序预测，只能来自历史观测并需报告误差，不可读取源未来脚本。部分观测条件下不声称胜过完整静态真值图上的精确最短路径。

## 第一版具体实现合同（已落地，范围见独立说明）

1. 数值层把剩余路线分成有编号的连接点与区段，提供每段长度、估计代价、支持比例、年龄、附近近期点测和预算；候选连接点来自当前路线，不读隐藏源。
2. LLM输出`start_id`、`end_id`、`route_version`、`operator`和受限参数。首版操作集固定为：快捷直连、局部RRT*接回、经一个中间点的局部侧绕、全局RRT*重搜。侧绕替换指定区间，区间外路线保留；所有拼接边重新检查。补测仍是独立飞行动作，不混成获得免费信息的修复算子。
3. 每个决策点冻结一份GP快照，最多3轮提议/反馈。反馈包含全路线`J`及相对当前最佳的差值、长度/干扰/不确定性分项、几何与能量可行性、已用资源和失败原因。不给真实未来积分。
4. 统一接受器仅在全路线可行且同一J更小时替换当前最佳；没有改进保留已有可行路线。观测更新后重评，不跨快照宣称单调改进。
5. 首版预设每次决策总上限2100次采样提议和10000次规划边评价，所有轮次、两段中间点搜索及恢复共享台账，先耗尽任一预算即停止搜索。快捷连接也计边评价。数值对照享有同样操作与总资源；单轮LLM可用全部预算，多轮最多分3轮，不能各轮重复获得完整总预算。这些数值已用于新第一版集成试验的冻结开发预设，不是旧点测基础试验的预算，也不代表统计验收已完成。

这一定义使优化落到可执行的航路替换、同目标改进量和总资源消耗。若当前信息不能支持可靠选择，应在同信息条件下分析失败；不直接向模型添加真值方向。未来创新是否成立由受控实验决定。

## 验证设计与当前缺口

新独立强LLM的两场景基础验证已完成，出现点测驱动的补测与绕行，均到达；动态例仍有明显暴露，且终点本身高于参考。第一版区段修复也已完成集成验证，但没有避强提升证据。对照共享感知接口、噪声设置和估计器，不同轨迹产生不同读数；最新程序比较增加同快照配对，以区分计算接口和闭环观测变化。基础演示不是论文创新实验。失败时先区分策略、求解、预算与信息可辨识性，不直接添加真值信息。

正式方法比较固定传感器、估计器、几何先验、任务目标和总搜索资源，设置：全局重规划、数值局部修复、同操作集合的数值自适应、LLM单轮、LLM多轮反馈。统一统计总搜索扩展/边评价/候选次数，另报LLM调用、词元和墙钟耗时；只统一单次迭代数而放任多轮增加总资源不构成公平比较。

开发场景冻结方法后，使用新场景、多随机种子及噪声/变化速度敏感性检验；分层看建筑反射、多源、静态和动态源影响。区段选择、反馈和保留候选分别消融。不将单个可视化、到达率或格式合法率当成LLM优势。模型时间不推进飞行的仿真不能用来声称实时性能。

当前已有点测、GP及第一版区段修复、拼接接受器、同点多轮反馈与统一预算。新模式暂未接主动补测，不做树持久复用；这些不能写成已完成。后续缺强数值自适应对照、多场景多种子和区段/采样/反馈消融。新颖性仍需系统相关工作检索，以下文献不是穷尽综述。

## 论文贡献的候选表述与验收

2026-11-10补充讨论。以下是后续研究假设，不是已经实现的能力或已确认的新颖性。当前程序比较只组合研究者预先实现的参数生成函数，没有离线LLM生成算子、程序内条件搜索序列或稳定避强优势。

仅由LLM离线生成一个好算子，再固定用于飞行，可以研究自动算法设计，但不能由此证明在线LLM组合或反馈推理的必要性。若固定算子足以取得全部收益，应如实收敛贡献，不增加没有增益的在线咨询来维持叙事。当前到达率对照已高；需要明确改善干扰—航程—搜索/咨询开销的哪一项及其权衡。

推荐的主问题为：在同样的局部点测、固定估计器、共同任务目标和总求解预算下，LLM能否根据电磁证据的支持/时效与数值反馈，构造适合当时状态的航路修复过程，改善动态闭环任务表现？

两项相互配合的候选方法贡献：

1. **面向不完整、会过期证据的修复算子设计。** 离线生成时明确区段、观测支持/年龄、未知标记及已发生搜索反馈接口，以闭环任务指标评估；保留在不同观测状态下互补的算子。可以研究给算子附带可计算的适用条件与资源申请规则，但适用条件不是安全证明。这需要新的任务相关表示、评价或算子机制，不能仅把通用ReEvo换一批地图就宣称方法创新。
2. **证据条件化的可执行修复过程与数值反馈修订。** 在线输出有限的算子顺序、条件分支、修复范围和资源分配；求解器计算数值，反馈几何失败、无改进、预算耗尽和代价分解，模型据此改过程。所有候选共享同一目标、约束和总预算，不由模型改权重或获得新真值；具体控制语法和实现尚待收敛。改善的是规划求解过程，不是声称加速LLM本身的推理。

复杂电磁必须实际改变规划问题：同样建筑下，源运动/开关、多源叠加和传播遮挡使观测证据及其有效性发生变化。应按机制分层评价并做消融，而非只把障碍地图改名。不能由标量功率升高唯一推出源运动/位置，也不因支持不足就宣称侧向安全。

| 待支持的主张 | 必须对应的受控比较 |
|---|---|
| 生成算子有贡献 | 固定调度流程：人工规则 vs LLM生成算子，记录离线生成/筛选成本 |
| 在线组合有贡献 | 固定相同算子库：最佳固定算子/固定流程、数值自适应调度、在线LLM组合 |
| 反馈改进过程有贡献 | 单次组合 vs 数值反馈修订，严格共享总搜索上限，另报咨询代价 |
| 证据时效/支持处理有贡献 | 保留/移除相应字段或处理规则，分析陈旧证据与未知区域案例 |
| 适应动态电磁环境 | 未参与开发的布局、源动态、噪声与种子，报告到达、航程、暴露和计算开销 |

传统主对照同样使用当前GP、干扰代价和任务预算，不能只与忽略干扰的RRT比较。完整真值规划只作明确标注的参考。开发与测试按场景分离，冻结后不看测试结果反复改算子；闭环轨迹不同会带来后续观测不同，配对快照与完整飞行需分别报告。

“安全到达”在当前模型中应具体写为满足几何/能量条件并按软代价评价干扰暴露；未定义设备失效或硬暴露边界，不能据到达推出硬件安全保证。仿真和复现实验可作为论文实验贡献，不自动构成新的传播模型或新的GP方法。
