# 研究方法与实验备忘录

## 当前主线：LLM 调用算子重规划

**首轮只改变运行时的调度者。** E3 已给出数值规划合规绕行并到达的证据。现在让真实 LLM 直接使用同一套数值工具，决定用什么参数生成候选、看哪次比较、提交哪条未飞余程，检验实际全程 `T+Q` 是否下降。GP、几何补全、风险计价、硬约束和总资源由运行合同固定。后续若研究 LLM 修改算子源码，在独立实验中冻结原版与改版，用同一数值调度先比较工具版本的收益或退化，再比较各版本上的 LLM 调度效果。[首对实验操作说明](passive_repair_tool_pair_draft.md#首对实验的执行顺序)

| 工具提案 | LLM 可决定 | 共同工具返回 |
|---|---|---|
| `generate` | 当前用 `via` 指定一个图外引导点，或用 `offset` 指定前向距离和横向偏移。 | 从当前位置经提议几何补全到原 `goal`，去重并核连续净空、已飞加余程、到达时间和保留能量。合法则给路线 ID；否则返回具体失败原因，允许修改提议。 |
| `compare` | 选择要查询的路线和参照，例如当前承诺路；可在弱证据时先比较彼此不同的走法。 | 固定当时的 GP 和参照时间片，返回完整余程 T、分岔后共同覆盖、期望与上尾 Q、缺支持及窗外时长。新增路线不能改写旧比较；不跨不同时窗做总排名，不把未知填零。 |
| `commit` | 明确提交一个已核验的余程 ID，包括保留原路。 | 绑定当前点测前缀和路线版本，复核全路约束，只执行最终提交的余程；不按 GP 名次否决合法选择，不用 N 代选。 |

预警触发后，即使初始菜单只有承诺路，也能进入生成阶段，否则漏路场景永远测不到这个机制。工具交互在同一暂停的检查点内：先给公开建筑、当前位置、承诺路、余量、点测及已发生的预测残差；LLM 提议并根据反馈再次修正，只有提交后才推进飞行。期间没有新实测。GP 仍按原有的先验证冻结预测、再更新顺序工作，不把派生点回灌为测量，不宣称从单侧读数推断出了另一侧真值。调用次数记录、不设 LLM 咨询次数硬上限；共同工具资源和停止条件须在新合同中冻结。

**先用现有算子，观察 LLM 如何改变搜索。** V1 先用单引导点与可见图补全，检验 LLM 能否按反馈换方向或缩短前视。若记录表明现有工具确实表达不了所需走廊，再考虑删段重连、多引导点或树结构。Karaman 与 Frazzoli 的 RRT\*（arXiv:`1105.1186`）可作树扩展参考，但渐近最优不等于有限查询时能给出多条优路，重接还会改变下游到达时刻。多走廊生成及 LLM 算子调度的参考见[文献表](#优先复现的已有方法)，都不是下一对试飞的前置任务。

**LLM 分配余量，不改硬上限。** 令 `L_min` 为当前求得的最短合法完整余程，LLM 可指定本轮愿意额外探索的绕行距离，并按反馈逐步扩大，最大不超过 `1.25D0 − 已飞距离 − L_min`，仍另核时间和能量。合成第 2 秒 `D0=180 m`，已飞 `30 m`，最短余程 `150 m`，所以有 `45 m` 可分配；可先找只多飞 `15 m` 的走法，不合适再扩，不能把总上限改成 `1.4D0`。`1.25` 若要作为研究变量，应在另行冻结的对照中给两组相同上限，而不是让 LLM 逐场放宽条件。

**V1 已通过接口验收。** [夹具双图](../outputs/development/synthetic_llm_repair_tools/index.html)默认打开第 1 秒。只有承诺路 `R0`，模拟回执先提议 `(770,145)` 落入建筑，收到拒绝后改用 `forward_m=50`、`lateral_m=-32` 生成经 `(705,68)` 的 `R1`；比较后提交，执行器沿这条完整余程实际推进，夹具航迹通过引导点。此点不是旧固定门或在线默认菜单中的候选。输入和反馈按回合冻结，每回合保留收发哈希、原始回执及会话 ID；没有真实 LLM 加入，不算任务收益。

## 论文规划（2026-11-26）

**拟题《局部功率观测下的无人机路径重规划：大语言模型反馈驱动的算子调度》。** 主问题是，在相同观测规则、可用工具和总查询预算下，真实 LLM 根据本轮反馈选择下一次搜索和最终余程，能否在维持合法到达率的同时，降低实际全程 `T+Q`？适合检验模型作用的时刻，是一次候选比较已经完成、还有搜索余量、而反馈允许多种后续动作的时候。已知两条候选在分岔前的报价几乎相同，和两条候选在分岔后仍有充分可比证据，对下一次查询的价值有不同含义。数值策略同样可以利用这个区别，因此需要正面对照。

| 环节 | 建议交给模型的决定 | 能检验这一决定的证据 |
|---|---|---|
| GP 与观测 | 读已发生的点测、旧预测残差和支持情况，决定接下来比较哪组路线。首版由共用工具固定核、噪声、支持判据和后验版本。 | 新点验证旧预测；同时记录比较到底覆盖多少分岔后的时间。 |
| 分岔与修复 | 选择 `via` 或 `offset` 及其几何参数，在合法余量内调整尝试范围。 | 相同生成预算下得到多少不同的可执行首分岔，哪些实际提交并推进。重复路线和失败尝试也计入消耗。 |
| 风险比较与提交 | 指定候选和参照，读完整余程 T、同窗期望及上尾 Q、缺支持与窗外时长，决定继续搜索、换参照或提交（含保留原路）。 | 同一参照和锁窗内记录报价变化，终点记录真实 T 和 Q。不同参照的局部报价各自保留。 |

**首版的算子计数。** `via` 用坐标指定引导点，`offset` 用相对承诺路首段的偏移指定引导点，两者共用同一种单引导点路径修复。两次提议得到同一条余程时，各消耗一次几何尝试，共用一个路线 ID。首对开发配对逐次核对工具回执，分别记下模型是否修改参数、是否生成几何上不同的余程、是否提交并实际推进。不同 ID 仍可能共享首段，应结合分岔时刻解释。两臂在同一检查点各自编号，跨臂比较需核对实际几何。静止验收用两种参数化以相反顺序提议同一点，检查去重、几何计费及生成阶段的 GP 查询数。

**优化推理的例子。** 某提议多飞 3 秒，分岔后的共同支持段估计只省 1 单位 Q。按该估计，其余路段还得再省约 2 单位才打平。模型可以把下一次几何提议用来减小绕行时间，再从同一参照查询，或直接提交原路。记录中可核对第二次提议实际改了什么、工具怎样报价、最终飞了哪条路。若只测到两路分岔前的共同段，证据只能说明共同段的暴露；允许模型给未飞侧编一个 Q 会让这个问题失去检验意义。

**文献给出的定位。** Barbosa 等已用局部带噪采样、GP 风险和事件触发重规划（CDC 2021，`arXiv:2109.11287`）。Liu 等的 LLAMBO 把候选提议从代理估值中拆出，可借鉴其按既有评价提出下一组参数的设计（ICLR 2024，`arXiv:2402.03921`）。Raoofi 等已让 LLM 根据结构化搜索状态调节 ALNS；其等迭代实验也报告了较高计算开销（*Systems* 2026，`10.3390/systems14101200`）。本项目可检验的区别是，工具只能为候选的部分余程报价，选择实际推进后又会改变下一批点测。论文贡献取决于这种条件下的完整任务结果。

**从一次开发配对到论文证据**

1. **整程机制已完成开发验证。** [RP1](../outputs/passive_repair_RP1_20261126/findings.md)在三个预抽场使用同一 GP 和单引导点修复，包含 LLM 改路后改善、保留原路后改善和改路后退化。三场用于诊断链路和建立后续假设。
2. **再检验哪部分值得用 LLM。** 后续独立合同保留完整枚举 N，并加入能看到同样反馈的数值自适应调度，例如借鉴 Ropke–Pisinger 按历史表现选择算子（*Transportation Science* 2006，`10.1287/trsc.1050.0135`），为不可比报价保留独立状态。优先做两项消融：一是数值生成同一组候选，分别用数值规则与 LLM 提交，测选路作用；二是让 LLM 在看到本轮工具反馈前一次列出搜索提议，按序执行后仍可看完整结果提交，与可逐次修改提议的 LLM 比较，测反馈对搜索的作用。预定提议与结果的绑定、失败处理和两种模式的总工具额度都提前固定。
3. **最后判断能写多强的结论。** 另立多场协议，先定最小有意义的 `T+Q` 改善、可接受的到达率差、场景数、噪声及模型重复规则、主要数值对照和统计口径，使用独立的新评估场景。以场景为独立单位，场内重复配对汇总；全样本列合法到达与停止原因，双方合法到达的配对才估计 `Δ(T+Q)` 及其区间，同时列 T、Q、几何尝试、GP 查询、模型往返和墙钟时间。若只节约查询，可就查询效率写结论；若仅胜枚举而与反馈数值策略持平，证据支持自适应搜索，尚不足以主张 LLM 独有增量。该路线图只规划研究，运行与场景访问沿用现有授权边界。

## 研究备忘录：未知路段怎么选

以下保留已有证据、方法备选和参考文献，不是下一次运行步骤。当前接手顺序只看[交接](AGENT_HANDOFF.md)。

**2026-11-24 讨论稿，不是实验合同。** 我们要降低实际飞到终点的全程 `T+Q`，不是画出一张看似完整的功率图。当前建议是：**沿候选路线，只对有证据、可比较的那部分暴露报价；完整计入航时；把还有多远看不清写出来。** 以下路线可以随证据改变，正式运行前再独立冻结。既有试跑和事后诊断不随建议改变。

### 1. 三种量不要混为一个 Q

| 量 | 回答什么问题 | 不能据此说什么 |
|---|---|---|
| 全程真实 Q | 实际航迹沿到达时钟积分 `10^((dBm+80)/10)` 到终点；只供事后任务评价。 | 不能供在线排序，也不能把未飞分支算作模型取得的成绩。 |
| 共同支持 Q | 在同一决策时刻，用冻结 GP 对各条仍在飞的路线**同一组时间片**积分。E2 的在线分数是完整剩余 T 加这项 Q。 | 有支持仍是预测，不是已知真值；局部代理既不是完整 Q，也不是完整 Q 的保证下界。 |
| 未定价部分 | 分开记窗内该路线无支持、该路线有支持但别路缺证据、窗外仍需飞行的时长；另标首分岔之后双方真正可比的秒数。 | 未定价不等于零暴露，也不应一律按危险区或禁飞区处理。 |

**划的是时空适用范围，不是积分一个地理圆。** [当前 GP](../src/uav_em/passive_map.py)在全图都能返回均值和方差；离已有点测足够远时，当前核使后验回到固定先验。E2 用相对先验方差缩减至少 10% 标记支持，40 m 和 35 s 仅区分近测与延伸支持。[当前积分](../src/uav_em/passive_event_choice.py)按每条路线到达该点的时刻判定支持，取 6 秒窗内所有仍在飞候选的交集。阈值是现有约定，不是已经验证的误差保证。第 6 秒两条路线立刻分岔，4.5 秒共同支持上的上尾排序仍与事后余程优劣相反；扩大半径并不能解释这个反例。见[公开复核](#第-6-秒路已分开为什么没选绕行)。

**一个容易忽略的比较错误。** 假设等航时的 A、B 两路，前 2 秒都支持、预测功率都为 1；随后 4 秒 A 仍有支持、预测也为 1，B 未知。各积各的会得到 A=6、B=2，凭空奖励 B。公平的表达是「共同 2 秒：2 对 2；后 4 秒：仅 A 有证据」。反过来，新增一条几乎无支持的 C，也不该抹去已有的 A、B 比较。建议保留原菜单的比较记录；检验图外提议时，以当次明确选择的合法路线为参照，预先锁定比较时间片和最低分岔后覆盖。提议若在要求的时间片仍在飞却无支持，记**证据不足**，不缩窗宣称改进。不同时间片的成对分数不能拼成全菜单总排名。

可给决策者一个有单位的折中：绕路多飞 3 秒，那么它**全余程**必须节省超过 3 单位真实 Q 才值得。若共同段暂估只省 1，则仍有约 2 单位要靠未定价段才能打平，且共同段估计也有误差。记录这笔差额，比替未知段编一个功率更有用。没有正面证据时仍可因航时或其他预定规则明确选择合法路线，但理由不能写成“更安全”。

### 2. 局部 GP、全图 GP，还是 MLP？

| 方案 | 现在的用途 | 什么证据会改变判断？ |
|---|---|---|
| **局部可信范围内计价** | 主线。保留 E2 基准；先检验“支持”是否真的筛出了较可信的预测，而非再选一个半径。 | 按预测提前量、相对历史航迹的横向距离、近测/延伸支持分组。只用后来真实飞到的点核验冻结预测，报告样本数、dBm 偏差、误差和预测区间覆盖率（与带噪点测比较要计入测量噪声）；同时报告能覆盖多少分岔后的可比时间。分组没有样本就标未验证，不用在轨误差代证横向误差。 |
| **全图 GP 输出** | 可将均值、方差与支持掩膜叠加展示，帮助读者看清哪些值只是先验；不把全图都标成已知，不按最近点延拓。 | 只有新场景的真实点测能支持原适用域外的误差水平时，才考虑预登记扩域。若若干环境解释对已见点同样合理、对两条路线却给相反排序，就分别报告；没有依据合并时，结论是无法区分。 |
| **MLP 直接给整路风险** | 暂缓。输入可以定义为已发生的点测、建筑和带到达时钟的候选，但标签必须先说清是全程 Q 还是局部 Q。只飞了一条路，另一条路就没有实测标签；用 GP 输出当标签学到的是 GP 的评分，不是独立的环境证据。 | 只有以后另获训练授权、有独立且匹配的历史数据、能按整场而非随机相邻点留出评估，才值得对照。同公开输入下须优于 GP，能报告何时不可靠，并证明排序改善能传到实际任务成绩。当前不训练，也不引入隐藏源或事后全图作决策输入。 |

### 4. 要做的事与改方向的条件

1. **先问证据够不够。** 根据已有公开决策包，整理一张分岔表：首分岔时刻、最后可换路时刻、完整剩余 T、共同 Q、分岔后共同秒数、单侧和未定价时长、之后在哪条实飞路线上验证到了什么。对已过最后可换路时刻的证据，不能算作当时可用。只做既有材料诊断，不在已见场调参。
2. **按失败类型决定改什么。** 若参考有合法低暴露余程而菜单缺路，优先做几何生成；若菜单已有好路而两侧不可辨，先做适用域和风险校验；若有可比证据却决策差，才重点比较选择器；若有界参考也没找到，记“在此搜索域未找到”，不声称无路。后验参考只做离线归因。
3. **把图外中间点实现为一种修复算子，而不是新终点。** 先做数值版本：删一段未飞路径，经一个图外点重新接回、补全到 `goal`，重算下游到达时钟，核建筑、全程 `1.25D0`、能量和时间。先看同预算是否多出可执行的、真正不同的首分岔；若只是同路换点，不扩大算子库。机制分别参考 Zhou 的多通道搜索、Ropke–Pisinger 的破坏/修复，见[复现表](#优先复现的已有方法)。
4. **先调通 LLM，再验证增量。** 开发不要求每次同时跑 N；让 LLM 主动调用算子改变候选，合法选择能执行，失败能归因。正式比较共享工具与规则，不要求候选菜单相同。见[当前主线](#当前主线llm-调用算子重规划)和[决策权与预算](#下一轮的决策权与预算)。

第 1 项的[分岔证据表](#e1e2-分岔证据表)已用公开日志完成。其他项是诊断选项，按实际试飞暴露的问题取用，不是试飞前置清单。本备忘录不授权新运行、模型调用或训练。

## 目标与边界

任务是从当前位置重规划未飞路线。任务层评价为全程 `T+Q`：航时 `T` 加沿实际到达时刻积分的归一化线性功率暴露 `Q`。−80 dBm 在 E1 同时用作软参考与预警线，并非失联或禁飞阈值。航程按原始全程 `1.25D0` 限制，已飞距离不能清零；建筑净空、到达终点、能量和时间上限均由共同工具约束。

在线只用已知 2.5D 建筑、当前位置带噪总功率点测和据此冻结的时空 GP。新点先检验旧预测，再更新。GP 支持表示可用于定价，不表示安全；GP 派生点不是独立测量。未知不填 0、1 或最近功率，也不作低风险断言。若同时评估互斥环境解释，分开评分，不拼成同一个真场。隐藏源、全图真值和未来点测始终不进入在线决策。

## E1 已执行

1. 沿承诺路线查询前方 1–4 秒有 GP 支持的均值。从未越线到越线时复核，持续越线本身不重开窗口。
2. 枚举合法余程，按首中间点组织分岔，原路保留；再试一次删首点并重连。这里的枚举针对离散候选，不是连续空间全局最优。
3. 用 `T_window + Q_common` 比较同一菜单：`T_window = min(完整余程航时, 6 秒)`；`Q_common` 只在窗内所有仍在飞的候选均有支持的公共时间片上积分线性功率逐点上尾均值。完整余程航时、各路线未支持时长和共同覆盖单独记录。窗外未定价，不表示窗外无暴露。这项窗口评分不是全程 `T+Q`，也不能证明某条路线安全。
4. 强 N 在同菜单最小化窗口评分；LLM 必须明确给出一个合法路线 ID，原路也是有效选择。执行后，两臂分别以真值核算全程 `T`、`Q` 与硬约束。[冻结合同](passive_event_choice_E1_contract.md) · [结果与回放](../outputs/passive_event_choice_E1_20261124/findings.md)。

### 第 6 秒：路已分开，为什么没选绕行？

只读复核使用[公开输入](../outputs/passive_local_hotspots_E2_20261124/public_inputs.json)、[第 6 秒决策包](../outputs/passive_local_hotspots_E2_20261124/packet_E201-01.json)和[公开飞行记录](../outputs/passive_local_hotspots_E2_20261124/public_numerical.json)。所用 GP、几何和定价模块与 E2 冻结哈希一致。用 0–6 秒未舍入点测恢复当时后验；16 条候选的共同 Q 均与决策包三位小数相符。未调用真场、生成新观测或重飞。

E2 按候选实际到达时钟，每 0.5 秒取区间中点。支持要求相对先验的方差缩减至少 10%；40 m 和 35 s 只区分近测支持与延伸支持，不是积分半径。Q 在 **沿线时间** 上积分，不是对地图面积积分。令 `D` 为该时空点 GP 的 dBm 随机量，`p=10^((D+80)/10)`；正式代理取 `p` 分布最高 5% 的条件均值再积分，不是整条路线积分的 CVaR。共同窗外不定价。全程评价则沿实际航迹对真实 `p` 积到终点，不加上尾项。

## 下一轮的决策权与预算

**旧预算是什么。** E1/E2 除共同起飞规划，原合同每臂最多三次事件复核；LLM 臂每次复核对应一次咨询。用完三次后沿先前已承诺的合法余程走，不是改让 N 选路。两组轨迹相同时，公开回执显示是 LLM 自己选择了和 N 相同的路线，不是数值回退。旧合同另有点测、GP 查询和等待上限；它们与飞机实际可飞的航程、能量、时间不是一回事。已关闭的实验不改、不重跑。

**先测效果，再测调用效率。** 开发时，几何、触发和回执可分别做确定性测试；调试 LLM 决策链不必每次同时执行 N。新科学运行或独立实验 LLM 咨询仍须先冻结合同、公开输入、强 N、资源和停止条件。需要主张 LLM 增量时，主配对仅为 **数值 N vs. LLM**。从相同初始条件出发，使用相同的公开信息规则、生成工具与参数域、共同定价、硬约束和选路机会规则；控制器决定搜索方向，因此可生成不同菜单。两组若走出不同轨迹，各自只能使用当时当地已发生的点测，实际选路时刻和次数可不同，不强行对齐。每次规则规定需要选路，N 组由强数值法明确决定，LLM 组由 LLM 明确决定。**不设每飞行/场景的 LLM 咨询配额，不继承旧三次复核上限，也不把公共工具的整程配额设成变相的三次上限。** 两组的共同工具及单次候选搜索边界对齐；建筑净空、全程 `1.25D0`、能量、飞行时间和到达终点的硬约束不取消。

**合法选择就执行。** 共同工具核路线和硬约束，不用「N 选了别的」「共同 Q 没改善」或「预测支持不足」覆盖 LLM 的合法选择。证据不足要正常报告，不能填零或宣称更安全；即使选原路也必须由 LLM 明确选，不提供弃权后转交 N 的选项。没有合法替代动作且规则不要求作选择的继续飞行，单记为无选路机会，不算一笔 LLM 决策。缺失、无法取得有效回执或其他中断按新合同如实记作该臂未完成，保留已完成合法进展，禁止 N 代选补完。记录每次机会、是否调用、明确选择、实际执行和调用等待；主结果是实际全程 `T+Q` 和合规到达/失败。调用次数和墙钟先报告，不用来压缩参与；是否够快、如何少调用，留到看见任务效果后另做实验。新合同仍须独立冻结公开输入、共同资源与停止条件。

## 计划：选路与触发

让 LLM 看到可区分动作的证据，而非只给路线长短：首分岔位置及最后可换路时刻、完整余程航时与资源余量、分岔后共同支持上的暴露差、单侧支持和未知时长、相关原始点测与冻结残差。优先核对差异是否落在可控的未飞路段上。所有路线都有暴露时，在合法余程中选有证据支撑的折中；没有足够证据时，不能把较短路线说成较安全，也不强迫换路。

已用[公开日志](#e1e2-分岔证据表)确认持续预警时仍可能出现实质不同的可执行首分岔。下一步用两组共用的规则识别真正需要决策的机会（例如持续预警中出现实质不同的合法走法），而不是每秒咨询，也不因证据弱而把已经要求 LLM 作出的选择交给 N。触发不能借用未来观测，路线重编号也不构成新分岔。不用本审计调整 E1 阈值后重跑。

后续若提出互斥局部解释，独立评分，不把未知段直接定价为低风险。强 N 共享新增证据；在相同证据下仍用配对实际 `T+Q` 衡量 LLM 增量。

### 优先改进的两处

1. **让选路发生在走法还可执行时。** 持续预警时，出现几何上不同、仍可合法补全到终点的首分岔，就提供一次实际选路机会，不等预警重新越线，也不把路线重编号或近乎同轨的重连当新机会。首分岔将关闭但仍有选择时，不为等更高置信度漏掉它。几何变化用当前可检验的前缀和剩余资源定义；历史日志的末见帧只用于审计，不是在线输入。调用由事件决定，不是配额。
2. **给 LLM 分岔证据，而不是只给综合名次。** 以原路为参照，分开列完整余程 `ΔT`、分开以后同窗的线性功率期望差和逐点上尾差、窗内缺支持与窗外未定价时长、已发生的原路点测趋势及冻结残差。上尾与期望使用相同支持，分数不互相替代；两者分歧时明确暴露排序依赖哪种风险度量。若 `ΔT > 0`，给出绕行必须节省的全余程 Q；支持不足时写「无法证实」，不把它变成淘汰规则。保留原有 GP、真值评价和硬约束，先判断信息表示和时机是否帮助了决定。

使用现成公开材料与确定性夹具先验证：重复编号不误触发、持续预警下新走法不漏触发、分岔前共同段不替分岔后的证据、未知不填零、合法 LLM 回复不被数值覆盖。新开发场结果按「没触发」「菜单缺路」「有路但证据不够」「有证据却选错」分开归因。仍找不到有效合法候选时，加图外点修复算子；有好路却依然排错时，优先检查 GP 的在轨误差、分岔后支持和已发生残差，而不是盲目加候选、扩大到全图或更换 MLP。开发版用实际合法到达和全程 `T`、`Q`、`T+Q` 看办法是否可用；有了可复验的任务效果，再用两组对照归因，不以改道率或一次低分替代增量证据。

**单步实现。** 持续预警时，原菜单和共享算子生成的合法整条余程共同用于触发；比较双方仍在飞的未来 6 秒，按距离判断是否实质分开。记录已比较分岔的两侧首目标，跳过同方向的共线插点，预警结束时清空；它是首目标去重，不是完整走廊拓扑鉴别。风险计价仍只用原菜单冻结时间片。两组用同一动作清单判断是否有机会，但只运行当前臂的决策方法。实现已用模拟回执和合成地图验证，不属于新试飞。

## 计划：图外中间目标

**状态：局部算子、同表选路、整程回放已通过合成测试，未试飞。** P7 的中间目标只是已有路线的内部顶点。当前算子用 `left`、`right` 指定未飞余程上两个保留顶点，中间顶点由直连或两条经过一个图外引导点的新边替换；其余顶点、飞行高度和终点不变。共同工具把每个合法结果登记在冻结表中，两组都选 `action_id`，不在回执里重新提交几何。当前只验证局部重连，不判断对同一点是否还存在更复杂的合法绕法。

1. 公开包只序列化一次，由受信接收端对实际送达字节核 SHA-256 后才交给新会话。保留原始回执、收发哈希和会话 ID，回执只能用于同一请求和飞行状态。共享算子在登记动作前核整条未飞路的建筑净空、原始 `1.25D0` 上限、已用时间和剩余能量。无有效回执或返回表外 ID 均没有新的可执行选择。
2. 在同一冻结 GP 下，先以原菜单锁住未来 6 秒内的共同支持时间片（0.5 秒网格并切开原路线到达时刻），新增路线不改变它。新路线按自身到达时钟取样，已到终点的部分没有飞行暴露，不是未知。新路线在锁定片仍在飞却无支持、原菜单没有风险证据，或完整分岔后时间片未达预定最低覆盖时，均不报风险差和综合分；否则报期望和上尾的 `ΔQ`，以完整剩余 `T` 加锁定片上尾 `Q` 排序。不把窗口外或未知补零。比较结果不否决 LLM 的合法选择。
3. 整程先用共用最短合法余程起飞。每次新点测先验证已冻结的到达预测，再拟合 GP，之后才预警和复核。合法选择不因数值得分或缺风险证据被覆盖；下一步冻结预测必须仍有公共查询额度，才实际推进。公共动作表算不完整则两组都停，不从半张表选；已承诺但未推进不算飞行，途中停止只核已飞前缀。渲染用的 GP 网格不进入决策，也不计作决策查询。双图显示原菜单、替换子段、引导点、补全余程和实际航迹；未获得风险证据的路线显示未定价。场景是否存在低暴露走廊另做事后诊断。

**对照。** 公共工具穷举原路线、可行锚点对和公开图外点；相同规范化顶点序列只查询一次 GP，保留每个生成原路及其分岔证据。先冻结完整表，再由强 N 穷举共同上尾目标或由 LLM 明确选择。原菜单完全没有风险证据时，N 在整个合法动作域只按完整航时选，不报 `Q` 改善。点列表和最低分岔后覆盖仍须在新合同冻结，不是 LLM 调用次数配额。额外几何自由度的收益不记给 LLM。

## 在线分岔生成（开发版）

[在线几何域](../src/uav_em/passive_repair_geometry.py)替代固定门作为新开发执行的默认候选源，显式传固定点列表仍走旧域。起飞前保留几何最短合法路线；预警时从当前位置重新生成，不等到岔口。以承诺路首段方向为前方，没有承诺路时朝终点。令 `L = min(6s × 速度, 到目标的直线距离)`，在前方 `L/2` 和 `L` 处各尝试 `±L/6` 和 `±L/3` 横向偏移。另尝试当前可见的公开障碍外角，保留承诺路和最短可见图余程；不读取真场、来源或额外点测。

首段必须从当前位置连续可飞。其后若不能直连终点，接到由障碍净空包围框外角组成的可见图，用到终点的最短图路补全；真实多边形净空仍逐边检查。整路须符合原始 `1.25D0`、剩余时间和能源约束。旧删段直连算子仍可扩展，但不再加手填图外点。有限图可能漏掉凹形障碍间的窄通道，图路也不是连续空间最短路。候选不足就报告，不替不存在的路赋安全性。

候选和原路在未来 6 秒内分离达设定门槛才算实质分岔；持续预警按分岔两侧的离开方向记忆，角度在 10° 内视为已见，不因新坐标重开同一比较。这是粗粒度去重，同向出发后又明显分开的走廊仍需后续覆盖验证。定价仍以当前原菜单锁定共同 GP 时间片，随后直连修复不缩窗；在线原菜单和旧固定域不同，比较时间片可能随之改变。冻结前要验证覆盖、支持、几何开销及 GP 查询上界，不把共同扩域的结果记作 LLM 增量，也不沿用旧固定域报文上界。

[两帧候选图](../outputs/development/synthetic_online_repair_geometry/checkpoints.png)只重建旧合成记录的公开状态。第 1 秒和第 2 秒的局部引导点分别为 `(745,70)` 和 `(760,70)`，原菜单分别有 11 和 10 条合法余程，其中 4 和 3 条与承诺路达到 20 m 分离门槛；这些是几何候选，不是新飞行、选择记录或任务收益。

[固定域与在线域的同点对照](reference/passive_repair_checkpoint_comparison.html)将两个域分别用同点测前缀冻结定价，再沿各候选的到达时钟离线核真值。第 1、2 秒增补 6、2 条低暴露合法余程，两个域仍共同支持前 5 秒。两个时间点的事后最优绕行甚至在**同一段**时间片上也更便宜，但两种 GP 代理均将固定和在线菜单的承诺直飞排在达标绕行前。不能把这两个检查点的失败归因于未知段、扩域缩窗或 LLM 选法。分解均值和方差的影响作为后续诊断备选，不是接入 LLM 的前置任务。

## 优先复现的已有方法

以下是复现建议，不是已实现的算法或新实验合同。先区分风险估计、路线生成和搜索控制，各层一次只换一件事。

| 原始工作 | 先复现什么 | 不能直接移植什么 |
|---|---|---|
| Barbosa 等，*Risk-Aware Motion Planning in Partially Known Environments*（2021，arXiv:2109.11287） | 用沿已走路线的带噪样本估计未知场，以逐状态 GP 风险引导重规划；与 E2 的逐点上尾、融合时间代价作机制对照。 | 原文的风险函数不是本项目的归一化功率积分；不能把一次状态的尾部风险当整航程安全概率。 |
| Zhou 等，ICRA 2020，*Robust Real-time UAV Replanning Using Guided Gradient-based Optimization and Topological Paths*（arXiv:1912.12644；作者仓库 `HKUST-Aerial-Robotics/Fast-Planner` 的 `path_searching`） | 优先复现几何前端：找绕建筑不同侧的完整候选，区分“多条路线”和“多个当前可执行的首分岔”。 | 同一建筑通道内不同偏移也可能有不同暴露，不能因拓扑相同一律剪掉；不引入相机、三维建图或主动观测。 |
| Ropke 与 Pisinger，*Transportation Science* 2006（DOI `10.1287/trsc.1050.0135`） | 复现 ALNS 的破坏、修复和按历史表现调度，作为有能力生成新路的强数值对照。 | 配送点是必访客户，UAV 中间点不是；改动的是未飞子路径，且改动后下游的到达时钟必须重算。 |
| Raoofi 等，*Representing Search State to a Large Language Model*，*Systems* 2026（DOI `10.3390/systems14101200`） | LLM 只从结构化搜索状态调整有界算子用法；可行性和评分归共同数值引擎。优先借鉴同状态的规则调度对照。 | 原文是车辆调度；等迭代比较有改善，但耗时更高，且未显著胜过最强专用求解器。不能类推 UAV 实时或任务收益。 |

**适配顺序。** 先将已经核验过的可见图补全和局部重连接给 LLM，复现“搜索状态反馈 → 调整算子或参数 → 再评估”的流程。多拓扑路径或采样树是备选构造工具，待出现单引导点或现有补全确实表达不了的走廊再接入。开发可以单独验收 LLM 链；增量归因沿用[当前主线](#当前主线llm-调用算子重规划)的共工具对照，不能把共享候选扩域的收益计给 LLM。

## 计划：区分场景与候选失败

- **场景限制。** 独立事后参考在相同建筑、航程、能量和到达时钟下，判断能否找到低暴露完整余程。按预登记的风险与绕行代价判据，覆盖可绕、可绕但代价高、未找到可绕走廊的场景。有限搜索没找到，只能在声明的搜索域内报告，不能当连续空间不可绕的证明。
- **候选限制。** 若参考有低暴露合法走廊、原菜单没有，记录为候选不足；图外中间点直接检验这个缺口。
- **在线信息限制。** 菜单已有较低真值暴露的可执行路线，但当时共同支持或普通点测无法区分时，记录为信息不足。若当时已有足够可比证据而选错，单独记录为决策失误，不归因于场景或 GP 覆盖。

场景种子和判据须在新合同中预先锁定，不因 LLM 是否换路筛选。主回放左图保留动态真场、发射机和实际航迹，右图保留当时 GP、支持/未知、原始点测与每次完整候选；左图只供事后审计，未实际执行的路线不报告为飞行收益。沿用[维护约定](../AGENTS.md)的封存边界，未批准前只做公开材料复核。
