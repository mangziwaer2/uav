# 方法 · 精简版

当前结果与任务顺序只看[交接](AGENT_HANDOFF.md)。本页是研究设计，不授予新实验预算；历史全文见[压缩旧稿](../outputs/research_archive/handoff_compaction_20261126.zip)。

## 目标与边界

在同信息、同工具和同资源下，检验LLM调度能否降低实际全程 `J=T+Q`，其中 `Q=∫10^((P_dBm(x(t),t)+80)/10)dt`。真场仅用于事后评分；在线仅用当前位置带噪总功率点测、公开2.5D建筑及已发生反馈。先冻结预测，再以新点验证旧版本，最后更新；GP派生点不当独立测量。

硬约束包括连续建筑净空、已飞加余程不超过原始 `1.25D0`、到达时间、能量和工具预算。−80 dBm是软风险参考/预警线。GP支持不等于安全；未知不补零、最近功率或低风险。互斥世界分别评价。合法LLM选择不能因数值排名或缺风险证据被覆盖；耗尽按合同停并保留已飞前缀。

## 当前主线：LLM调用现有分岔工具

分岔生成仍是**单引导点＋可见图补全至原goal**。`via`与`offset`是同一修复算子的两种参数化，不是两个独立创新；有限候选没有连续空间全局最优保证。当前优化重点是搜索覆盖、运行时参数与触发时机，尚未更换生成算法。

| 工具 | 决策与共同核验 |
|---|---|
| `generate` | LLM给 `via(waypoint_xy_m)` 或 `offset(forward_m,lateral_m)`，可带软绕行 `extra_m`；工具补全整条余程、去重、核硬约束，反馈失败原因。 |
| `compare` | 指定候选与参照ID；冻结GP和参照时间片，返回完整余程ΔT、同窗期望/逐点上尾ΔQ、分岔后覆盖、缺支持与窗外时长。新增路线不缩旧窗，不混排不同时间片。 |
| `commit` | 显式提交已核验ID，含保留原路R0；仅执行提交的未飞余程。无有效回执不让N代选。 |

工具链在同一暂停检查点内执行，无移动或新点测；提交后才推进。当前比较窗6秒、基础片0.5秒、分岔后最少0.5秒可比。局部Q不是全程Q或其保证下界，逐点上尾不是整路CVaR。多飞3秒，真实全余程Q至少省3才值得；共同支持只估省1，仍有约2需由未定价段承担，不能编造补齐。

完整N枚举公开障碍外角、局部偏移及必要的最短余程引导点，统一相对R0比较，以 `ΔT+Δ上尾Q` 选；仅R0完全无证据时按时间选。LLM可根据反馈改方向、幅度、参照或停止，两者可有不同菜单，但工具、参数域、资源与观测规则对等。不削弱N，不恢复旧三次咨询上限。

## 下一步的验证设计

先静止修复预警重新越线遗漏；再提供双方共用的公开走廊覆盖，加入同反馈、同资源的数值自适应搜索。只在确有表达不足时扩成多引导点或树，额外几何自由度的收益先归共同工具。

后续新合同比较完整N、自适应N和LLM；优先消融：同候选仅换选择者，以及LLM一次预列提议与逐轮看反馈修改提议。锁定版本、随机抽样规则、噪声、资源、失败/停止口径，保留无改善与早停，不选好场补成绩。报告到达率、T、Q、T+Q、查询/几何开销、回撤和模型等待；仅双方合法到达时计算配对差。正式论文另用独立评估场，以场景为统计单位；仅胜枚举不证明LLM独有增量。

每次新飞行交付同期HTML双图：左为事后真场与实际已飞航迹，右为当时点测、GP支持/未知、候选、工具调用和提交；保留各臂实际停止处。仅静止检查须明确无试飞，不用旧回放冒充新结果。

## 并行线A：完整余程优化

[静止原型](../src/uav_em/passive_repair_optimization.py)在冻结预测的有限合法图上搜索，按实际到达时刻积分期望 `T+Q`，保留时钟不同的前缀。`已用T+已定价Q+直飞最短剩余T` 为下界，完整定价合法路线给上界；预算终止报告最好合法解与界。未知部分单列，未完整定价不报完整目标值。证书只针对冻结模型、图与积分规则。

**先修积分再接入。** 原型时变夹具0.5秒中点报价9.24，按合成边界分段为27.47；搜索与同积分穷举吻合仅验证搜索。需用解析/加密积分核短窄强干扰段及路线排序。RP3已飞轨迹加密积分吻合原分数，不能替代新算子的验收。随后由共同数值法先验证收益，再检验LLM如何分配分岔或细化预算。

## 并行线B：等效源与多假设预测

源是解释点测的等效分量，不声称识别真实源。假设h内先以线性功率相加再转dBm：`μ_h=10log10((P_bg+ΣP_hj)/1mW)`。固定独立高斯dB噪声时，内层为有界最小二乘 `min_θ Σ(y_i−μ_h(x_i,t_i;θ))²`；换噪声则换似然。只拟合已发生点，不能以拟合真场全图误差作为在线目标。

LLM可根据公开几何、点测和数值试拟合反馈选择结构；数值工具负责参数优化。保留相容的左右热点、背景/暂态与必要时漂移解释，分别冻结下一普通点的预测，观测后先评分再更新。镜像世界可能同样解释历史却给相反绕行排序；无前兆时预测主要来自先验，权重需校准，不能把相对胜出写成绝对可信。

先验收无前兆、镜像歧义、可辨认与弱漂移；以未来点NLL、dBm误差和区间覆盖比较强数值结构选择、全结构混合、滚动GP与LLM，再固定同一规划器检查T+Q。条件规划只能在下一普通点实际发生后分支，含零概率分支均须合法到goal。预测提议和规划调度分开归因。现有[预测工具](../src/uav_em/equivalent_prediction.py)可复用；EP1、MC1均已关闭，EP2旧草案已归档，后续须新合同与新样本。

## LLM配置

RP3使用内置子agent，每次 `fork_context=false`、继承当前模型、显式 `reasoning_effort=medium`。59个原始会话核验的平台运行期ID为 `gpt-6.1-sol`；上游权重、官方快照及价格未核验。未显式覆盖温度、top_p或seed，不写成确定性采样。每调用180秒、每场累计1200秒、三场3600秒，是故障/总等待界，非额外调用次数配额；新合同须独立确定。

只给隔离指令、public allowlist和当时已发生反馈，不继承父历史、其他臂成绩、工作区、真场或未来数据；保存精确请求、原始回答、平台回执、完整会话、usage及哈希。RP3共59有效回执、652.98秒等待；RP2误拒另计1次、43.48秒，工程子agent另计。等待不计仿真T，不能据此称实时。

[实际用量与配置](../outputs/passive_repair_RP3_20261126/summary.json)是平台记录，不是账单；缓存是输入子集，推理已含输出时不重复相加。低成本偏好保留，尚未完成经济性比较；不以恢复MC1旧网关为门槛。论文按原记录披露渠道、请求/返回ID、推理设置、提示/输入指纹、有效率、失败、用量、等待和有凭据的费用，不回填旧模型身份。
