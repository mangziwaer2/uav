# 同一区域时序地图编码核查

更新：2026-11-04。承接map_codec_v2；当前检查固定空间编解码器是否保留历史地图变化，不训练LLM、RL或新传播模型。只声称仿真机载估计重建，不把估计变化标成真实源运动。

## 1. 为什么需要这一步

单帧重建较准，不代表前后差值准确。逐帧近似误差可能相减后形成假变化，也可能抵消真实变化；支持边界抖动还会伪造新增／失效支持。后续LLM需要依靠新信息修订计划，因此应先检查这些信号，不能从单帧IoU直接跳到源移动推断。

当前编码器逐帧独立处理。4帧窗口是带有效位、实际时间偏移及位置的4组空间tokens，不是已经训练好的时序Transformer，也不是128个文本词元。较早帧只以当时原始快照编码；没有用当前belief回填历史，没有将未来点测送入较早帧。

## 2. 核查协议

入口`../tools/audit_map_temporal_codec.py`，实现`../src/uav_em/map_learning/temporal.py`。

- 仅使用正式数据manifest、episodes的地图／时间和原始temporal_tasks；不读取evaluation_only、隐藏源或全图真值。校验哈希、场景划分、任务数量、因果窗口、ROI及原始任务标签；不是再次做完整物理重放审核。
- 每道题固定同一世界坐标ROI，比较历史窗口最早有效帧和锚点帧。先encode，再仅用tokens与公开尺寸decode，没有原图旁路。
- 新增支持与失效支持分别统计精度、召回和IoU。解码支持使用logit>0，原图使用mask>0.5，不用原图mask替解码器纠正错误。
- 功率差／年龄差MAE固定以原图前后共支持格计数，不能只在解码器挑出的容易格上算。另报共支持保留率；未知功率填充值绝不作差值标签。
- 默认绝对变化至少3dB视为功率变化，仅是诊断尺度，不是传感器或安全阈值。变化方向召回还要求前后均被解码为有支持、方向正确且达到同一阈值；漏支持计失败。
- 无分母返回null，不用满分替代。时间窗／ROI重叠，计数是任务格出现次数，不是独立样本，不据此计算独立试验置信区间。

```bash
python tools/audit_map_temporal_codec.py --dataset datasets/interference_onboard_maps_v1 --checkpoint outputs/interference_map_encoder_20261104_174105_494050/best.pt --device cuda
```

默认validation；test必须显式指定，本轮未运行。省略output自动新建时间戳目录，不能覆盖旧记录。没有改动数据、权重、训练划分或重新选checkpoint。

## 3. 实际结果

当前完整核查：`../outputs/interference_map_temporal_codec_20261104_181909_806135/`。108条validation轨迹、5,433帧、1,731道原始时序题；保留v2第39轮权重与原manifest哈希。

| 指标 | 实测 |
|---|---:|
| 新增支持精度／召回／IoU | 0.97778／0.98479／0.96323 |
| 失效支持精度／召回／IoU | 0.83046／0.96094／0.80334 |
| 共支持保留率 | 0.98309 |
| 共支持功率差MAE | 1.32855dB |
| 至少3dB变化格的功率差MAE | 4.51302dB |
| 功率变化事件精度／召回 | 0.35707／0.63846 |
| 变化方向召回 | 0.62821 |
| 共支持年龄差MAE | 3.71627s |

功率变化事件真阳性747、假阳性1,345、漏检423。22,712次共支持格出现中，只有1,170次达到3dB变化；平均误差容易被大量平稳格稀释。不能仅凭1.33dB均值宣称动态信息已足够。revisit包含1,008次变化格出现，goal只有8次；各行为完整结果见report.json，不能用稀少goal变化的高召回代替整体判断。

支持增失保留较好，但功率变化误报较多，年龄变化仍有平滑误差。这里的“变化”是机载局部估计随新测量／支持时效发生的变化，不能区分源移动、功率变化、反射或测量噪声。

## 4. 怎么看文件

- README.md：指标口径与图例；report.json：整体、行为分组、哈希及模型版本；task_metrics.csv：逐题时间、ROI、计数与误差和。
- new_support／lost_support／power_change下comparison.png：原图对应事件格最多的示例，不按重建好坏挑选；stable_region为无达到阈值功率变化且共支持最多的题。
- 图片上行为机载原始估计，下行为解码结果；五列依次是较早功率、当前功率、功率差、支持新增／失效、当前年龄。灰色无支持不是零功率，蓝色事件为失效、橙色为新增。
- 每例sample.json含原始题和由重建派生的近似标签；roi_reconstruction.npz保留两时刻数值。这些不是LLM输出或新增测量。样本仅帮助理解，不是代表性评价采样。

历史初版核查`interference_map_temporal_codec_20261104_181530_171482`保留未改写；当前版本增加平稳区域示例，整体指标一致。

## 5. 历史窗口导出增强

inspect_map_encoding仍保留原tokens、valid、offset_seconds、positions_m、anchor重建及原图诊断字段；新window_schema_version=2增加reconstructed_window，形状为[窗口位,6,行,列]。无效历史位为零，必须结合valid使用，不能当真实零干扰。temporal_encoding明确标注逐帧空间编码，而不是已学习的时序推理。

新示例在`../outputs/interference_map_inspect_20261104_181924_344676/`，包含scene_00087_revisit_000末帧之前的4帧、目标间隔6s。旧导出没有reconstructed_window时不得补造；后续LLM适配只能使用tokens及公开时间／位置等信息，不能读取onboard_target等诊断原图作为压缩旁路。

本轮全量测试400通过、2个既有外部夹具缺失失败（111.38s）；编解码／时序定向28项通过。新增14项测试覆盖事件、未知格、漏支持、因果／标签校验、无隐藏真值读取、未来帧不影响历史重建、哈希与输出保护。没有跳过或补造缺失夹具。

## 6. 后续收敛方向

按current_roadmap继续编解码保真，不扩展其他研究方向。下一次改进应保留v2单帧目标，同时使用已有训练组时序题约束共支持功率差、年龄更新与支持增失；混合平稳与变化题，避免样本失衡。不能简单惩罚所有前后变化，否则会把真实新信息抹平。

2026-11-05已完成这一候选训练与validation复查，结果见map_temporal_training.md：变化召回与变化格差值改善，但假变化增加，未直接宣称达标；本文件第3节仍保留原v2核查数值，不改写历史报告。投影／文字嵌入拼接的未训练接口见map_embedding_bridge.md，尚无真实LLM集成。

先固定当前checkpoint为对照、只用train训练与validation选模，检查是否减少假变化且不损害强干扰／支持边界。参数或权重改变必须另存新版本、重算对应tokens；不要用test继续调参。达到时序保真要求后再适配LLM理解编码历史与任务B，最后研究新信息触发的动态重规划；本轮未启动后两阶段。
