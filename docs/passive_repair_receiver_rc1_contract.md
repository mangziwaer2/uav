# RC1：长公开包的静止接收验收（2026-11-25）

**本合同只验接收和读取，不授权模型调用或试飞。** 接续 LC2；不读取其原始回执、不沿用其场景，也不复跑 LC1/LC2。真实模型运行须另获授权，并绑定已冻结清单 SHA-256；一个清单只准启动一次。没有新点测、仿真推进、实际 T+Q 或飞行回放。

- **公开输入。** 用固定合成点测和几何构造 60 个因果点、161 条合法完整余程和 160 条与 R0 的比较。没有隐藏源、真实功率图、未来点或其他臂数据。所有候选和比较经同核构造，不剪尾、不重排。仅把工具说明换成读取验证说明。冻结输入前对照本地确定性字段读取：从精确送达的字节提取首个点测功率、末条比较的状态与路线、该路线首个中间点的纵坐标。这里的数值控制是确定性读回，不运行决策基线，不测任务增量。答案、合同和清单均不送入模型。
- **资源及隔离。** 一次独立、临时会话，故障截止时间 600 秒；不是未来试飞的调用配额。启动器和设置锁定后，已核哈希的公开包从标准输入送给 CLI，不作为命令行参数，不向模型附加旧回复。新临时 HOME、最小权限为 `0600` 的配置和空工作目录，不加载用户规则；禁用 shell、网页、图像和应用。只接受 UUID 绑定的单个完整会话回执，不接受其他工具活动。启动前冻结合同、公开包、代码、可执行文件、无凭据配置指纹和预期读回；凭据不写入清单。
- **通过与停机。** 完整会话且首尾字段逐项吻合才通过。回执用 `commit` 信封校验 `request_id` 和路线 ID，**不执行该调用或任何工具**。没有第二次咨询、超时重试、人工代答或数值代答。责任分开记录：字节错配、进程或会话失败、格式错误、读回不符。留存原始请求、原始会话事件、回复、哈希与诊断；如泄漏配置中的凭据，遮蔽并拒绝本轮。
- **结论范围。** 通过仅表示该冻结配置能在这一长包上读取所要求的首尾证据，不等于模型读完每一行、覆盖最坏上下文或能生成更好的余程。失败则先修接收路径；不能压缩成缺尾候选，也不能沿用同一合同重试。正式开发场配对仍须另冻场景、两臂共用资源和独立停机条件，并在明确授权后才试飞、交付同期双图。
