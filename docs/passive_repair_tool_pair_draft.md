# 现有算子的首对开发实验说明（2026-11-26）

**开发协议草案，场景和运行参数待独立冻结。** 首对用一个未经预飞筛选的新开发场，完整数值 N 与真实 LLM 各一次。研究问题是，在相同公开观测规则、数值工具与总预算下，由模型在运行时生成、比较并提交余程，对两臂合法到达和实际全程 `T+Q` 有什么影响？一次配对用于检查机制和发现失效情形。算子源码改版及跨场效果评价另立实验。

## 首对实验的执行顺序

1. **冻结首对合同。** 在首次点测、模型请求或任一臂运行前，登记实验标识、未用开发场标识与输入指纹、选场规则、点测噪声种子和按序取样规则。锁定实际使用的执行器、共同工具、完整数值策略、公开输入白名单、提示文本的内容指纹、模型标识、推理设置、回执故障截止时间和停止规则。按下文公式用公开角点数 `C` 算出每臂的几何尝试和 GP 查询点整数上限，登记回放预算及新输出目录。场景真值由仿真端持有，决策端只收公开请求。封存验证和测试场继续封存。
2. **执行两个独立臂。** 当前已有单臂执行函数，首对开发场入口还需按合同接入场景、点测接口与真实模型接收器。获得试飞授权后，分别调用 `fly_repair` 的 `numerical` 和 `llm` 模式。两臂都显式传入合同中的 `tool_geometry_limit` 与 `tool_query_limit`，采用在线几何。LLM 臂另绑定本次请求前缀及接收器。每轮独立新会话只读当轮公开包，逐轮保留收发原文、哈希与反馈。两臂独立使用自己的点测和工具账本。[单臂执行器](../src/uav_em/passive_repair_flight.py)
3. **关闭并发布。** 保留各臂实际终态，待两臂关闭后调用 `publish_tool_pair`，真实模型记录使用 `synthetic=False`。输出 `replay.html` 及 `evidence.json`，汇报先给同期双图链接。随后列出各臂合法到达状态、停止原因、工具和模型开销，以及满足配对条件时的全程差值。[配对发布器](../src/uav_em/passive_repair_pair.py)

## LLM 实际可调用的接口

每份请求提供本检查点的位置和点测前缀、已发生残差、公开建筑及资源、已登记余程 `routes`、已有成对报价 `comparisons`、最近一次工具反馈 `last_feedback` 和剩余工具预算。较早的失败尝试保存在逐轮审计日志；后续模型只能使用当轮请求中实际出现的信息。首对沿用这一接口。模型每轮返回一行 JSON，含当轮 `request_id`、一个 `tool`、对应的 `args` 和简短的 `reason`。[请求与回执实现](../src/uav_em/passive_repair_tools.py)

| `tool` | `args` | 返回值及其对下一步的含义 |
|---|---|---|
| `generate` | `operator=via` 与 `waypoint_xy_m`，或 `operator=offset` 与 `forward_m`、`lateral_m`。两种写法均可带 `extra_m` | 两种写法共用单引导点修复。`generated` 登记一条合法完整余程，`duplicate` 返回已有 ID，几何拒绝返回具体原因。每次尝试计入几何预算。 |
| `compare` | 两个不同的已登记 ID，`route_id` 与 `reference_id` | 固定参照时间片。`comparable` 返回余程航时差、估计暴露差和分岔后的共同覆盖时长。证据不足时保留原因和未知值，合法候选仍可提交。 |
| `commit` | 已登记的 `route_id` | 复核成功即结束该次决策。`0` 表示保留此刻的承诺路。是否实际推进以及飞过哪些点，以执行日志为准。 |

## 共用流程与两种调度

- **公开信息与起点。** 两臂从同一公开几何、飞行参数和最短合法初始余程起飞。独立运行，同一冻结噪声规则按点测序号供各臂使用；分岔后各用自己已发生的点测，咨询秒数可不同。用当前点验证上一步冻结预测后再更新 `nominal` GP，不补测，不回灌派生点。隐藏源、真场、未来读数、旧回复和另一臂结果不进决策。网格仅供回放，不供控制器使用。
- **共同触发。** 起飞后的每个非终止点测帧，沿承诺余程预测到达后第 1、2、3、4 秒（超出余程的点不查）。至少一个受支持的均值达到 `-80 dBm` 就暂停复核；持续预警的下一帧仍可复核，不要求已有分岔或可比报价；无预警则沿上次承诺推进。复核中不移动、不采样。没有“LLM拒绝介入后让 N 选”的分支。
- **同核工具。** 两臂使用 `generate(via/offset)`、`compare` 和 `commit`；单引导点由可见图补全至原终点，不使用固定分岔点。每次提议核连续建筑净空、原始全程 `1.25D0`、到达时间及能量；软绕行参数不放宽硬约束。比较锁定所选参照的 6 秒窗，以 0.5 秒时间片为基础，分岔后至少 0.5 秒可比较；保留完整余程 T、期望及上尾 Q、缺支持和窗外时长。缺证据的 Q 不补零，报价不足也不等于路线非法。
- **数值 N（待冻结的对照实现）。** 用已有可见角点、沿承诺首段的 8 个局部偏移点和必要时最短可见余程的引导点生成；去重后逐个走共用 `generate`，对每条新合法路线调用 `compare`，统一相对承诺路 `R0`。有可比证据用 `ΔT + Δ上尾Q`；只有 R0 完全无已定价片时才按 `ΔT`；有参照证据但个别候选缺支持或分岔后覆盖不足，不用时间替代其风险。R0 以零改变量参与，排序并列时依次比更短航时和路线 ID。完成枚举才显式提交；不删候选、抬高其门槛或故意压低 N 的资源。该对照覆盖既有几何枚举，不代表连续空间最优，也尚未通过新开发场验证。
- **LLM。** 只给公开请求白名单：当时的位置、建筑与资源、点测和已发生残差、承诺路、本检查点已生成路线、比较与当前工具反馈。模型可改方向、参数、参照与软余量，自选下一次调用，也可明确提交 R0 或合法但未定价的路线。和 N 可生成不同候选；不给模型额外地图、数据或工具额度。不设咨询或交互轮次上限，不中途切回 N。每轮用独立新会话，保留原始请求、回执、会话 ID、收发哈希、耗时与工具反馈。

## 总资源与停止

建议按公开几何确定每臂相同的整程上限，不沿用 LC2 单点额度。当前执行器最多 61 个点测和 61 次单后验拟合；起飞用共同初始路线，终止帧不复核，故最多 59 个预警决策帧。设 `C` 为公共可见图初始化时保留的角点数，数值臂每帧至多 `G = C + 8 + 1` 次生成尝试，含失败和重复。对单一 R0，锁窗和每条候选各最多查询 13 个 GP 点，涵盖到达时刻引入的额外切片。建议冻结：

| 每臂资源 | 建议口径 |
|---|---|
| 几何尝试 | `59 × G`；失败和重复计入，非按咨询轮次分配。 |
| 决策 GP 查询点 | `300 + 59 × 13 × (G + 1)`；300 覆盖沿途预警与下一点冻结预测，一个参考窗与至多 `G` 条新路按帧计。缓存命中不重复扣除。 |
| 回放 GP 查询点 | 每点测帧一个公开网格；按至多 `61 × 网格点数` 单列，不把显示网格送入控制器。事后真场评估也另计。 |
| 实际开销 | 两臂分别报拟合、查询、生成尝试、复核与提交数，以及墙钟耗时；LLM 另报模型往返次数、时长及可取得的 token 用量。冻结接收通道的故障截止时间；不把它设计成正常决策的咨询配额。 |

例如 `C=4` 时，上限为 767 次生成尝试与 11,038 个决策 GP 查询点。这个上界保证当前 N 的完整扫描不会被设计额度截断，不表示实际会用完，也不证明模型接收端容得下最坏公开包。LLM 在同一总额下可能更集中地搜索或用不同参照；如实记录消耗，不能把模型开销与数值算力等同。

首个合法提交结束当前复核，推进至下一点；仅收到参数或几何拒绝时反馈并允许修正。合法到终点结束该臂；无合法余程、点测或工具超支、到达时限、失联、错绑或无效回执按原状停止，保留已飞前缀和已收到的回执。资源用完后不凭未提交候选继续推进。迟到回执不补执行，不重开会话替换失败结果，不择优重跑。不把暂停仿真的模型耗时算入飞行 T，也不报告为实时运行。

## 双图交付与冻结前检查

- **每对只有一个主结果。** 两臂关闭后，用实际折线和到达时钟积分真实 `Q = ∫ 10^((dBm+80)/10) dt`。两臂均合法到原终点才报告 `Δ(T+Q) = LLM − N`，另列 T、Q、航程、剩余能量和耗时。有停止臂时只列停止原因和各自已飞前缀，不计算全程差值。逐检查点分开记录「生成了新路」「报价可比」「实际提交并推进」；仅有候选或更低 GP 分数不算任务收益。
- **按记录解释 LLM 参与。** 全程无预警时记录模型调用为零。触发后提交 `R0` 时记录真实调用与保留原路。报告换路时，用当轮回执关联提议参数、已登记几何、比较反馈（如有）、提交及实际航段。路线 ID 只在各臂各自的检查点内有效。配对差值为负表示该开发场中 LLM 臂实际全程代价较低；为零或为正也按同一口径报告。
- **同期回放是交付条件。** 每个新试飞对输出可直接打开的同页 HTML，带两臂切换；汇报第一项就是回放链接。左图仅事后绘制逐时真场和实际 `moved` 航迹；右图显示同帧点测、GP 支持/未知、候选、工具参数与反馈、提交和实际推进。保留每臂自身停止位置和时间；未执行余程只画在候选层，不计为航迹。与原始日志、回执和评分互链；没有新跑就没有新回放，夹具或旧回放不能顶替。
- **本地验收。** [工具模式发布器](../src/uav_em/passive_repair_pair.py)核对两臂已关闭的日志、提交和回执，再走独立的已执行航段积分；双臂合法到达和单臂早停均已用夹具验证。夹具中 N 的工具候选覆盖同态下既有几何菜单，不等于在新开发场验证了 N 的表现。长包夹具用 60 点前缀、161 条路线和 160 个比较构成大于 128 KiB 的公开请求，通过标准输入送达隔离的本地进程，哈希一致，末条可读。没有打开模型会话，未验证模型上下文、最坏报文或运行通道容量；不能把 LC2 的命令行传参直接用于整程。
