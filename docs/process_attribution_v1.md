# 生成过程的阶段截断与同状态归因诊断

2026-11-11。承接[第一轮生成](offline_generation_v1.md)的draft_02：dev619改善、dev613退步，完整收益门槛未通过。本轮为数值归因诊断，0模型调用，不增加第5份生成产物、不筛新seed、不改原评分/GP/传播/搜索器，不据本轮最好截断自动升级方法。实验前版本随输出冻结，实际结果另节补充。

## 固定问题与干预

仅使用已观察dev613/619，复制原场景与draft_02原始程序。五种诊断模式：pool_only不执行额外过程；local_prefix仅可达原节点0/1；via_prefix可达0–3；global_prefix可达0–4；full_process执行原6节点。每个程序都保留全部6节点与所有action字段，只把越过指定边界的next改成stop。既有反馈额度按整个原节点后缀计数，因此停止前的操作、预算分配和随机流可逐位核验；不能直接删除后缀，否则改变前面动作的额度。本轮程序副本标记为诊断干预，不进入生成提交库，不计为新LLM产物。

共同初始池/700样本旧J-RRT*、全池R10+1窗口取最短、几何/端点/能量/固定全程1.25D0、2100样本/10000边上限完全不变。原始29核心模块不改，新工具只组装验证过的过程并调用原执行器。截断留下未用额度，不重新分配；少搜索是干预的一部分，不冒充等实际CPU。

## 两层验证与预算

1. **同状态配对：30求解。** 对draft_02在两个场景的首次不早于0/20/40s的决策各取一份，共6状态；该选择规则先冻结，不按真实暴露峰值选时刻。只从该状态已收到的点测重建GP，复算原选中风险。五模式同初始路线、种子、D0、已飞距离、能量与预算；检查前缀状态/提议/反馈/实际工作逐位一致。每个独立求解有同样上限，30求解的累计工作不能算作一次在线预算。
2. **完整闭环：10新飞行。** 两场景×五模式，所有失败留存。pool_only和full_process必须重现上一研究的轨迹及主要指标，不能复制旧结果。闭环路线改变后点测、决策时机和搜索次数都会改变；搜索seed由原仿真按累计搜索数推进，所以后续seed流也可能分岔。这是整个截断策略的控制实验，不将两条不同闭环差值归因于某次单独操作。没有新模型/补测或第五份生成候选。

全部30求解候选及原draft_02两城全部16个决策池先复制/哈希冻结，再做事后评价。固定池比较旧J最小与共同R10选择，分解E、未知秒数和长度；用原传播对候选的固定10s前段按0.25s中点积分，起飞延迟0.5s、无新点测/重规划，真实场只进入评价。该反事实不等于真实闭环执行，积分也不直接冒充逐飞行步积分。另为同状态五模式选中路线保存同样的10s反事实。**同一池重排不是更换RRT*搜索目标的消融**，不能据此断言把搜索J换成R10就会改善。

完整闭环独立报告到达、实际飞行积分、航程、能量与搜索开销，决策悬停另列。dB·s是仿真惩罚，−80dBm是软参考，GP及R10不是安全保证。只做这两城的开发机制诊断，无完整四城验收/统计优势/泛化结论，不自动选择“最佳截断”。验证/测试种子继续不生成、不读取。

单入口`tools/run_process_attribution.py`，新输出`outputs/interference_process_attribution_20261111`拒绝覆盖，10项实际飞行的GIF集中replay，固定10s反事实另存evaluations，不伪装成实际飞行回放。本轮最多30配对+10闭环；失败不重试、不追加截断/新seed或模型生成。

### 同状态结果限制了因果解释

所有停止前的状态、提议、构造、反馈和资源逐位一致。6个预声明状态中，4个local_prefix与完整过程最终路径相同；dev61340s的via作极小调整，dev61944.5s的末尾shortcut再缩短约7.098m。两者10s前段真实积分均不变。另在dev61920s，pool_only到local_prefix的R10为28.712→28.721（+1窗口内以短路优先）、剩余航程669.495→627.897m，但未来固定10s积分4.798→5.804dB·s。这个可复算反例表明，局部候选也不保证减少下一段真实暴露，完整飞行改善不能解释成每步风险单调下降。

local_prefix与完整过程在两城起点选路相同，10s前收到的点测也完全相同；首次不同选路均出现在10s。原种子使用`config.seed + len(plans)`，额外搜索即使no_gain也推进后续种子：dev613此时分别615/620，dev619为621/626。因此截断不只改变可选候选，也改变后续随机搜索流，之后才改变飞行、点测与GP。此事实单列留证；本轮不修改旧种子来重跑，不把差异唯一归于via/global的几何质量。

### 旧J与R10不构成互相替代的正确性保证

16个已冻结原决策池中15个选择不同；对固定10s前段事后比较，R10真实积分更低3次、相同9次、更高4次。不能将重叠窗口积分求和当完整任务指标；未知10dB权重及GP支持范围只是代理。例：dev61350s的R10路线真实积分3.883，J路线1.849；dev61920s则为5.804 vs 14.361。重排没有重新生成树，不是“将RRT*搜索目标换成R10”的消融，也不能据此宣称J或R10普遍更好。

## 下一步收敛

先设计**与其他搜索调用次数解耦的随机流配对协议**：按决策时刻、算子位置和独立重复编号派生种子，双方共用同一规则；保留本轮完整旧流证据。然后以局部截断为强数值参考，测试“局部结束后停止，还是花剩余额度扩展”的过程选择。状态需要明确区分R10改善来自支持暴露下降、未知秒数下降还是1dB·s窗口内的缩短，不增加传感或让LLM改目标。共同信息/预算下，比较固定局部、固定完整、数值反馈选择，再考虑在线LLM选择/修订的增量价值；不能用开发最好截断当作LLM收益。

以上是待冻结的新协议，不是本轮已实现随机流分离/在线组合。当前4份生成名额不追加；新过程开发预算必须在下一研究先写清楚。验证/测试仍封存，暂不扩展GP/主动补测/自由代码或训练，也不继续扫未知权重。若强数值局部过程已解释收益，论文应承认其贡献；在线LLM必须超过这个参考才能声称决策推理优化。
