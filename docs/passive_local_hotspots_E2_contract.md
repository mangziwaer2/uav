# E2 · 局部动态干扰中的配对选路开发试跑

- 本轮只跑固定开发场景 `43711` 一次 LLM 和一次强 N，各从同一起点出发并重新初始化同一观测噪声种子 `43712`。不使用 E1 或封存种子、不预飞、不筛场、不挽救失败臂。场景是专门设计的可绕开发例，不是对复杂环境总体的代表性抽样。
- 复用 E1 双建筑、定高飞行、离散路线和删点重连，保留原始 `1.25D0` 全程航程、建筑净空、能量、到达终点和时间限制。以三个半径较小、缓慢移动、不同活跃时段的合成热点代替宽场。具体场景由冻结实现生成；生成参数不进入在线输入或回执。
- 两臂用已知地图、机载状态、当前位置普通带噪总功率点测和冻结时空 GP。每次先用新点检验旧预测，再更新。LLM 只收冻结的 E1 请求字段：当前位置与时间从路线和点测推得，含建筑、目标、剩余资源、预警、完整合法菜单、共同支持与单侧支持、最多 12 条已发生点测和残差。不提供场景种子、隐源、真场、未来点、N 的选择或其他会话。经新独立会话获得一次必选回执，记录原始请求、回执和哈希；各次不共享会话。
- 复用 E1 因支持内均值首次达到 `-80 dBm` 而复核的规则；无备选先继续合法余程，持续越线不重开，未改变本轮触发。两臂起飞先用共同数值算法。强 N 在同一菜单穷举最小化**完整剩余航时 T + 6 秒窗口共同支持上的 Q**，依次以完整时间和路线 ID 破同分。Q 是公共时间片上归一化线性功率的逐点上尾均值积分，缺支持不定价。LLM 获同一目标和证据，必须给一个实际执行的合法 ID；提示区分首分岔方向、实测变化、完整绕行时间和未知段。无图外动作、主动补测或回退。表中 E1 窗口代理与本轮完整 T 代理须明确区分。
- 每臂至多 61 次普通点及 GP 拟合、90 秒模拟时间、70M 逻辑风险查询、126 条路线每次、起飞加至多 3 次事件评分。LLM 至多 3 次，每次请求不超过 24 KB、回复不超过 800 B、等待不超过 180 秒且合计不超过 720 秒。不重试，不增加预算；咨询仿真暂停，墙钟另计。超时、缺失或非法回复终止该臂，保留合法进展；其他臂照合同完成。事件预算耗尽继续原有合法余程。
- 紧凑性与可绕性**在两臂关闭后**只做离线核验：按 20 m 网格可飞点、0–60 秒逐秒抽样，`>= -80 dBm` 最大网格点比例须在 5%–30%。同建筑及同初始硬约束下，从有限路线菜单中找比最短合法路线多 1–12 秒、真实 Q 至少减少一半、真实 `T+Q` 更低、且越预警线时间不超过 10% 的绕行。最短路在等长时用共同枚举顺序。用各路线实际到达时钟积分；此核验不进决策，不构成连续空间最优证明。没通过也报告，不换种子。
- 主要结果为合规到达的两条**实际**航迹全程真实 `T`、`Q`、`T+Q` 及 LLM−N 差值；不拿未到达的部分代价充当完整收益。发布左右双图、备选与实际分岔、咨询时刻和回执。场景真实绕行仅作诊断；一对开发试跑不能证明一般性增量或实时可用。新版本不重用此场历史成绩。
