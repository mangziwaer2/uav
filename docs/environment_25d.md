**当前状态（2026-11-03整理）：** 主流程使用demo_25d本地时变源和一次反射，无需外部数据；离线脚本已移到tools，4份可选配置已移到configs/optional。两个datasets小夹具当前缺失，相关示例不能直接运行；下文291项全绿和旧回放数字是较早历史状态，不是当前测试或现存证据。最新状态以AGENT_HANDOFF为准。

更新：2026-11-03。用户明确研究对象为电磁环境仿真数据，不要求拥有真实无人机或电磁设备。本轮补环境与数据接口，不启动训练、模型评价项目、门控或代码执行，不把设备标定变成LLM研究前置条件。

## 1. 研究定位与适配责任

实验可以明确表述为“在电磁干扰仿真环境中验证LLM辅助航路决策”。可采用合成城市、真实城市几何或外部传播仿真数据；必须区分数据来源与实验结论，不把仿真结果写成实机验证。

用户的“教练”比喻对应可复用的决策闭环和环境接口：环境／传感器提供统一单位的局部观测，决策层提出计划，传统求解器生成并复核路径，执行层返回真实接受行动与新观测。使用者适配其地图、传播数据、传感器能力、飞行器参数及约束；我们不把具体机型、场地图像或设备协议写死在LLM策略里。

这种接口可适配不等于已证明跨任意设备、车型或场景自动泛化。当前只验证仿真软件、几何与信息边界，不保证零适配上机，不提供真实飞行安全认证。以后硬件接入是使用者按任务条件实现的适配，不是本轮工作。

## 2. 定高2.5D是什么

航路仍为二维`[x,y]`，无人机固定在统一地面基准上方`altitude_m`飞行，不爬升、不下降、不优化高度。建筑为平面多边形加基底／楼体高度的竖直棱柱；支持凹建筑、庭院孔洞及不同楼高，没有地形起伏或斜屋顶。

楼体竖直区间为`[base_m, base_m+height_m]`。上下各扩`vertical_clearance_m`后与飞行高度相交，则该楼体是本高度的碰撞障碍；边界相等也禁止。水平净空`clearance_m`按到多边形边界的欧氏距离计算，不用整个外接矩形封死凹槽／庭院。整条航段复核，而不只检查两个端点。

例如固定30m、竖直净空5m、基底0：12m楼允许飞越；25m楼正好触及净空边界，禁止；45m楼必须绕行。安全飞越低楼不代表其下方源到无人机的无线电传播不受遮挡。

`map.obstacles_m`仍是额外平面禁入矩形，保持旧实验语义；不按统一20m传播高度自动放开。旧配置`geometry_mode=planar`默认不变，确保已有实验可回放；新配置显式用`fixed_altitude`与`buildings`。需要楼高语义时不要把所有建筑导入旧矩形字段。

## 3. 配置与传播

新配置入口为`configs/demo_25d.json`，含低楼、凹高楼及带庭院高楼，**是手工仿真夹具，不是真实城市样本**。示意建筑：

```json
{
  "id": "building_1",
  "footprint_m": [[40,40],[80,40],[80,80],[40,80]],
  "holes_m": [],
  "height_m": 12,
  "base_m": 0,
  "loss_db": 6,
  "height_source": "provided"
}
```

- `id`非空且场景内唯一；`footprint_m`至少3个不重复米制顶点，允许输入闭合末点；拒绝自交、退化和相邻边重叠。
- `holes_m`为严格处于外环内的庭院环，不能相交／嵌套；不自动修复坏GIS几何。庭院内部可通行不代表能穿墙从外部进入。
- `height_m`为楼体高度m，正数；`base_m`为同一高度基准的基底m，非负；`loss_db`为每个楼体相交一次的非负损耗，不是每米材料衰减，默认6dB。
- `height_source`标记提供／估计／默认来源，不能把补默认高度写成实测；`map.provenance`保存数据来源、许可、坐标及导入哈希。

简化传播使用三维收发连线与**未膨胀**楼体相交，先裁切竖直相交区间再检查多边形及庭院，每栋相交建筑仅计一次损耗。不会因为飞机能飞越楼顶就忽略低高度传播遮挡；飞行净空也不作为额外墙厚。仍没有反射、绕射、材料实测、阵元IQ或全波计算。源候选前向检验使用同样的公开楼体信息，不访问隐藏源脚本。

回放中深灰为本飞行高度不可穿越的楼体，浅蓝为允许飞越的楼体；庭院保留孔洞，标题显示固定高度。左右图使用同一几何；左侧隐藏源与全场功率仍只是研究者评价信息。

## 4. 离线GeoJSON建筑导入

入口`tools/import_buildings.py`，不联网、不自动下载、不引入GIS依赖。保留Polygon／MultiPolygon多边形与孔洞，不做外接矩形替代。模板必须显式清空`buildings`与`obstacles_m`，防止悄悄覆盖旧场景。

```bash
python tools/import_buildings.py datasets/example_buildings_local.geojson --template configs/optional/import_25d_template.json --coordinates local_m --source handcrafted_fixture --license project_fixture --output configs/imported_25d_trial.json
```

输出路径必须不存在。输入支持两种显式坐标方式：

- `local_m`：输入已投影到本场景的米制坐标。文件使用GeoJSON几何结构，但不声称是RFC 7946经纬度；由用户保证原点、尺度与模板一致。
- `lonlat`：输入为`[经度,纬度]`，必须给`--origin-lonlat 经度 纬度`作为地图西南原点；采用球面局部等距圆柱近似，不是精确UTM／测绘投影。纬度限制±75°，保留建筑顶点距离原点不超过5km；更大范围请在外部GIS投影后用local_m。统一地面高度不由经纬度推断。

读取高度属性`height_m`或`height`作为相对统一基准的楼顶高度，基底读取`base_m`或`min_height`，导入后楼体高度=楼顶−基底；输入高度仅支持数值或米制字符串，不把层数／英尺自动当米。缺高则报错；只有显式`--default-height 数值`才补默认值并记录数量和`assumed_default`标签。不要把导入输入的楼顶高度与内部Building.height_m楼体高度混淆。

只保留外接范围与场景相交的建筑，保留完整轮廓不裁碎边界建筑；不相交对象计数，其他无效建筑报错，不默默修复／跳过。来源、许可必须由使用者核实填写，程序不能替用户判定法律授权。模板中的合成电磁源仍按模板设置，不会从建筑数据推断真实源。真实数据下载、城市选择和第三方专用转换尚未执行。

## 5. 直接使用外部电磁仿真栅格

独立传播真值生成入口见`sionna_rt_environment.md`及`tools/generate_interference_rt.py`；优先补足干扰场可信度，地图只作为传播输入。Sionna RT为可选离线依赖，不进入LLM运行环境或在线决策。

`configs/optional/demo_power_grid.json`展示另一条后端：环境不按隐藏源公式合成，而直接从静态总接收功率图采样。旧`datasets/example_power_grid.json`是粗分辨率合成夹具（当前缺失），验证适配流程，不冒充公开数据集。

外部JSON格式：

```json
{
  "x_m": [0,120],
  "y_m": [0,120],
  "power_dbm": [[-100,-80],[-100,-80]],
  "altitude_m": 30,
  "carrier_frequency_hz": 2400000000,
  "provenance": {"source": "dataset identity and release", "license": "verified license"}
}
```

NPZ支持相同的五个数值键，禁止pickle与额外键，来源写在配置中的`provenance`。横纵轴各至少2项、严格递增，功率矩阵按`[y,x]`排列，有限值且在实现支持的−300至100dBm数值范围内。该范围是输入校验，不是设备物理能力声明。必须覆盖完整仿真边界、无NaN／nodata，高度与载频须匹配配置。

配置用`electromagnetic.power_grid={"path":"相对配置文件的路径","provenance":{...}}`加载；加载后内嵌数值及原文件SHA256，episode回放不依赖旧绝对路径。也可直接内嵌上述字典。只把完整数据保存在评价配置，不放入LLM上下文；在线观测仍只在飞机实际位置获得、加测量噪声。

适配有四个不可省略的限制：

1. 数据量必须是**已包含背景的总接收干扰功率dBm**，不再次叠加背景。双线性插值先转毫瓦，再转回dBm，不在dBm上直接平均。
2. 只提供静态、固定接收高度切片；`fields`必须显式为空。不用移动一张场图伪造任意干扰源运动；已存在动态源的合成传播后端不受影响。
3. `sensor.mode`必须为`power_only`。纯标量图不提供真实来波角度或源位置，不能偷偷复用隐藏源生成精确扇区。
4. 路径损耗、单源贡献、SINR、通信覆盖或归一化图片必须由使用者按数据定义完成转换，不能直接改字段名。暂未实现RadioMapSeer／Sionna等专用转换器或反射路径／波束数据适配。

数据集可能使用不同频率、机高和传播模型；功率图本身不能被硬改为我们默认2.4GHz／30m。可选LLM源提议仍由当前公开前向近似检验，面对外部射线追踪真值是模型失配，不是默认严格一致；不能把拟合拒绝直接说成定位错误。纯功率观测的不可辨识性也必须保留。
