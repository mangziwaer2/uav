# 航程与连续功率的共同评价：开发数值检查

2026-11-11。用户在查看起点折返后，明确认可允许一定暴露、联合优化路径与干扰。本轮改变共同接受评分并配对随机流，原传播/GP/传感/旧搜索器保持不变；是数值开发检查，不是在线LLM收益或第五份生成提交。实验前版本随新输出冻结，结果运行后另补。

## 问题与评价

旧R10只看候选接下来10s，未知时间按10dB/s惩罚、航程仅在风险+1窗口内比较。已知范围内插入弯路可能把同一未知尾段推到窗口外而获益。新分数对**整条剩余路线**积分，不把未知推迟误作消除：

`C = T_remaining + lambda * (Q_supported + Q_unknown)`

`Q_supported = integral supported E[10^((X_dBm - P_scale_dBm)/10)] dt`

其中当前GP假设`X~N(mu,sigma²)`，期望为`exp(a*(mu-P_scale)+0.5*a²*sigma²)`，`a=ln(10)/10`。功率先转线性后积分，不截断低功率或强功率，不把负dBm直接积分当物理能量。P_scale=-80dBm沿用旧数值作单位（10^-8mW），不是容忍阈值；分数不含安全/失效定义。

未支持网格不读其均值/标准差数组，也不公开功率；单列`Q_unknown = unknown_seconds * q_prior`。q_prior由已有背景均值-100dBm、未知标准差15dB的声明先验通过同一期望公式计算（约3.894），不是实测或上界，不保证保守/校准。支持格使用当前GP后验；跨边界仍可能跳变，核与先验偏差须如实说明。不新增源推断/全图估计或免费感知。GP快照在整条路上冻结，只是当前空间证据代理，不预测抵达时刻，不代表长期未来地图已知。

lambda=1为主任务偏好：在P_scale下1秒归一化功率积分等价1秒额外航时；0.25/4只作预声明敏感性，不按结果挑权重。改变P_scale时同步改变lambda可保持等价，所以P_scale不是硬件阈值。固定快照中，插入一段回到同一位置、后续路径不变的正长度绕圈，会增加航时及非负积分，不能靠推迟未知尾段降低分数。这不保证不同几何绕路都无价值，也不解决动态未来推断。

记录航程—功率积分的池内Pareto集合，按预声明lambda选择。保留旧R10/dB·s分解作诊断，但新接受不要求旧J/R10单调下降。数值搜索内部仍用原J，故本轮是接受目标变更，不是搜索目标消融。几何/端点/能量/固定全程1.25D0/共享2100样本及10000边不变；新评分数组工作另计节点与墙钟。

## 随机流与比较预算

新研究共同使用SHA256派生种子，键为版本、场景原seed、决策时刻微秒整数、重复编号0、阶段（共同池或原程序node）及搜索purpose（含via两腿）。忽略仿真传入的累计plan种子，不修改旧仿真器。额外失败/no_gain搜索不能推进其他节点/后续时刻的流；同状态同操作/额度可复算。几何/预算/路线不同仍会改变树和结果，不声称闭环观测或实际CPU相同。只做每城市单次完整飞行，不声称独立随机重复。

六组：paired_prefix_pool旧R10共同池；balanced_pool主lambda1；balanced_local沿用draft_02局部截断；balanced_full沿用完整六节点；balanced_pool_low/high分别lambda0.25/4。程序副本明确是已有产物/诊断干预，不新生成或让模型改权重。

1. 复制上一归因阶段6个因果状态，每状态六组，共36次同状态求解。共同初始池及资源一致，同lambda局部/完整在停止前提议/反馈/种子/工作一致；候选全部冻结后才评价。仅供描述，不用真值挑参数。
2. 原样复制已用dev611/613/617/619，六组共24项新闭环，失败不重试、不筛seed/模式。全部冻结后再汇总、复算真值、生成24个实际飞行GIF。
3. 主比较为balanced_pool相对paired_prefix_pool，固定lambda1；再比较balanced_local/full相对balanced_pool。敏感性两组不晋升主组。报告到达、全程约束、航程、初始50m/150m几何进度与绕行、连续真值功率积分、旧超参考dB·s/时长、悬停及所有搜索/数组成本。完整任务失败的低暴露不奖励。不追加第5份生成，不读取验证/测试。

本轮为权衡检查，报告每场景及合计，不用旧“积分必须下降”门槛选新目标：短路径允许较大软暴露。按预声明lambda对实际完整任务`航时+lambda*归一化连续真值功率积分`另作事后共同指标，主组若失败或总指标不改善则明确记失败；所有分项/逐场景退步保留，无统计优势或安全结论。事后指标不是在线真值访问，也不是完美信息最优路线。

先验功率系数实际按公式为3.894110，冻结文档的3.896仅近似文字，程序一直按公式计算，无运行后调参。15dB未校准标准差经指数变换会放大尾部期望，这是模型偏好而非物理上界；普通GP跨建筑平滑、支持边界和抵达时变化都仍会使分数与未来暴露错位。不能把本轮数学消除“插入纯绕圈获利”解释成已解决所有无效绕行或未知风险。

## 下一步

先保留新目标为“短路—软暴露”的共同开发版本，不把它升级为稳定避强方法。围绕dev617的真实高暴露，下一研究应冻结有风险证据时的局部区段/绕行候选和反馈合同：提供支持/未知分解、近期功率趋势、额外航程及原目标差值，让数值反馈策略与在线LLM在相同算子、信息和预算下选择停止或扩展；禁止给LLM改权重或真值特权。先诊断同一已发生状态是否存在可由当前目标接受的有意义修复，避免直接用模型掩盖候选/估计瓶颈。不能重新加入“支持E必须下降”的失败硬准入。
