审核证明实现的一致性和基本覆盖，不证明传播模型真实、源唯一可辨识、整图均已测遍或720轨迹足够覆盖未来策略分布。源数少的场景与大量未知区域仍需要保留。

## 3. 空间编解码器训练

已完成训练目录：`../outputs/interference_map_encoder_20261104_170403_750336/`。

使用`configs/map_encoding_full.json`，CUDA，RTX 3060 Laptop GPU；模型302,982参数，每帧32×96潜在向量，30轮，batch 32，学习率0.0003，frame_stride=2，初始化与洗牌种子7。不是1.7B LLM训练，也不下载模型。正式训练启用`--require-quality`，报告哈希写入training_config，轨迹首次加载时重新核对哈希。
