# D2-M2：集体失配后的活动源版本替换

2026-11-20，用户要求继续。M0/M1预算已经结束；本轮独立合同、输入、源码和预算先冻结，再运行，拒绝覆盖原件。目标是检验一个具体机制：所有旧源刚被真实新点测判为失配后，仍按固定75/25配比维持旧池，是否阻碍了修订影响规划。本轮不把数值版本维护称为LLM创新。

## 唯一处理差异

两方法均采用M1的源池（无全图功率延续）、8秒初始化、同一GP/源字典/幅度拟合、4事件预算、原预警和侧向50中间点搜索、T+Q及整路约束。

- `renewal_keep`：原75%旧池/25%新版本出生规则，复现M1侧向参考。
- `renewal_replace`：每次成功出生新源前，检查刚取得点测对旧活动源的预先发出预测。若全部有源模型的绝对误差均≥8dB（与既有集体失配触发完全相同），将旧版本完整留档，当前活动池改为全部新出生版本，初始等权；其他情况沿用原出生规则。没有成功新源则不移除旧池，记录未解决失配。

替换只在已有决策事件、拟合成功后提交，不新增事件或传感点；所有旧源均须真实出生后预测，不用本次拟合误差、GP软点或真值做资格判断。新版本不继承旧版本得分。旧版本被暂停参与当前池，不是证明其在全图物理不可能；本先导不实现恢复旧版本，也不把等权出生解释为已验证可信。原件、暂停原因、失败预测、公开前缀及新源保留完整记录。

8dB是已有开发判据，非校准显著性检验。单点噪声、局部模型偏差或共同错误可导致过早替换；新源亦可能全部错误。两方法都继续边飞边检验，不注入最近功率延续、额外全图未知热点、真源坐标或手工调权重，也不保证改善。

## 范围和预算

输出`outputs/interference_source_renewal_d2_m2_20261120`，最多2条新数值飞行，每方法一次，仍仅已见开发种子109；0次决策LLM调用，无训练、主动补测、新传感或封存评价。同步回调冻结物理状态，每事件仍固定0.5秒悬停。

每飞行100模拟秒、102点测、4事件含初始化；每事件最多3拟合作业、6求解、240残差、700路径提议/10000边，初始几何规划另700/10000。共享上限204点测、24作业、48求解、1920残差、7000路径提议单位、100000边、4000监测查询、360软GP查询、202预序联合查询、40000000规划接收点。留档/资格计算只使用已经发生的原始预测，不产生额外场查询。

另固定M0修订版20.5/31/41.5秒三个公开状态。旧源和新出生源参数均直接取该时刻已保存结果，不重新拟合。参考为M1已经冻结的同状态侧向最优路线；处理组只按上述规则替换源集合，重新评分同一组候选几何（原M0候选及M1的50侧向提议），同一GP、历史和约束；每状态最多50侧向提议/10000边，共≤150提议/30000边、≤12000规划接收点。没有新点测或模型拟合；新源不继承历史成绩。

这检验当时一次出生提交的源替换，不能冒充从头采用新维护规则的完整历史。所有处理组预测/候选/路线和新飞行先冻结，再作真值评价。参考路线的真值样本直接复用M1已存原件，不新增查询；只对新选定的三条整条剩余冻结路线做新积分。结果不回流到参数或已运行飞行。

新飞行真值积分≤1000点，三状态新路线积分≤1000点，均用≤0.5秒中点法；反事实排除共同起始悬停，不代表闭环收益。显示预测/真值网格各≤21504点，两飞行各≤32帧21×16，保留事件前后；不额外评价未选路线真值或做多次重试。真源只在事后左图出现，右图仍为实际聚合预测和一个明确的活动假设源，暂停版本数量另示。

## 判读与验收

先检查公开前缀、预测先于点测、资格只用旧预测、替换原子性和全程/共享预算，再报告源误差、路线排序、选择/到达/航程/T/Q/T+Q及资源。`renewal_keep`应与M1侧向参考的观测、动作、拟合、预测逐项一致。若不一致先查实现，不能称处理收益。

同时报告同状态三个结果，无论正负；完整飞行的不同航迹误差不是同点因果比较。改善也只支持此已见场景的一次机制先导，不是泛化、校准安全或LLM收益。后续LLM需要独立会话，在相同工具、信息和总预算下组织资格检验/修订与搜索；根会话已见真值，不能作为盲决策LLM。
