## 唯一组织差异与共同执行

`allocation_N`采用固定数值分配规则：在本次3个新生模型中，先最大化“条件权重×本世界对当前聚合路线的预测后悔值×下一15米端点距离/15”；并列按原拟合目标降序、版本ID升序。它是任务相关确定性参考，不称论文最终强基线。

`allocation_I`让LLM读取同一公开包，选择`refine_geometry`及一个允许的新生版本ID，或`keep`。只能对当前事件原3个拟合之一调用一次M3有界几何工具；不可改权重、增加源数/路线候选、设真源坐标、换目标或使用额外观测。理由一并保存，但不作为正确性证据。

共同工具沿用M3的±40米/√2/原区域/幅度边界、原目标、解析导数、40次残差/40次Jacobian/5000核项上限；收敛且合法且目标改善>1e-8才接受，否则保留原模型，不重试。pilot仍仅用其训练前缀。只替换所选新生版本的参数，重基准至当时，出生后得分为0，原相对权重保持；其余模型和历史完全保持。这是出生时参数修订的局部机制诊断，不假称实时旧模型维护。

共同规划器重新评分同一份缓存候选几何，按T+Q/原整路硬约束取最优。不新增路线、主动补测或扩大搜索。记录候选变化与下一15米端点变化；参数变化但执行前缀未变时照实报告。

LLM每状态1次回复，共最多3次实际决策调用/3次派发；不追问、不重试，非法/超时/未派发按keep回退，分别保留原始回复、启动、解析、工具接受和最终路线。数值与LLM各≤3次细化，不以少用预算自动算收益。独立会话不继承D1已结束的调用预算。
