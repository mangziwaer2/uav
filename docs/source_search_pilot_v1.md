## 已存日志支持的问题

M0修订版后三次事件虽然重新拟合，额外数值提议却都沿当前位置至goal的同一直线延伸，最终与保留路线重合；每次路径采样实际为0，声明上限700。固定±35/60度、180米的候选不能覆盖不同尺度的局部侧绕。旧候选评分已保存，不需要新真值证明这个搜索退化现象。

## 新工具及唯一处理差异

源池继续排除全图功率延续，沿用M0的8秒初始化、所有源误差≥8dB触发修订、每飞行最多4事件、GP/字典/幅度/出生权重/似然规则及T+Q约束。本轮不改变源权重、GP方差、代价或触发来制造绕行。

新增最多50个中间点：以当前位置至goal的朝向为纵轴，纵向比例依次取0.25、0.5、0.75、0.1、0.9；侧向偏移依次为+20/−20、+40/−40、+80/−80、+120/−120、+160/−160米。各点仅来自任务几何，不看真图。每次提议（包括越界/不可行）先记1个共享路径采样单位；仅对地图内、两段直线可达并满足全程航程/能量的路线评分。障碍阻挡不另外运行隐藏RRT；仍可保留原来合法路线。工作账本耗尽停止，不能突破共享700提议/10000边额度。

所有新候选与保留路线使用同一冻结源＋GP预测、完整到达时刻和T+Q；不按最有利源单独选路，不把未知当零成本。执行器共同argmin决定是否换路。候选/拒绝原因/逐假设Q/预测版本与预算均保存，便于以后LLM在相同工具能力下组织搜索。
