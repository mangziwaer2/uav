# MC1 · 三种 LLM 配置的独立静止校准

2026-11-26。用户授权尝试 `gpt-5.6-luna`、`gpt-5.6-sol` 和 `gpt-6.1-sol`。本合同将三者作为固定配置比较，检验相同公开点测和数值反馈下的协议有效率、未来预测质量、调用资源及可取得的费用。本轮没有飞行，不生成航迹，不进入 EP2 正式评估，不复用已关闭 EP1 的样本或预算。

## 候选、输入与任务

| 标识 | 网关请求名 | 推理档位 |
|---|---|---|
| luna | `gpt-5.6-luna` | `low` |
| sol56 | `gpt-5.6-sol` | `medium` |
| sol61 | `gpt-6.1-sol` | `medium` |

三者均为当前连接目录列举的请求名，底层版本、价格和实际通道是否可用尚未核验。`sol56` 是固定的能力参考。比较对象为模型与推理档位的组合，不能把差异全部归因为模型架构。温度、top_p、seed、服务层级不额外覆盖，记录为后端默认或未提供；不宣称零温度、确定性或未经实现的输出 token 硬上限。无运行期改名、换档位、强模型补答、模型间反馈或失败重试。

模型各自在新隔离会话中收到同一份语义可见的白名单包：十二个已经发生的 `(time,position,total_power_dBm)` 点测、公开 `[0,400]²` 无建筑边界、三种匿名结构的释义、八点试拟合对随后四点的冻结预测和实测误差、三个二选组合的留出 NLL、同一工具预算。模型选择两个不同代号并给一句理由。场编号、分层、种子、干净信号、未来坐标或读数、其他模型的回执、模型比较成绩和历史试飞均不得入包。使用 [既有固定提示与白名单](../src/uav_em/equivalent_prediction.py)。模型上下文无文件、仓库、其他会话、网络和外围工具。

## 样本与共同数值程序

12 张独立合成点测表，四层各三张，`layer=0…3`，`rep=0…2`。仅更换随机命名空间：每条流使用 ASCII `MC1-v1/{layer}/{rep}/{tag}` 的 SHA-256 前八字节大端整数初始化 PCG64；tag 为 `samples、signal、noise、alias、order`。依 `order` 整数升序，同值按 `(layer,rep)`。每表 18 点、坐标抽取顺序、四层信号与 2 dB 噪声公式严格沿用 [EP1 样本设计](equivalent_prediction_EP1_contract.md#样本与盲法)。首表产生前先封存本合同、结构化配置、提示、源码、环境和客户端哈希。不读取任何封存验证或测试场景。

三个结构、背景 −100 dBm、4 dB 预测观测标准差、线性功率叠加、最多两分量、字典参数范围及有界最小二乘均与 EP1 相同。八点试拟合后，逐次冻结对第 8–11 秒的预测，再揭晓对应读数；模型在第 11 秒选择。三个模型的选择或失败状态均先落盘，然后公共程序用前十二点重拟合三种结构。每个成功臂以等权出生，在第 12–17 秒逐点冻结、评分再更新世界权重。新版本不继承试拟合的留出成绩。缺失回执不由数值策略代选。

强 N-选二按同一公开包的四点组合平均 NLL 选最小的一对、平分按匿名代号；N-全三保留三种结构，成本更低。另有最近十二点的滚动 GP，设置与 EP1 相同。LLM 与 N-选二有相同的可用候选、试算反馈、参数域、计费及求解预算，N-全三不承担不用的试拟合成本。未飞行的本轮只比较未来点测分布，不评价路线安全或实际 `T+Q`。

每表按 `[luna,sol56,sol61]` 左循环移动 `(layer+rep)%3` 的顺序请求；顺序在生成样本前即由清单固定。每种配置十二个机会，各一次独立会话。不因请求顺序、选择内容或分数改变其余模型的输入。

## 总资源与失败语义

- 全批至多 36 次逻辑请求；每种配置至多十二次、2,160 秒模型等待，每次最多 180 秒，三者合计 6,480 秒。CLI 在一次会话内的内部重连计入同一等待，记录可见网络错误、重连事件及实际回执；不知道完整网络尝试数时填未知。原始请求、原始回执、事件、诊断、会话 ID、usage 与请求/接收哈希均保留。可恢复的诊断不能单独否决最终完整且无工具活动的合法回执，工具活动、错绑或未完成会话仍拒绝。
- 共用实际数值上限为 72 次拟合作业、144 次最小二乘、5,760 次残差、5,760 次雅可比、65,520 个拟合字典核项和 72 次最多十二点的 GP 分解。另有最多 1,872 个分量预测核项，含试拟合验证和五个等效世界臂的正式预测。失败但已经发生的试算计入成本，成功模型同选一对时也不免去其独立应计预算。
- 单个选二臂每表至多五个拟合作业、十次求解、400 次残差、400 次雅可比和 4,992 个拟合字典核项。N-全三为三作业、六次、240、240、3,276。公共计算可缓存，实际共享成本与各臂独立应计成本分别报告，不能相加冒充真实执行量。
- 回执超时、缺失、错绑、非法 JSON、重复或错误代号保留为该场失败，其他模型和其他预定场继续。明确的模型通道不可用关闭**该配置**剩余调用，记录为 `disabled_unavailable`，其余配置继续；全部配置均关闭时结束批次，不再生成后续样本。达到单模型预算关闭该配置。公共输入泄漏、预测冻结/评分时序不可核验、工具活动、源码或公共数值账本失效立即停止整批。
- 不补场，不替换种子，不重跑以取得更好的输出或分数。每种模型仅一次生成的随机性写入限制。已完成的合法数值结果保留在各自实际终点。

## 评价与选型

逐场六点平均 NLL 为主质量指标，越低越好。另报 RMSE、MAE、90% 观测区间覆盖和宽度、所有入选均值距新读数超过 8 dB 的全失配点、同选一对的次数、有效回执率、耗时中位数/P95、token 及可取得的费用。分列请求名、返回模型 ID、系统指纹和底层身份是否已核验，无返回信息填未知。

每个 LLM 分别与 N-选二及 sol56 作逐场配对，四层等权、层内三场等权。10000 次分层 bootstrap，PCG64(438271)，场为重采样单位，各比较共享索引。缺失时仅列完整配对的描述性均差、区间及分母，不能当作十二场完整检验。仅正常闭批且该配置十二场全部合法、有完整的 N-选二及 sol56 配对时，才评价校准通过：两项逐场平均 NLL 差均 `≤+0.05 nat/点`。sol56 相对自身为零。此筛选阈值不是统计非劣效证明。

满足质量和协议要求的配置按有凭据的总实际校准费用择低，价同依次比较等待中位数、版本可核验程度。未取得价目和有效账单时，**成本选型未定**，报告质量、时延和 token 资源，不声称已找出最便宜或性价比最好者。输出可能含推理计费，不能重复相加；缺失 token 和失败费用均不填零。若无配置通过，报告本任务的 LLM 用法尚无合格模型，不削弱强 N 或改判据。

交付可直接打开的静止 HTML 比较图、逐场与汇总 JSON、原始回执、配置、资源表和停止原因。该结果只用于选型。EP2 须另外固定选定模型并冻结独立评估合同与新样本，不将校准表用作正式论文性能评估集。
