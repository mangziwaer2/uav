# P7：直接选路线与中间目标的单次闭环试飞

2026-11-24。用户授权一次新的仿真试飞。仅用未试的新开发场景 `43537`，测量种子 `43538`，复用 P4 的合成时变场生成与固定高度建筑处理，不看封存场景。目的为验证两个动作接口从真实 LLM 到实际仿真余程的接入和单例行为，不是论文收益验证集。无重试、主动补测、新传感或阈值回调。

- 在时刻 0 与 12 秒按既有数值规则复核；共用一次正常点测飞行至 24 秒（含该点）。仅用固定 20 秒时空 GP，点每秒一测，先核旧预测再更新。若前缀未抵达检查点、无合法当前余程或无合法几何备选，不咨询，不执行后缀。24 秒的合法全余程同域比较，持续核建筑净空、初始 `1.25D0`、能量储备和 90 秒上限。接入仅修余程；各后缀承诺选定路线直至终点或硬预算，不做第二次选路，仍保留正常监测并更新 GP。
- 两次独立、无上下文继承的实验决策调用，均继承同一主会话的默认模型及推理配置，不替换模型，每模式至多一次单轮、不使用工具。公开白名单为时刻/几何/飞行资源、已有原始点和已匹配的冻结残差、同一 GP 的有限路线与分岔证据、合法中间目标和补全映射。不得给真场、发射机、未来点、场景种子、回放、答案基线 ID 或事后评价。除动作说明外两包相同。`route` 可选任意合法路线 ID 或保持；`waypoint` 只选公开内部顶点 ID 或保持，以公共代理价最小的完整余程补全。旧软规则不是这两模式的二次门控。未知不是低干扰区。
- 同一 checkpoint 固定 `N-guard`（旧软换路规则）、`N-route`（同域全枚举最小共享代理价）、`N-waypoint`（在同一补全映射与保持动作上全枚举）。失败回执各用对应的 N，而非改为原规则 N。选定同一路线的实验臂共享一条实际后缀，不重复飞；不同路线同起点、同世界、同检查点的随机状态。观察者真值只在全部执行结束后计算并发布到左图，右图只用同期 GP 和已发生点。报告实际 `T`、`Q`、航程、能量、到达和有限域动作差异。
- 总预算：一次前缀、最多五条不同合法后缀、两次真实调用；每份完整白名单输入最多 14000 UTF-8 字节，每次回复一行、最多 1000 UTF-8 字节。自发布检查点共同计时 360 秒，记录端到端回执耗时；服务隐藏推理 token 不可见，不申报为零，不把墙钟等待计入模拟航时或宣称实机实时。单次回执须匹配菜单 ID、只含规范字段、在截止前到达；原始回执留证，失败/缺失/迟到不再询问。数值预算每路径最多 61 点、3 次复核、70M 决策 GP 查询、最多 61 次决策拟合；检查点分岔证据也计查询。显示栅格、事后评分和一次检查点恢复拟合单列，不参与选路。预算耗尽保留合法已飞段。
- 冻结源与合同后方可生成前缀；公开输入就绪并固定字节哈希后方可发起调用。检查点与执行均单次，失败照实记录，不选另一个种子补结果。没有合格回执不能称 LLM 实际参与了该臂；即使单例有收益也不能泛化。
