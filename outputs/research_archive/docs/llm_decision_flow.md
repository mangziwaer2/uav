# LLM 介入后的完整决策流程

当前能证明的是数值闭环可运行、局部一步预测有仿真点测核对、独立 LLM 能产生合法模型选择。P5 的回复实际未进入飞行；P6 只检查冻结快照和模拟回执。新增的公共证据工具已用本机固定回复验证，尚未接在线执行器。下面把已实现与待检验分开。

## 在线闭环

| 步骤 | 执行者 | 输入、输出与限制 |
| --- | --- | --- |
| 1. 预测、核验、更新 | 数值 GP | 在飞下一小段前签发下一实际位置和到达时刻的预测。抵达只测当前位置带噪总功率。先把该点与旧预测对账，保存带符号误差、观测标准差与支持标记，再用原始点更新 GP。GP 栅格不是新增测量。 |
| 2. 形成候选与复核机会 | 公共规划工具 | 从当前位置枚举未飞到目标的合法余程，保留当前余程；核连续建筑净空、原始总航程 `1.25D0`、能量和时限。P5 固定 24 秒咨询，P4 的风险越线只是复核信号，不直接改道。后续应把是否还有不同的合法动作分开记录，不能事后只挑有利的咨询位置。 |
| 3. 冻结公开决策包 | 公共工具 | 同步打包截至此刻的原始点、旧预测反馈、候选及预计到达时刻的 GP 证据。P5 有三种时间尺度的逐点预测与全部候选价格；新的公共证据工具对每个冻结后验额外生成相对当前路线的分岔比较。数值 N 拿同一包。不传发射机、真场、未来点测、事后最优或回放。 |
| 4. 一次结构化回复 | 独立 LLM | P5 只选 `short/nominal/long`。后续可在一条回复里提交一个有界模型修订或保持，加候选 ID 和依据；候选 ID 是建议，不是飞控命令。须用确定性工具比较同一动作域内的强 N。公共交付必须验证原字节、格式、时限和版本；失败只数值回退，不续问、不采用迟到回复。P6 只用确定性本机进程验证了该接口。 |
| 5. 核价、核约束、执行 | 公共规划工具 | 用被采纳的模型重新核整条余程及每个候选的预测代价，当前路线同样参与比较。保留公共支持规则，不能仅凭候选进入未知区后代理价便宜就改道。几何细化、插点和连续净空由数值工具处理。选定后只执行短段，已飞部分不改。 |
| 6. 评价影响 | 预先冻结的核验器 | 修订以后只用新签发、后来真实取得的点核预测，不重复继承旧分数。记录模型是否变、实际选路是否变、全程真实 `T`/`Q`/到达是否改善，以及调用资源。异轨后的点误差是在不同位置，不直接当同点精度对照。 |

## 先增加能区分路线的信息

1. **原始点与模型失配。** 给最近一段的坐标、时刻、带噪 dBm，加上旧版冻结的预测、标准差、支持和标准化残差。看偏差是否持续并有方向，而不是看一次大偏差或 GP 回代。沿航迹看到功率变了，可能是飞到了不同位置，也可能是环境随时间变了，单一轨迹未必能区分。
2. **分岔前后分开报告。** 对每条合法候选给到达时序、分岔时刻、能否在分岔前取得下一个正常点、分岔后双方各自/共同有支持的时长、未知时长、航时与相对功率代价。先给少量代表候选和原始证据索引；只有必要时展开查询，不把局部覆盖良好的整张栅格当成全余程证据。
3. **给多个可验证的解释，不凑一张完美图。** 固定 GP、变化点后重新加权的 GP、不同时间尺度等可以作为互斥假设分别预测。只有在下一些正常点上能区分，或者它们预期有不同的合法首选，才值得让 LLM 提议修订。不能把它们的功率相加，也不能把假设里的等效源称为真实源定位。给 N 同样的结构、参数域和预算；数值可完全枚举的小域先完整枚举。
4. **先利用顺飞已有的观察机会。** 如果候选在下一正常点前仍共用合法前段，才可能使用新点复核后面的分支；这不保证该点能区分两条分岔后的暴露。若已从当前位置立即分开或两条都缺证据，就明确标未知并按数值策略继续。额外飞行补测需要独立合同，当前不启动。

## P5 中一个具体例子

24 秒时，45 秒 GP 的当前余程预计需 26.67 秒，其中 21.19 秒没有定价支持，约 79.5%。备选和当前余程先共用 1.31 秒，分岔后只有约 4.08 秒双方都有支持。备选按 `T+Q` 代理便宜 23.81，但排除单侧支持相对代理的价差后反而贵 28.18。应把这组差异交给 LLM，而不是仅显示更便宜的代理价或高亮另一路线。

沿实际飞过的路，24 秒后有 27 个局部支持的一步预测与新点匹配，MAE 为 2.41 dB，27 个都在模型给出的 95% 观测区间内。这个小样本说明有可核验的近程预测，不等于区间已校准，更不验证分岔后未走的路线或全图。两种目标在 P6 共享约束和证据规则时都保留了该余程，单改目标并不能为这一状态增加信息。

## 公共证据工具的边界

[实现](../src/uav_em/passive_decision_evidence.py) · [确定性测试](../tests/test_passive_decision_evidence.py)。工具只接收公共规划器已核合法的候选和一个当前冻结后验，不生成路线、不采样、不选路。配对支持只计到两条路线中较早的到达时刻；较长路线的后段不能再算双方支持。分岔处恰好可取得的正常点不算提前观察；分岔前只是预计可测，是否来得及处理还是要扣预留时延。整路代理差沿用公共积分；分岔拆分另显式插入分岔时刻，拆分是说明证据来源，不替换正式复核或将代理差当真实暴露。内部快照尚不是实际模型请求合同；上线前还需冻结序列化、字节和查询上限、回执版本和回退规则，不静默削弱 N 的候选域。

**动作表达的对照：** [直接选路和中间目标](method.md#直接选路与中间目标离线接口)已用确定性样例验证。它们不重新应用原软换路规则，便于对照 LLM 是否可能提出不同的合法动作；数值对照也可以在相同动作域不施加该规则。中间目标由合法候选的内部顶点提供，共同算子按完整 `T+Q` 代理价补全，不能创造原来不存在的路线或信息。实际模型回执尚未接入。若缺少能支持不同动作的观察，再比较可由后续普通点区分的互斥模型修订；最后才比较更细数值路径优化的收益。目标改为 Barbosa 指数弧长时要单设对照，并始终分项报告真实 `T`、`Q` 和硬约束，不以代理价格代替飞行收益。
