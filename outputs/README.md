# 当前结果

唯一入口：[index.html](index.html)。当前只保留`interference_point_agent_20261109/`，旧实验已按最新用户授权删除，不把历史测向收益当作当前点测结果。

研究目录包含：

- `scenarios/`：研究者用冻结环境配置，含隐藏真值，不给决策agent。
- `public/`：agent合同、因果请求、原始响应和运行控制状态。
- `runs/`：每个任务episode、metrics、可读决策日志和静态图。
- `replay/`：集中GIF和源episode/文件哈希清单。
- `reports/`：审计、必要运行源码、清理记录及当前源码动作重放核验。
- `logs/`：运行和测试日志。

本轮是两个构造机制场景的基础可行性试验；动作、航程与总搜索资源不同，不证明同预算LLM优化优势。未来论文方法与对照另建新研究目录，禁止覆盖本轮证据。
